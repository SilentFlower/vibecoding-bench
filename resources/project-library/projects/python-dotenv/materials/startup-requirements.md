# Startup requirements
The caller supplies an absolute path, for example /tmp/synthetic-app/settings.env, created only in a dedicated temporary directory. Different working directories must not change results. Preserve existing deployment environment values. APP_NAME must exist and be nonempty before startup; OPTIONAL may be empty. A missing file is acceptable only if explicit deployment values satisfy all required fields. Missing required fields must prevent the application startup marker from being written. Prefer explicit paths, never search an ancestor directory. Distinguish parsing/loading success from business validation.
