# Backup and recovery review
This is one local writer using JSONStorage. It is acceptable to stop writes and close the database before taking a backup. Preserve all named tables, document IDs, and next-insert behavior after restore. Explain validation of backup bytes and malformed JSON, how to avoid overwriting an unrelated nonempty target, and how to rehearse recovery using synthetic data. Evaluate the current guarantees from source. AtomicJSONStorage, export_backup and import_backup are not application-provided APIs. Any storage extension is proposed future work; do not implement it or touch real files.
