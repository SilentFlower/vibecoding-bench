v3 调度与会话可视化

规划示意 · 账号总览、发送时间轴、当前请求状态和会话分布 · 数值均为合成示例

关键口径：三个数量不能混用

  • 绑定会话：当前未过期的账号绑定。
  • 活跃会话：有效绑定中至少一个等待／执行请求的不同会话。
  • 请求：一个会话可以同时发起多个请求。
  • 上游池槽位独立展示，不等于上述数量。

关键判定：看真实提交和剩余等待

  • 实际提交才落一个时间轴点，既有重试也计入。
  • 倒计时表示最早许可，不是未来发送保证。
  • 时间轴只覆盖最近短窗口，不补造缺失点。
  • 健康和延迟来自真实请求，不发额外探测。

异常与资源：只读观察不改变调度

  • 本地超时返回 429，既有绑定保留。
  • 采集失败显示未知／陈旧，不假装零负载。
  • 详情可见时每 5 秒刷新，关闭或隐藏暂停。
  • 事件缓冲有上限，截断和重启缺口明确提示。

当前边界：设计示意

  • 仅 v3 API 网关到账号发送器，不含独立 CLI 流量。
  • 会话摘要脱敏，仅管理员可见，不读取官方聊天。
  • 采用现有页面风格，图解的暗色不代表全站换肤。
  • 图解为方案示意，实际功能以管理端运行状态为准。
