每方五个新进程，每进程六轮串行作业，交错顺序且奇偶轮反转，共 60 次实际模型路径请求。相同业务正文、相同本地 HTTP SSE 上游和 739 B 响应负载，独立 HOME、合成 API key、无外网命名空间；无压缩任务并行。标杆保持 20 逻辑槽位，只使用一槽，两方都是一个物理进程串行。

## 空间与独立部署

部署只需一份上述可执行文件，无外置 Bun、JS、原版、提取目录、7zz 或新增专属动态库。原生执行体沿用系统 glibc 的 libc、librt、libpthread、libdl、libm 和 ELF 加载器，全部在清单中单列；这些是既有系统平台组件，不是新增打包依赖。控制面公共依赖与构建工具均不计入 CLI 运行时边界。

加载器使用封存 memfd，展开的内存文件约 102.25 MiB，不创建完整磁盘展开副本。私有挂载/网络命名空间中，隐藏原版、项目 src、构建 scripts 和全部旧 /tmp 后，仍可完成真实单轮并正常 shutdown。额外 /tmp 文件在就绪、空闲及 10 ms 轮询的观测峰值均为 0 B；证据见 acceptance/deployment-filesystem.json。内存文件大小与 RSS 是不同指标，不能直接相加当作物理内存总量。

基准中本项目作业后 RSS 中位 149196800 B（约 142.29 MiB），观测 RSS 峰值中位相同；标杆分别为 213983232 B 和 231559168 B。两方 HOME 内新增文件观测均为 0 B。RSS 不是部署文件大小，观测值不是内存硬上限。

## 可重复构建及依赖闭包

固定来源、工具、桥接源码和配方，在不同临时目录独立执行两次最终生成命令，得到相同分发及执行体 SHA256。审计数组受并发模块加载影响，条目顺序可以不同；按条目集合比较完全相同，二进制字节一致。证据见 acceptance/reproducibility.json。

正式转换使用 TypeScript AST，逐模块验证原始摘要，不对源码示例/模板内容全局替换。闭包映射 1220 项，改写 218 个明确位置；包含两个嵌入原生扩展及九个压缩资源。199 个其余静态 require 对应 26 个已在原版隔离探针核验的 Bun/Node 内建模块，不新增包依赖。

残余三处动态 require 均已读取：剪贴板和音频模块的相对 .node 回退，以及 protobuf 的可选依赖探询。前两项已有嵌入主路径，桥接不注册本地工具或音频/剪贴板入口；第三项 long 使用已打包实现，buffer/fs 使用内建实现，未接入可由 API 输入任意选择模块的路径。独立部署及全部支持场景验证不访问这些相对回退目录。具体位置见 manifest 中 remaining_dynamic_calls。

## 行为验证

- TypeScript 检查与基础构建通过；C 加载器以 -Wall -Wextra -Werror 构建成功。
- 单元 **40**、控制/存储集成 **17**、原版 TLS 原生 **17**、精简版 TLS 原生 **17**、浏览器 **3**，共 **94** 个自动化用例通过。
- 原生场景独立核对 CCH、扩展头、metadata/session/prompt、主子代理和压缩分类、工具/thinking 历史、流/非流、原始响应字节、错误状态及每轮单次发送。
- 相同 session 的六轮交替主子代理保持同 PID，Unicode 正文不串轮；取消、空闲及流中崩溃后换进程，当前作业不重放。伪进程额外覆盖错归属、重复握手、双终态、缺 idle、迟到帧、初始化失败、文件替换及背压下取消/关闭。
- 结构故障探针拒绝九类来源/内核/标志/指针/越界路径/重复/编码/ELF 错误，源文件始终未变。内层结构测试使用合成摘要进入边界，不能代替生产入口的固定源 SHA256 校验。
- 完整构建流程的缺资源与预算失败探针均通过：前者在私有抽取目录删除一个必需资源，后者以私有 GCC 替身生成超过预算 1 B 的最终候选；生产工具与源码未变，两种故障均不输出可接纳文件或 manifest。预算探针使用已校验的本地 SDK，证据见 acceptance/build-guards.json，替身不会执行或登记。
- 独立默认 Intl 与 en/zh/ja/th/ar 分词/字素探针与原版一致；当前正文支持保留。未宣称提供全部非英语 Intl 展示定制或通用 CLI。

命令输出与原始报告保存在 acceptance/。验证全部使用合成凭据、独立 HOME，无真实账号、登录刷新或付费推理。
