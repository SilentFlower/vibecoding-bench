# 修复 Claude 账号跨代切回 V1

## 目标

让 Claude 账号在关闭接单、环境停止或经历多次换版后，仍能从账号配置切回 V1。

## 范围

账号管理保存、待切记录的后台对账，以及切换后第一条请求的路由。11-14 的线上验收沿签名发行和受管部署流程完成。

## 现场与决定

- **11-14 的接单已打开，发送器第 174 代已就绪且空闲。** V1 已保存为待切目标，当前配置仍为 V2。网关登记的是第 168 代，现有检查只拿到第 172 代的换版凭据。
- **跨代回切读取同账号已核验的换版记录。** 第 168 代的登记与归档吻合。后台补齐核验后可继续处理已保存的 V1 目标。
- **已停止的环境可原地切换。** 编排确认原角色已停且旧请求和回执已收尾后，网关可以应用 V1，接单开关由原入口控制。

## 技术概览

沿用现有账号门禁与修订提交。编排补充同节点换版和实际停止的证据，供首次保存和后台对账共用。

## 验收

- 接单关闭时，本机和 SSH 节点的已停账号均可切回 V1。
- 隔离复现 168 → 171 → 172 → 174，已有待切目标自动生效。接单开启后，首条新请求走 V1。
- 旧轮活动或归属待确认时保留待切。重复保存和网关重启后继续对账。
