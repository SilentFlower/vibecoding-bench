# Brief — AGY 受管凭据与原生更新合同验证

## Goal

- 取得 AGY 1.5.9 受管凭据的实测合同，为账号和 API 运行环境接入确定依据。

## Scope

- 验证 AT-only 启动、凭据缓存、更新和到期刷新。
- 覆盖并发刷新、旧代回执、原子保存和失败对账。
- 观察认证恢复、SSE、工具续轮、取消、遥测及停止排空。
- 交付独立验证器、离线单测和脱敏接入合同。

## Non-Goals

- 工程任务、养号执行及其与 AGY 的交互。
- 正式账号迁移、UI、Gemini API 路由和同形体处理的实现。
- 生产部署、生产凭据迁移及 new-api 渠道变更。

## Technical Overview

- 使用临时 HOME、合成凭据、本地服务和并发屏障执行离线实验。
- 原生实验采用已核对哈希的 1.5.9 原版，管理侧独占刷新材料，工作副本测试仅消费访问令牌。
- 通过私有观察关联实际发送与凭据代次；按结果确定原位更新或保留在途进程的新代切换机制。
- 刷新未知结果持久保存为待确认，收尾保留最新权威凭据。

## Context & Decisions

- 已有基线确认原生 OAuth 登录及新进程复用登录态。
- 父任务已确定账号、凭据、运行环境、Gemini API 与请求记录闭环。同形体开关按 AGY 账号独立设置，默认关闭。
- 真实验证限既有 agy-oauth-test-159 测试环境及私有副本，最多 8 次模型提交，单次截止 120 秒。
- 原始凭据和敏感观察仅存于受限私有目录，仓库交付脱敏摘要。

## Risks

- AT-only 和常驻进程凭据更新能力待实测，原生限制可能影响后续接入方案。
- 真实测试环境访问和当前登录态待核对；实验中断需依当前权威凭据对账恢复。
- 旧压缩研究制品存在待核对差异。本轮使用已验证原版身份。

## Acceptance

- 固定版本、进程、隔离 HOME 与实验结果可关联。
- 凭据换代、并发和故障矩阵有可重复结果。
- 实际发送代次、SSE、工具副作用与收尾行为具有脱敏依据。
- 各项结论区分原生实测、离线模拟及待验证状态，后续子任务取得统一合同。

## Next Step

- 激活凭据合同子任务，核对原版实际入口与凭据字段，并建立离线实验验证器。
