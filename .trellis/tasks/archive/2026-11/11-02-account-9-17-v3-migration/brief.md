# Brief — 9-17 免登录迁移

## Goal

- 复用当前登录态，把 9-17 安全交接给 v3。

## Scope

- 迁移必要登录文件、原 CLI 身份、代理与账号策略；保留额度阈值，v3 养号迭代初始关闭。

## Non-Goals

- 不迁旧任务、会话、工作目录、抓包或旧 API Key；旧数据由后续退役步骤永久删除。

## Technical Overview

- 等旧执行完成并关闭旧入口，经刷新锁核对最后凭据，再走 v3 现有身份导入、绑定和维护门禁，恢复原策略。

## Acceptance

- 无重新授权，目标身份、代理与策略匹配，旧端退出且 v3 为唯一活动刷新所有者，管理检查通过。
