# AGY运行环境与Gemini API接入

## Goal

让已管理的AGY账号通过现有平台运行环境实际处理Gemini协议请求，提供文本、SSE和调用方工具续轮，同时保护凭据与账号归属。

## Background

- 父任务为../11-18-multi-platform-account-runtime/prd.md，本任务承接R03、R04及R06的运行环境部分，支持AC02、AC03、AC04、AC05、AC07和AC09。
- 凭据研究与多平台账号授权任务已经交付；接入基于当前分支feat/agy-account-runtime，包含业务提交f2d9c4c6及完成记录6f82ec62。实际源码核对见research/current-contracts.md。
- 现存AGY 1.5.9研究原型具有原生RPC、原始Gemini响应及工具回填机制。其固定模型、API Key测试配置、参数子集和交付身份仍需正式适配。
- 用户要求沿用现有界面与链路，AGY与工程/养号交互处于范围外。此前人工登录验收前置已取消；真实授权/模型实验分别记录证据和授权，既有真实模型预算已耗尽。

## Requirements

### AR01 平台运行环境与交付

- 按账号平台选择固定内核，AGY首期固定1.5.9；相同模型名不能导致AGY账号误入CC内核。
- 复用现有部署、环境、代理、维护和资源策略，通过平台适配接入；账号HOME、凭据、会话、出口和运行归属独立。
- 固定内核随账号镜像交付，完整执行体和适配源码身份可核验。共享只读映像，分项观测分发体积、共享映像、worker和控制内存，资源限制使用明确策略。
- 环境的启动、就绪、停止、重启、恢复及空闲升级有完整生命周期。未知状态受控隔离，回退保留当前凭据及身份。

### AR02 Gemini业务接口

- 对外保持Gemini协议，复用管理平台已有API令牌、限流、取消与维护准入；格式转换继续由下游new-api承担。
- 文本生成、非流式返回、SSE、调用方函数声明和真实结果回填接入固定原生路径，业务连接Google官方上游。
- 模型选择来自账号实际原生能力，核验公开模型名与原生ID映射；AGY账号调用其支持的Claude或Gemini模型均使用AGY内核。
- 原始候选、usage、签名、停止与错误保持可追溯。不能以部分文本或HTTP成功代替原生终态。
- maxOutputTokens采用已验证的原生映射。temperature、topP按用户决定作为兼容字段接收并忽略，沿原生默认值执行；请求记录区分收到与实际生效参数，不将这两个字段标为已应用。
- 输入结构、模型、工具、签名及其他实际功能继续按明确能力校验，保持请求语义与原生执行来源可追溯。

### AR03 凭据代次、工具与有界恢复

- 唯一管理所有者保存RT并执行刷新，业务worker只接收有效AT和到期时间。pending/reconcile阻止新普通发布，旧结果按代次隔离。
- 新worker读取新代AT，原worker保留在途请求和工具轮；工具结果绑定原账号、调用方、worker、conversation及toolCall，拒绝重复、跨归属和歧义回填。
- 只有已核验真实认证失败、同账号有效新AT、原截止有效、响应阶段允许且尚未重试时，允许一次认证恢复。
- SSE已发送后、工具等待期间、取消、刷新中断和停止排空分别有明确终态，记录每次实际模型发送。

### AR04 界面及后续交接

- 沿用现有环境页控件、布局和反馈；轮询保持草稿、焦点与选择，迟到回执按账号和代次隔离。
- 交付平台、账号、版本、环境、worker、HTTP请求、attempt、conversation、toolCall及凭据代次的事件合同，供后续请求记录任务消费。
- 同形体策略字段继续沿用账号配置，实际文本转换由独立子任务实现。

## Acceptance Criteria

- [ ] ARA01：同一公开模型在CC/AGY账号下按平台选择内核，AGY模型名与原生执行ID有可重复映射证据。（AR01、AR02）
- [ ] ARA02：隔离环境可启动、就绪、停止及恢复；HOME、出口、凭据与会话隔离，资源分项和共享映像身份可核验。（AR01）
- [ ] ARA03：Gemini文本、非流式、SSE、函数声明与结果回填保持正确终态和原始用量来源；temperature/topP缺省及显式提供均可正常执行，实际采用原生默认策略；其他不支持输入在发送前明确处理。（AR02、AR03）
- [ ] ARA04：AT-only副本、新代准入、旧worker在途保留、并发认证失败、有界恢复、SSE取消、工具跨到期与重新授权场景可复现。（AR03）
- [ ] ARA05：CC接口、环境及资源配置回归；环境页桌面/移动布局、草稿与迟到响应验证通过。（AR01、AR04）
- [ ] ARA06：交付可复现制品及跨层事件合同。合成与原生证据分开，真实Google模型请求按独立明确预算执行。（AR01—AR04）

## Non-Goals

- 工程任务、养号执行及其与AGY的交互适配。
- 新增公共Anthropic协议、修改new-api源码或现有渠道配置。
- 同形体文本转换、完整请求记录页面及跨子任务最终联调。
- 生产迁移、部署和未授权真实模型调用。

## 已确定的验收边界

本任务先完成工程、合成上游和固定执行体的零模型验证。此前用户取消人工登录前置的决定持续适用，真实Google授权、模型接受性及跨实际到期场景作为有授权账号与独立调用预算时的外部验证，保持未验证标记。生产部署及新的模型预算另行授权。
