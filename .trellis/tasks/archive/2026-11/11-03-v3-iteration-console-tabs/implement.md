## 验证

- 对实际修改的原生脚本执行 node --check webui/app.js、node --check webui/projects.js。
- 使用现有 deploy/v3/verify_stack.py --browser --project-iteration 的隔离验证入口，实际命令补齐同批清单路径；扩展既有工程浏览器夹具。
- 真浏览器覆盖统一顶层激活、内部切换、账号往返、刷新、前进后退和账号页直达。
- 网络记录核对导航只有 GET；两个 namespace 各自项目池/计划/终端/记录/分页不混用，已有后台工作持续。
- 注入旧请求慢响应，快速往返至少 20 次，检查仅当前页更新，SSE/时钟数量无累积。
- 覆盖账号参数非法、账号删除/停用、深浅主题、键盘及约 720px 窄屏。
- 账号 CLI 配置和抓包弹窗使用正确 namespace，保持既有保存与停止行为。

不为静态标签改名编写重复实现的单测；行为与生命周期通过现有真实浏览器夹具验证。
