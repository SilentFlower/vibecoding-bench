# Brief — SSH 节点支持账号密码认证

## Goal

- 添加节点时支持用户名密码 SSH 认证，兼容现有私钥方式。

## Scope

- 节点表单、API、私有凭据保存及全部 SSH 连接支持认证方式选择。
- 补充安装配置缺失提示、接入文档和隔离验证。

## Non-Goals

- 已有节点在线改密、二次认证、批量导入及自动写入公钥。
- 发行与生产维护沿各自流程续接。

## Technical Overview

- 使用 OpenSSH 和 sshpass，经独立文件描述符提交密码。命令输入和隧道继续沿原执行入口。
- 密码文件权限为 0600，目录为 0700。主机指纹继续固定校验。

## Context & Decisions

- 旧配置默认私钥认证。表单仅提交所选材料，切换、关闭和成功后清空秘密。
- US 旧宿主模板修正方案已备好，控制端重建等待独立维护授权。

## Risks

- 密码认证涉及子进程和长驻隧道，需验证错误认证、超时清理及凭据保护。

## Acceptance

- 真实隔离 SSH 验证密码登录、指纹拒绝、标准输入和独立隧道；原私钥路径通过回归。
- API、日志和进程参数保持秘密只写；前端类型检查、构建和表单行为验证通过。
- 配置缺失显示具体配置项名称。

## Next Step

- 启动任务并实现节点认证合同和凭据执行通道。
