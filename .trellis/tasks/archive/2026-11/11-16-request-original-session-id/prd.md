# 请求记录补充原始会话、实际版本与 TPS

## Goal

管理员能够从请求记录取得原始 session ID、实际转发版本和平均 TPS，便于关联排查与比较请求表现。

## Background

- 用户要求新增原始请求 session ID 列，方便关联查询。本轮交付为记录、展示和复制。
- 用户补充请求版本与 TPS，要求复用现有列，并要求“时间 / 请求”列去掉 Asia/Shanghai 时区标识。
- `services/gateway/src/model/request_diagnostics.rs:45` 的根记录缺少原始会话字段；`:161` 的尝试会话字段均为散列。
- `services/gateway/src/service/gateway.rs:2038` 在正文解码后获得入站 JSON；普通和原生链路随后分别在 `:2488`、`:3714` 记录账号域会话散列。
- `services/gateway/src/store/diagnostics_store.rs:347` 已以 JSON 持久化根记录，管理列表和详情复用该对象。
- `apps/web/src/components/RequestDiagnostics.vue:302` 为请求列表，现有查询支持请求、响应及上游关联 ID。

## Requirements

- R1：新增“原始 Session ID”列，取客户端入站时、上游映射前的会话。支持现有 metadata.user_id 的 JSON-string 和 legacy 格式。只有请求头提供会话时记录唯一的 X-Claude-Code-Session-Id。正文会话优先。
- R2：每个根请求只冻结一次原始值。重试、换号、原生 280/293 和原有转发均保留同一入站值。本地响应和正文策略拒绝也可记录已成功解析的会话。
- R3：有效值完整保存并支持一键复制。无值、旧记录和入站正文解析前拒绝显示“未提供”。普通 API 请求使用客户端实际提供的值。
- R4：只记录非空白、无控制字符且 UTF-8 长度不超过 256 字节的完整值。超过边界显示“未提供”，保持业务转发原行为。
- R5：info/debug 均保存该字段，沿用管理鉴权及七天诊断保留期。这是用户指定的原始会话字段例外；上游会话、消息、正文、凭据及任意头保持既有摘要边界。
- R6：列表直接读取根记录，详情概览同步展示该值。窄屏和长值保持页面可操作。
- R7：在现有“模型 / 转发方式”列的转发方式后补充末次实际尝试 profile_version，例如“原生运行时 · 2.1.280”。原有转发也展示版本。详情沿用每次尝试版本，未知或无尝试显示“未观测”。普通 API 同样展示实际采用的版本。
- R8：在现有“Token（末次）”列下方补充“平均 TPS”，性能详情同步展示。计算口径为该次输出 token 数除以该次尝试耗时（秒），包含首输出等待；仅完整成功且 token/耗时有效的尝试展示数值，输出为零显示零。缺失、非正耗时、处理中或不完整记录显示“未观测”。数值保留一位小数，提示说明口径。
- R9：“时间 / 请求”列仅展示浏览者本地日期时间和原请求信息，去掉 IANA 时区文字；详情继续提供时区与原始时间。

## Acceptance Criteria

- [x] AC1（R1、R2）：280、293、原有转发的入站会话与页面值一致；池映射或换号后仍为原始值。
- [x] AC2（R1、R4）：覆盖 JSON-string、legacy、仅头、正文与头冲突、重复头、空白、控制字符、256/257 字节边界。
- [x] AC3（R2、R3、R5）：info/debug、本地响应、正文策略拒绝、普通 API 缺省会话均符合定义；记录经存储读取及重启读取保持一致。
- [x] AC4（R3、R6）：列表与详情可查看、复制完整值；旧 JSON 缺字段兼容；桌面和窄屏布局可用。
- [x] AC5（R5）：新增明文字段仅包含原始会话，既有散列、权限和保留期合同回归通过。
- [x] AC6：Rust 格式及测试、前端构建和合成管理页面验证通过。
- [x] AC7（R7）：混合 280/293 和原有转发按实际版本展示；账号基础版本、入站 UA 和配置默认值与实际版本不同时，以实际尝试为准；旧记录缺字段及零尝试显示“未观测”。
- [x] AC8（R8）：100 输出 token / 2000ms 显示 50.0 token/s；零输出显示 0.0；缺失、零时长、处理中及不完整记录显示“未观测”；列表与详情保持同口径。
- [x] AC9（R9）：Asia/Shanghai、America/Los_Angeles 浏览环境下，列表时间按各自时区正确转换，时间单元格省略时区文字，详情时区仍可查看。

## Non-Goals

- 原始会话搜索筛选、历史数据回填、上游会话明文、发送器调度及内存策略。
- 软件发布及生产部署属于后续独立操作。
