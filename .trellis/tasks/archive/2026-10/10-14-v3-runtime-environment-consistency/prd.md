# v3 固定执行环境与题库主题修复

## Goal

使 v3 账号容器、CLI 执行与页面展示使用同一套持久环境设置，新环境默认洛杉矶时区和美国英语 UTF-8，同时收住无用途项目目录及管理脚本读取权限，并替换用户排除领域的题库主题。

## Background

- 用户要求修复上轮发现的环境问题，并提出默认“洛杉矶 + utf-8 us”。
- 实际会话工具输出包含日文日期。`orchestrator/main.py:3774` 仍调用旧 `derive_fingerprint()`，`:3835` 给正式作业注入旧 LANG/LC_ALL；`account_runtime.py:857` 复制 worker_env，没有用已固化 fingerprint 覆盖三项环境值。容器默认与执行过程不一致。
- `main.py:3779` 在 v3 分支前创建 `.claude-home`；18 个实际任务目录都有该空目录。`account_runtime.py:1176` 仅清理已知旧 session 链接，未覆盖这个空目录。
- `derive_v3_fingerprint()` 未指定时区时当前使用 UTC；登录默认和前端提示也写 UTC。账号列表的有效时区仍调用旧派生函数，可能与已存在环境不符。
- 镜像中的四个 v3 管理脚本和 /sidecar 当前可被 UID1000 读取，包含中文注释；没有发现会话读取这些管理脚本的记录。业务产物中的中文／日文来自模型生成，不属于待删除内容。
- 上一个被动额度任务已完成隔离检查、未提交／部署；其现有改动必须保留，两个任务各自记录进度。本任务不将环境特征认定为封禁原因。

## Requirements

- **R1：新环境默认。** 未指定时区的新 v3 正式账号和登录草稿使用 `America/Los_Angeles`、`LANG=LC_ALL=en_US.UTF-8`；IANA 时区正常处理夏令时。显式时区设置继续支持现有地区 locale 配对。已保存环境不因默认值变化而重算时区、设备身份或资源预算。
- **R2：执行环境一致。** 普通任务、养号、抓包、恢复、续聊和登录使用账号已保存的 TZ/LANG/LC_ALL，旧账号名派生或上层 worker_env 不能覆盖。CLI 设置文件里这些受管理环境键同步到相同值，其余用户 env 与设置保持。手动查询及 OAuth 短命令保持现有代理和环境链路。
- **R3：项目目录干净。** v3 正式作业不再创建无用途 `.claude-home`；准备原项目时清理系统创建的空目录及既有可核对旧链接。非空目录、未知链接和用户文件保持，session／凭据／历史产物不删除。旧 runner 继续保留所需的 per-run HOME。
- **R4：管理脚本权限。** root 管理的四个 v3 运行脚本和 /sidecar 不向 UID1000 开放读取；root 网络初始化、监听切换、版本安装和 Recorder 功能保持。CLI 必须执行的本地额度采集脚本保留运行权限，中文源码注释保留。
- **R5：页面与兼容。** 新建表单明确默认洛杉矶；账号列表的有效时区优先展示现有持久环境，尚无环境时展示显式配置或新默认。不通过页面读取创建环境。非 v3 行为、账号凭据、代理及上一个被动额度实现保持。

## Acceptance Criteria

- [x] **A1 → R1、R5：** 新环境／新登录默认洛杉矶＋美国英语 UTF-8；显式 Tokyo／UTC 可用，已有环境在改名、重建和默认改变后保留原值；页面显示实际有效值。
- [x] **A2 → R2：** 输入带旧 ja_JP worker_env，启动的正式 CLI 与 settings.env 均使用已固化值；普通／养号／抓包／恢复／续聊／登录入口一致。实际 UID1000 的 locale、ls/date 输出符合账号设置。
- [x] **A3 → R3：** 实际 Runner 启动不生成 `.claude-home`，已知空目录安全清理；非空／未知链接不删除，原 session／HOME 不变；旧 runner 回归通过。
- [x] **A4 → R4：** Docker 内 UID1000 不能读取管理脚本或 /sidecar，仍能执行额度采集；root 版本／网络／抓包与 API 长流隔离验证通过。
- [x] **A5 → R5：** 页面默认及有效时区与后台一致，相关 Python、Shell、Docker 和浏览器验证通过；不使用封禁账号发送验证请求。

## Non-Goals

- 不清除历史模型生成的中文／日文内容，不修改官方 CLI 或遥测，不重置账号设备身份，不变更代理。
- 本轮完成本地实现与隔离验收；线上镜像切换、批量修改已有账号和 Git 交付另走现有流程。
