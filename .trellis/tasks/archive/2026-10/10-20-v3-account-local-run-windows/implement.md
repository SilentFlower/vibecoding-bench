1. 加载账号、SQLite、额度恢复和前端规范，重读当前模型/DTO/生命周期及已有时区函数。

## 风险与回退

- `QuotaGuard._resume_account` 不能在休息期消耗持久额度恢复许可；须用竞争和重启场景验证。
- queued 时间等待与崩溃运行的区别必须由持久事实确定，不靠错误字符串或内存标志。
- 时区计算不能持有数据库写锁；长等待不占 CLI 或 API 资源。
- 最后一次窗口检查不得删掉已经启动 run 的正常补充；续聊拒绝输入不得终止正在输出的回合。
- 回退前关闭限制并收口等待，保留新增列和其它任务/凭据数据；旧版本不承诺继续执行时间约束。
