# 采集 Claude Code 2.1.293 协议并升级 cc2api 版本画像

## Goal

通过正式抓包证据，让 cc2api 默认使用 Claude Code 2.1.293 画像和新模型处理，通过可配置访问策略仅允许 280、293 客户端，保留 260 等已有版本画像能力。

## Requirements

- R1：采集必须通过线上 `POST /api/captures/run`，走正式 orchestrator、worker、sidecar 与账号既有代理，目标版本固定为 2.1.293。
- R2：使用现有题库任务和系统既有默认提示词；请求中的 `prompt` 保持空值，不自行编写、添加或改写提示词，也不通过继续对话注入额外内容。
- R3：抓包 run 串行执行，相邻启动至少间隔 120 秒；前一 run 终态且 worker、sidecar 已清理后才开始下一轮。轮换可用账号，不持续只使用一个账号；每次换账号以新基线开始模型组。
- R4：出现 429、连续 5xx、上游重试、额度门禁或账号限额变化时暂停至少 15 分钟，复查账号后再决定后续采集，不用切号绕过冷却。
- R5：293 的重点模型为 Opus 5.5、用户提供的精确模型 ID `claude-sonnet-5-5`、`claude-haiku-5-5`，以及用户追加要求采集的 Fable 5.1。Fable 使用实际 bootstrap 暴露的 `claude-fable-5-1[1m]` 客户端选项，核对真实 wire 模型和协议差异后纳入对应兼容处理。不为 `claude-sonnet-5`、`claude-haiku-4-5` 等旧模型追加本轮采集和升级工作；260、280 已有兼容处理保留。
- R6：主模型采集六种现有权限模式；次要模型先采集同账号的 bypassPermissions 基线、auto 和 plan。根据实际 beta、body、SSE 差异决定是否扩展其模式覆盖，不从模型名称推断协议。
- R7：逐条主请求校验真实版本、身份头、beta 集合及顺序、请求体结构、CCH、cc_version 后缀与线程续轮规则，并区分辅助 Haiku 请求、主请求及 safeguards/SSE，记录工具调用关联的脱敏结果。
- R8：原始抓包及调试正文只保存在受限远端目录，目录 0700、文件 0600。Git、任务文档和对话只保留脱敏结构摘要、run ID、验证结果和证据路径。
- R9：在采集证据充分且升级方案经过复核后，增加按 UA 精确适配的 293 画像，保留 260、280 原有映射，出厂默认改为 293。现有准入门禁通过后，未匹配或缺少 UA 版本的请求按配置默认处理；客户端模式的出厂准入范围包含 293，保留管理员自定义准入及账号模式策略。保持账号身份与容量共享、请求画像在一次请求及重试期间固定、不同版本缓存隔离。
- R10：本轮不扩展遥测功能，不自动部署线上 cc2api；新版本上线及默认配置生效需另行按部署约定执行。
- R11：设置页和账号管理页正确呈现 293 的支持、默认回退及准入关系；账号基础版本继续表示持久环境，不能误标为最近一次请求的临时画像。
- R12：通过现有设置页的允许范围与禁止版本实现实际仅允许 280、293，不删除 260 的画像、UA 映射、页面选项或独立处理，不新增针对 260 的强制迁移。目标配置为客户端模式、默认画像 `2.1.293`、允许范围 `2.1.89-2.1.293`、禁止版本 `2.1.89-2.1.279,2.1.281-2.1.292`；非 Claude 客户端的现有允许 UA 保留。

## Non-Goals

- 删除或重做 260、280 的已有旧模型兼容；为本轮排除的旧模型新增专项采集。
- 遥测功能扩展、修改题库提示词、人工继续对话或中断既有养号任务。
- 未经独立部署流程直接更新线上 cc2api。

## Acceptance Criteria

- [x] AC1（R1、R2）：正式 API 创建的 run 快照与实际 CLI/UA 均为 2.1.293，持久化提示词与现有系统默认文本一致。
- [x] AC2（R3、R4）：操作记录证明串行、冷却、终态清理和账号轮换；异常时没有突发切号继续运行。
- [x] AC3（R5、R6）：重点模型和权限模式具有明确的成功样本或失败边界，采集矩阵与证据路径可追溯。
- [x] AC4（R7、R8）：每条消息请求的 CCH 与后缀验证结论、beta/body/SSE 差异均有脱敏报告；未验证项不得宣称已验证。
- [x] AC5（R9、R12）：目标访问配置下 280、293 客户端分别通过并使用对应画像，260、279、281、292、294 等被拒绝，默认画像不能绕过禁止规则；260 的画像、映射和配置能力仍存在。出厂默认及准入通过的未匹配或缺失 UA 回退为 293，260/280 wire 回归、配置迁移、自定义准入、账号模式、共享身份/容量和版本隔离契约通过回归。
- [x] AC6（R9、R10、R11、R12）：设置与账号页面正确展示默认 293、目标允许/禁止关系、基础版本和当前生效选择，260 选项保留；遥测开关保持用户既有设置，本轮没有自动部署。
