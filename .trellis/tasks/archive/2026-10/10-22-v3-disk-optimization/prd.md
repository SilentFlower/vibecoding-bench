# v3 磁盘优化与精简备份

## 目标

降低美国 v3 部署的磁盘常驻占用和升级时的临时空间需求，默认只备份不可重建的业务状态，同时保持账号身份、历史成果及首项目运行能力。

## 背景与用户决定

- 用户已确认执行前轮列出的磁盘优化，并明确表示“没必要全量备份”。不把这项决定解释成放弃数据库、凭据、HOME 身份或任务成果的恢复能力。
- 当前正式版本为 `ci-39800434954-1`，父提交 `cc53ba7c78d77bcf8b5303cdb5093771085e6604`；正式账号列表为空，94 条历史 run、1 个保留项目批次、6 个历史账号环境仍须保存。
- 本轮只读测量：账号环境约 6.10GB，其中 HOME 缓存约 2.36GB、npm 下载缓存约 1.40GB、CLI 安装约 1.99GB；项目内容版本约 2.12GB，任务制品约 0.68GB。缓存与已安装程序不得重复计数。
- 当前完整备份约 9.45GiB；控制端镜像的项目库层约 1.88GB。已有 22 个闲置历史镜像已在前轮清理，本轮不能再次计算这部分收益。
- 对本地已冻结项目库的依赖制品进行内容散列后，已确认约 540MB 相同文件的重复副本。生产采用相同内容版本，但实际节省量仍以生产执行前后测量为准。
- 已按明确排除项只读遍历生产目录，精简备份候选文件合计 2,015,885,937 字节，约 1.88GiB；此值为方案估计，不是已完成备份。保留历史内容版本和未明确归类的 HOME 缓存。

## 需求

### R1 默认精简备份

- 常规兼容升级默认备份数据库、部署配置、账号身份与凭据、持久 HOME 中的业务状态、工作区、任务成果、执行与恢复证据；不再完整复制下载缓存、可重装 CLI 和已证明可以由固定发布恢复的内容。
- 备份应清楚记录包含范围、排除范围及恢复依赖，校验成功前不得替换现有恢复点。
- 默认使用精简模式，完整模式仅作为显式选择保留。未被当前正式镜像覆盖的历史项目内容仍须备份。
- 保持 SQLite 一致性和当前凭据所有者，不恢复旧 token 或旋转账号身份；精简恢复必须在隔离目录验证。

### R2 缓存治理

- 清理本部署闲置账号环境中已证明可重建的 npm 下载缓存，阻止后续安装无限积累相同下载数据。
- 浏览器缓存仅清理已证明闲置或重复的版本；保留任务实际使用的浏览器与所需运行依赖，避免正式任务首次启动临时下载。无法充分证明可删的版本保留并说明原因。
- 清理必须检查当前占用、目录归属和链接边界，不影响其它部署、业务文件或正在使用的程序。

### R3 CLI 安装与版本占用优化

- 核对有效配置、登录、执行记录和历史 run 的精确版本引用，仅清理无引用的旧版本。
- 对满足只读与安装边界的相同 CLI 制品实现能够保持账号隔离的物理复用；旧布局或无法证明写入边界的制品保留并记录。不能共用可写 HOME、会话、凭据或账号私有目录。
- 所需精确版本继续可直接执行，保留版本检查、安装互斥和失败重试能力。

### R4 项目内容去重

- 对相同离线依赖与冻结内容减少重复物理副本，覆盖构建交付和安装到运行目录的路径。
- 保留全部 100 项目、426 场景、726 任务及离线验证所需制品，逻辑文件字节、权限、内容摘要和历史版本引用不变。
- 镜像拆分本身不能计为磁盘收益；以实际去重后的独立文件和文件系统空闲变化验收。

### R5 生产落地与空间证据

- 准备精确清理清单、不可重建数据保护清单、精简备份和隔离恢复回执，再执行已授权的生产空间优化。
- 新精简恢复点验证通过后才淘汰同部署旧完整备份；保留当前和上一版回退镜像。
- 验证管理服务健康、历史 run/项目内容/账号身份和配置不变，报告实际释放空间以及后续备份体积。
- 代码交付、镜像发布及生产更新遵守项目各自流程；不把本地实现通过宣称为正式上线。

## 验收标准

1. 常规备份不再包含已声明的可重建缓存和 CLI 安装，数据库完整性检查通过；隔离恢复后的凭据、身份和业务文件与原数据一致。
2. 精简备份、清理和恢复在失败、错误归属、链接异常或活动执行时保留原始状态与最近可用恢复点，失败不报成功。
3. 缓存清理后，当前所需 CLI 精确版本可以无下载启动；任务实际使用的已验证浏览器保持可用。按 R2 保留的未知历史浏览器缓存核对原字节及原兼容状态，不能把其原有缺库计为启动通过；账号工作目录与历史成果仍可读取。
4. 项目内容优化前后逐文件字节/权限及内容摘要一致，离线依赖解析、代表性原生验证和历史版本读取通过。
5. CLI 复用不扩大账号可写边界，普通账号不能修改另一账号的程序、身份或凭据。
6. 生产空间收益使用执行前后的文件系统数据，不相加镜像虚拟大小，不包含前轮已完成的镜像清理收益；当前、上一版镜像及其它应用资源保留。

## 范围外

- 删除历史账号身份、项目批次、run、会话或任务成果；重建/重授权现有账号。
- 改变评审串行机制、账号资源预算、网络隔离和身份画像。
- 全局 Docker prune、卷清理、其它应用目录清理，以及真实 OAuth 或模型请求。
