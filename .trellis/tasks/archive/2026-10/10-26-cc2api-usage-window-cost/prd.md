# cc2api 5h／7d 用量与费用统计

## 目标

参考本机 sub2api 的账号用量展示，让 cc2api 的账号卡片同时呈现当前 5h、7d 窗口的额度使用情况与请求、Token、美元费用统计。

## 原始需求

用户提供 sub2api 用量截图，并要求 cc2api 学习该功能，显示当前 5h、7d 额度；价格参考 `/root/project/my/sub2api`。

## 已核实背景

- `cc2api/web/src/components/Accounts.vue:988` 已有 5h、7d、Sonnet 和 Fable 的百分比与重置时间展示；`cc2api/web/src/api.ts:118` 的窗口契约只有 `utilization`、`resets_at`。
- `cc2api/src/service/telemetry.rs:178` 已定义输入、输出、缓存读取与缓存写入 Token 摘要，但未发现业务请求费用账本。
- `/root/project/my/sub2api/frontend/src/components/account/UsageProgressBar.vue:4` 在进度条上方展示请求数、Token、账号费用 A 与用户费用 U；后两者属于不同计费口径。
- `/root/project/my/sub2api/frontend/src/components/account/AccountUsageCell.vue:829` 的周窗口预估总费用使用 `当前窗口费用 × 100 / 使用百分比`，目前只用于 OpenAI 分支。
- `.trellis/spec/cc2api/backend/service-architecture.md:274` 要求 v3 只通过正式响应被动采集额度，保留管理员手动查询；本功能必须遵守此契约。

## 需求

- R1：在账号卡片现有 5h、7d 区域增加该窗口内的请求数、Token 数和按模型单价折算的美元费用，保留额度百分比及重置时间；随账号列表刷新更新统计，官方窗口重置后只统计对应新周期，普通页面刷新不清除当前周期记录。
- R2：价格和缓存计价规则以本机 sub2api 中可核实的 Claude 模型定价为依据；输入、输出、缓存读取及不同有效期的缓存写入分别计价，未知模型不得冒充零费用。
- R3：费用只代表 cc2api 实际接收到并记录的网关请求，不声称覆盖同账号在其它入口发生的全部消费；部署前的历史请求无法补算。
- R4：同一上游调用不能因 SSE 多段 usage、正常结束和清理重复计数；已落盘统计跨进程重启保留，并按两个真实额度窗口分别汇总。响应只记录到部分用量或统计链路失败时，不宣称数据完整。
- R5：额度或窗口信息缺失时展示未知；已到期且尚未取得新观察时展示待更新，不把未知状态伪装成 0%。
- R6：参考截图，为 5h、7d 支持 `本窗口网关折算费用 × 100 / 官方已用百分比` 的总额估算，明确标注“按网关记录估算”，不称为官方美元配额；已知记录不完整、费用或百分比无效／为零、窗口过期时隐藏估算。新启用统计的当前周期标明记录起点和可能缺少周期前半段数据。
- R7：有有效重置时间时按对应额度周期统计；没有有效周期信息时可以展示明确标为“最近 5h／7d”的本地滚动统计，但官方使用率仍为未知或待更新，且不做总额估算。现有 Sonnet／Fable 专属额度展示保留，本轮新增费用统计只覆盖通用 5h、7d。

## 验收标准

- A1 → R1、R4、R7：相同请求分别进入所属的当前 5h、7d 窗口，跨 reset 后旧请求不会串入新周期；没有可信 reset 时明确标成滚动统计。界面随现有账号列表刷新而更新，Sonnet／Fable 原有展示正常。
- A2 → R2：不同输入／输出／缓存组合的费用与 sub2api 对应规则一致；未知模型保留请求和 Token 统计，并明确费用不完整。
- A3 → R3、R4：部署后只统计本地真实网关用量，已落盘统计在重启后仍可读取；遥测关闭时仍采集，转发响应与计数不受影响。
- A4 → R5、R6、R7：未知、过期、零占用、无定价、启用后首个不完整周期和正常完整周期均有明确展示；不输出 NaN、Infinity、假零或被误标为官方配额的估算。
- A5 → R4：JSON、SSE 分块、压缩、提前断开及网关重试都有对应验证，已观察到的可计费用量按实际承载账号至多记录一次。
- A6：`cargo fmt --check`、`cargo test --locked` 和 `npm run build` 通过；本地合成请求验证数据落库、窗口汇总和页面展示。

## 范围外

- 用户／API Key 的加价结算、账单扣款、sub2api 的 A／U 双账本。
- 补算部署前历史用量，或采集绕过 cc2api 的原生 CLI 消费。
- 修改选号、额度门禁、TLS、请求改写策略或新增自动 usage 查询。
- 远程价格抓取与自动更新、新的用户计费设置和 Sonnet／Fable 专属费用账本。
- 发布部署、提交或推送。
