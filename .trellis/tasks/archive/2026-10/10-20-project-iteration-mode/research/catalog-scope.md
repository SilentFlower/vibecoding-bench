# 首版项目内容覆盖与路线样例

## 内容边界

本文件记录首版内容覆盖与实际路线。首版从既有题库的十个业务方向各选十项，共 100 个不同项目；题目仅提供领域来源，每项有可运行的小型业务核心、固定合成数据和 20 个递进步骤，不宣称实现来源题目的完整产品。

所有外部数据、页面、设备或服务均以固定的本地合成夹具提供，基线不能等待用户上传、授权或硬件接入。业务逻辑必须实质不同，允许共用启动和验证适配层，不能只替换标题、表字段或样例名称。

## 具体路线示例：批量重命名工具

首版基线提供本地 JSON 请求的文件列表分析，不执行磁盘重命名事务；路线围绕映射预览、筛选、诊断和交付结果展开。每五步为一个阶段，后续步骤继续使用原目录并回归先前能力。

| 步骤 | 新增行为 |
| --- | --- |
| step-01 | 前后缀命名预览 |
| step-02 | 编号命名预览 |
| step-03 | 捕获替换与非法模式拒绝 |
| step-04 | 名称模式选择 |
| step-05 | 扩展名归类 |
| step-06 | 相对路径越界诊断 |
| step-07 | 不区分大小写检索 |
| step-08 | 稳定排序 |
| step-09 | 保序去重 |
| step-10 | 必填项诊断 |
| step-11 | 模板占位符填充 |
| step-12 | 局部文本替换 |
| step-13 | 逐行文本差异 |
| step-14 | 逐条词数统计 |
| step-15 | 按业务分组计数 |
| step-16 | 标准 CSV 导出 |
| step-17 | 前后版本差异 |
| step-18 | 规范内容摘要 |
| step-19 | JSON 往返一致性 |
| step-20 | 业务 ID 唯一性检查 |

其他项目使用自己的业务核心；工具类的文档渲染、专注时段、片段展开、变更记录、命令历史、输入指标等安排独立业务步骤。通用查询、导出等算法原语可以共享，但输入领域字段和已运行的初始功能不同。

每步包含固定样例、空数据和变体样例；验收回归基线与前面所有已接受步骤。控制端参考行为仅用于验证内容，账号副本只有 seed，不含参考实现或冻结预期。

## 内容完成检查

- 每个项目都有可启动的不同业务基线，不能只有需求文本。
- 每个步骤至少一个新增行为断言，并包含应保留能力的回归组。
- 全部基线通过；参考行为或参考修改序列证明 2,000 个步骤的验收条件可达到。
- 实际模型通过率另行观察，参考路线通过不冒充真实模型已完成全部步骤。
