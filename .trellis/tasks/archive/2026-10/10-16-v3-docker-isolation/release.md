# v3 Docker 隔离部署核验

- 本地 Check-All 已通过；正式镜像与 verification 镜像有相同冻结源码。生产交付使用 v3 CI 生成的正式两镜像和联合清单，不使用本地验证镜像或测试 CA。
- 发布与停机/备份/恢复沿用 deploy/v3/README.md 和 scripts/v3-stack；现场读取现存部署的 env、批次与占用，保留全新停机备份，再切换同批镜像及清单。
- [上线后验证] 由本次部署执行者在现有 v3 实例核对管理端健康、会话/API/WS、全部角色状态、实际 UID/capabilities/只读挂载及总资源限额；预期与本地布局 2 验收一致，其他部署不变。
- [上线后验证] 无活动执行、发送或凭据提交未决时，按环境显式重建完成旧布局转换；核对原环境 ID、HOME、设备身份及最新凭据所有者，不能自动恢复升级前 RT。
- [上线后验证] 使用无真实模型推理的出口检查核对 CLI、sender 与 gateway OAuth 的代理配置及失败关闭；仅观测现存账号，不新增真实账号、不用已封账号探测模型。
- 公共角色异常、身份或凭据不一致时保持拒绝并核对迁移证据；回退先排空和保留最新备份，再按布局兼容规则恢复，不能用旧数据库/RT 覆盖新令牌。
- 真实上游模型推理未验收；本次隔离与本地测试结果不构成免封保证。
