# v3 手动额度查询与被动采集统一

## Goal

让 v3 除用户点击查询外，只消费正常业务请求产生的额度信息，取消额外额度轮询并保留无人值守任务、阈值等待与恢复能力。

## Background

- 用户要求“查询额度除了那个我们点击的主动查询，其余的难道不能都改成被动”，并在厘清 cc2api 与 CLI 的不同采集链路后确认“按你说的来”。
- cc2api 已从真实成功／429 响应头更新额度；v3 账号发送器已有白名单观察文件，bench 已有消费入口。CLI 普通任务保留原生 TLS，通过账号代理直达 Anthropic，不经过网关的明文响应处理层。
- Claude Code 官方 statusLine 数据包含正常响应后的 `rate_limits.five_hour`、`rate_limits.seven_day`，窗口字段为 `used_percentage` 与 `resets_at`；服务器 2.1.293 包包含这些字段，但当前项目未接入本地采集。
- 当前 v3 调度器在执行前后与待运行工作的后台循环调用主动 usage 查询；失败默认至少 60 秒重试。cc2api 还有独立的 `auto_poll_usage` 轮询入口，必须纳入 v3 的完整自动入口审查。
- 原实例及既有未提交内容不属于本任务；真实封禁原因未知，本任务不以减少请求保证账号不会被限制。

## Requirements

- **R1：主动额度查询仅由用户触发。** v3 删除任务启动／收尾、后台等待、缓存到期、窗口重置和失败重试中的自动 usage 请求；v3 的 cc2api 后台账号额度轮询同样不得发送请求，即使历史 `auto_poll_usage` 为 true。手动查询入口仍使用账号代理、按原生 TLS 查询一次，失败不新增自动重试。
- **R2：CLI 额度被动采集。** 普通任务、养号和恢复执行消费官方 CLI 已产生的 5h／7d 百分比、重置时间。采集器只读本地数据，不发 HTTP、不执行 `/usage`、不启动额外模型请求、不改变正式任务的 TLS；登录不是额度采样入口。
- **R3：复用网关现有采集。** cc2api 正常请求继续从真实响应更新额度，v3 发送器观察继续进入 bench 共享账号状态；不通过增加业务请求制造观察，不将 CLI 流量改接网关。
- **R4：阈值与恢复不依赖额外查询。** 保留 5h／7d 已用阈值、账号共同耗尽、单账号串行执行与原任务恢复。未知额度显示未知，允许已有正常任务取得首个被动观察；已命中有效窗口阈值时阻止后续执行。可信窗口到期只允许一个已有正式执行获取新观察，不将到期或缺失字段写成 0%，不新建探测任务。
- **R5：数据归属与永久错误。** 被动样本核对账号身份、执行来源与会话，按窗口时间合并，缺失／损坏／过期／旧会话数据不能冒充新观察。正常业务或用户手动查询明确返回 `account_on_hold`／`invalid_grant` 时固化现有永久门禁、停止自动恢复，不把普通限流或网络错误误判为封禁。
- **R6：页面与兼容。** 账号、任务和批次展示最新被动／手动额度、观察时间、未知状态和实际等待原因；不再显示自动查询等待／重试提示。保留用户停止、账号停用、关闭养号及身份切换的优先级；旧 runner 和非 v3 cc2api 的既有行为保持兼容。

## Acceptance Criteria

- [ ] **A1 → R1：** v3 的启动、收尾、空闲／等待 tick、重置恢复、重启和查询失败路径均不调用 usage；cc2api v3 账号即使启用旧轮询开关也不发主动 usage。旧实例轮询行为不变。
- [ ] **A2 → R1、R5：** 点击手动查询只触发一次 usage 请求并更新额度；不旁路代理；失败不安排自动重试，明确永久认证错误能进入既有停止状态。
- [ ] **A3 → R2、R5：** 正常 CLI 响应的本地样本能更新 5h／7d 状态，0% 为有效值；百分比、UTC 秒与归属正确，缺失／非法／乱序／旧会话不会污染状态。采集路径无网络调用。
- [ ] **A4 → R3：** 网关成功／429 的原有被动采集仍生效，API 与 CLI 样本按同一账号事实合并，无额外业务请求。
- [ ] **A5 → R4：** 首次未知可正常执行；达到阈值后暂停后续任务；可信 reset 到期认领一个已有执行，被动更新后恢复或再次等待。保留原 run／session／配置，停止与封禁不复活。
- [ ] **A6 → R6：** 页面来源和等待提示与后台一致；旧部署、手动查询、普通任务、养号和恢复回归通过。验证使用隔离本地服务，封禁账号不用于验证。

## Non-Goals

- 本轮不切换生产镜像，不重新授权或恢复封禁账号，不迁移旧实例账号。
- 不改变账号代理、固定环境身份、CLI 版本或官方遥测；不恢复普通任务 MITM。
- 不修改 cc2api 的选号、模型请求重写、TLS 实现或模型专属额度政策。
