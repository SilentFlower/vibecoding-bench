# 会话临时数据保留与内存盘治理

## 目标

将账号 CLI 的 scratchpad 转为私有磁盘持久存储，降低 tmpfs 刚性内存占用，保持功能、历史续跑、会话归属和 sender 性能。

## 背景与决定

- 父任务：`../11-18-runtime-memory-isolation/prd.md`。现场归因：父任务 `research/baseline.md`、`research/ordered-review.md`。
- 用户已选定第2项继续改造，要求功能正常、会话隔离、sender 性能保持。采用完整保留和原路径转存策略。
- 同账号三个养号 csvkit 会话的 scratchpad 大文件各约36.3 MiB，总分配约108.8 MiB；该CLI的 tmpfs 共享内存约127.1 MiB。这些文件属于养号执行产物。
- 账号运行环境还供普通任务、项目迭代、历史恢复及远程节点使用。变更按最新共享工作区合同实施。
- 代码依据：`services/orchestrator/account_isolation.py:230` 创建 UID1000 CLI 并挂载128 MiB noexec tmpfs；`account_runtime.py:1205`、`:3328` 提供空闲维护门禁；`cluster_migration_files.py:19` 定义节点运行态排除；`storage_backup.py:41` 盘点并核验持久文件。

## 需求

- R1：容器内 `/tmp/claude-1000` 及已有项目、session 子目录保持原路径。完整保存可读取的现有文件、目录、链接目标、内容及权限归属。停止迁移时保留已发布资料和恢复证据。
- R2：磁盘数据按不可变 environment_id 独立持有。维持同账号各 session 的路径及执行 source 映射。账号间隔离与当前会话控制合同保持。
- R3：正常执行、历史 resume、暂停、额度等待、交接及兄弟执行受原门禁保护。旧实例转存只在已核验空闲和排他维护阶段进行，转存核验成功后进入原重建流程。
- R4：维持 CLI UID1000、能力清零、只读根、no-new-privileges 及临时区 noexec/nosuid/nodev 保护。普通 `/tmp` 保持原 tmpfs。挂载能力不足的节点继续使用原布局并给出明确状态。
- R5：覆盖本地和指定远程节点。备份、隔离恢复和节点迁移保存真实 scratchpad 文件；目标节点按本机路径重新建立挂载。迁移及维护的原归属、租约和凭据合同保持。
- R6：磁盘满、转存中断、校验失败、部分创建及挂载失败具备明确恢复路径。回退携带迁盘后新增文件及最新 HOME、凭据和身份。
- R7：分别记录 tmpfs、普通页缓存、cgroup、进程内存和磁盘成本。数据样本的 scratchpad 内容退出 tmpfs；可回收磁盘缓存独立列报。
- R8：CLI 文件操作与历史恢复通过功能回归。固定版本及并发，在同宿主交错重复验证 sender 吞吐、TTFT、p50/p95/p99、冷启动和CPU。可重复退化的候选停止接纳。

## 验收标准

- [ ] A1 / R1、R3：三个独立 session 的原路径文件逐项摘要、权限及归属一致。真实 CLI 的合成会话经重建可继续读取原文件。
- [ ] A2 / R2、R3：两账号、多 session、普通任务、项目和养号执行交错运行；单条取消、暂停恢复与兄弟继续符合原合同。
- [ ] A3 / R4：实际容器 mountinfo 含 noexec/nosuid/nodev；执行临时区中的可执行文件被拒绝；UID、能力及原角色挂载边界通过核对。
- [ ] A4 / R3、R6：忙碌、未知进程、外来租约、旧代回执、坏链接、磁盘满和每个转存阶段中断均通过故障注入；重试按绑定记录恢复。
- [ ] A5 / R5：本地、远程节点、完整及精简备份、节点导出导入、目标续跑和失败回退逐项保全 scratchpad，进程及凭据归属正确。
- [ ] A6 / R7：固定3×8 MiB合成文件，scratchpad 写入的 tmpfs 增量从约24 MiB降至测量误差范围；磁盘成本及文件缓存单列。约108.8 MiB现场样本只作为预期刚性占用减量依据。
- [ ] A7 / R8：CLI功能及sender配对性能报告齐备，支持接纳决定。

## 范围外

- 按保留期删除历史文件、合并跨会话可写数据、正文裁剪及修改模型请求内容。
- sender 分配器配置、进程架构、并发、暖进程或跨账号映像共享。
- 将普通文件缓存统计直接作为净内存收益。
- 本工作包的实施范围为代码与隔离验证，首次实施沿 Brief 评审入口推进。线上发布、重建及现有数据迁移沿部署操作的授权边界推进。
