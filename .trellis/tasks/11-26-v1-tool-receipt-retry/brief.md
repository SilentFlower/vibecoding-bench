# Brief — 恢复 V1 工具历史转发

## Goal

- 让 V1 按完整工具历史继续，并在切换内核后从新轮开始。

## Scope

- Gateway 的 V1 转发、V2 回执查询和账号切换。

## Non-Goals

- V2 交互进程按发送器的现有生命周期收口。线上发布走平台流程。

## Context & Decisions

- **【关键决定】V1 和 legacy 沿普通转发契约接收工具历史。回执账本服务于 V2 会话。**
- **【重要限制】内核切换和正在发送的请求通过现有账号门禁协调。**

## Acceptance

- 存量登记无法触发正常 V1 的这两条本地 400。V1 首轮、工具续轮及重发正常投递。
- V2 校验原归属。V1 的旧工具组不会推迟 V1 切出。

## Next Step
