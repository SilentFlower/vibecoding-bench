# 恢复 V1 工具历史转发

## 目标

受管 Claude V1 按正常 Messages 路径发送完整工具历史，避免由为内核切换引入的工具回执账本误拒绝。

## 现象

用户持续使用 V1 时遇到「工具回执与登记轮次不符」和「该工具组的回执已处理」两条网关 400。共用登记自 `8718e860` 加入。旧测试复现了 V1 拿同一工具组继续发送时命中认领或终态保护。用户要求去掉适配，内核切换后的请求开启新轮。

## 需求与验收

- R1。V1 首轮及工具结果携完整历史正常转发。公开入口验证显式和省略会话、完成后重发及响应中断后的重发。存量 V1 待处理和终态记录不影响请求，新 V1 请求不写回执账本。
- R2。V2 读写自己的回执。核对原账户、主体、工具组及会话；错误归属和 V2 已消费回执继续拒绝。账号已切至 V1 后，其过往 V2 回执不参与 V1 调度。
- R3。切换使用账号配置及已有在途请求门禁。V1 完成正在发送的响应后，待执行或待回传的客户端工具结果不推迟切换。新内核开启新轮。
- R4。支持存量数据。避免数据库结构变化。实际运行的 V2 进程按现有生命周期收口。
