# 任务页交互、账号门禁与CLI运行策略修复

## 目标

合并处理任务页导航体验、账号授权异常展示和Claude CLI遥测配置，并交付已确认的备用暖进程五分钟保留策略。

## 原始需求

- R1：额外原生暖进程的空闲保留时间由60秒延长到300秒，减少备用实例重复恢复。
- R2：顶层“任务”页默认打开内部accounts账号Tab。
- R3：切换任务页二级Tab时消除iframe销毁重建造成的白屏，刷新、前进、后退与账号定位正确。
- R4：排查11-5在任务侧显示invalid_grant而cc2api实际可用的差异，修复状态来源或恢复机制中的实际问题。
- R5：任务内官方Claude Code CLI默认关闭遥测，并提供部署环境变量配置。

## 已有证据

- apps/web/src/components/Environments.vue默认内部Tab为tasks；iframe使用完整source作为key，查询或hash变化触发重新创建。
- services/orchestrator/main.py:2787读取account_quota_states的account_error并生成阻断提示；现场11-5映射bench账号14、gateway账号12；任务侧仍有invalid_grant，gateway为active且auth_error为空，任务额度窗口有更新。
- 官方CLI任务环境当前可见DISABLE_AUTOUPDATER强制设置；线上CLI容器环境和账号settings均未设置遥测关闭键。
- R1已有本轮授权下的局部改动，涉及native_runtime.rs、verify_forwarding.py和部署说明；新回收边界测试通过。
- 网关全量首跑出现压缩响应连接重置；该用例单独复跑通过，随后限制测试并行度的完整回归886项通过、0失败、9项忽略。

## 决定与约束

- 父任务直接承担共用app.js、main.py、部署配置的跨子项接线与统一浏览器验收；四个子任务记录各自实现责任、证据和独立验收。按同一批次收敛实施范围。
- 任务页默认accounts；显式tab=tasks、账号定位、刷新和前后退继续有效。
- 11-5的普通API成功不自动清除任务认证门禁。复用现有显式“额度”核验；成功后刷新账号卡片和门禁显示，失败保留真实拦截及提示。已经终止的任务由用户另行决定。
- 新部署键V3_CLI_TELEMETRY缺省off，显式off/on；非法值明确拒绝。作用于任务、项目、养号等官方CLI启动链，on恢复官方默认许可。
- 原生发送栈CCRB_TELEMETRY沿现有合同；CLI关闭策略使用官方环境键，独立自动更新关闭策略继续执行。
