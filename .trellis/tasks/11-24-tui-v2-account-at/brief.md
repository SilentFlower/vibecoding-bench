# V2 内核复用账号 AT 注入官方 CLI

## 目标

已有授权的 Claude 账号切到 V2 后，由平台把账号的有效 AT 注入原版交互 CLI，用户可直接使用 Messages。

## 范围

账号凭据解析、私有 sender 提交、官方 CLI 启动、模型鉴权，以及原工具续轮和切回 V1 的验证。

## 技术方案

复用 V1 的账号凭据解析和刷新。V2 在绑定本账号的一次性提交中传递 AT。受管 CLI 通过 `CLAUDE_CODE_OAUTH_TOKEN` 启动，sender 保留回环协调和冻结的 Messages 正文。

## 决定与风险

- **V2 自动使用当前账号已有授权。** SSH 工作区的人工登录流程独立。
- **刷新后的新会话用新 AT。** 在途工具仍回到原进程。先用真实 2.1.293 和合成凭据验证回环鉴权及续轮换代。
- **所有受管 Claude 账号各自选择 V1 或 V2。** 保存 V2 时可以按需唤醒本账号。切换继续等待原轮收尾。

## 验收

原版 CLI 与模型端都使用对应账号凭据。公开入口保持真流式、原始正文和缓存断点，客户端工具只执行一次。两账号隔离、AT 更新、待工具时回切 V1 均通过。

## 后续

休眠账号的双向切换已通过隔离验证。签名发行和 US 真实订阅实测由 V2 上线母任务执行。
