# Brief — Claude 遥测收尾与原会话状态保留

## Goal

- 让官方 Claude 客户端正常收尾，并保留原会话尚未发送的遥测。

## Scope

- worker 正常结束、失败、超时、停止、额度暂停与恢复，以及继续对话和登录会话关闭、登录提交。

## Non-Goals

- 不做固定容器改造，不改 cc2api、额度策略和题目；不跨会话代发、不伪造遥测；本轮不部署生产。

## Technical Overview

- 记录并校验本次 Claude 进程，发退出信号后最多等 15 秒，完成状态回写后再关闭 worker 和代理；取消原会话遥测目录的主动删除，记录超时强制收尾。

## Context & Decisions

- 客户端本来支持退出刷新，队列重试按会话筛选；已有 HTTP 200 发送记录。沿用每个 run 的 HOME，保持原业务结果、额度恢复代次及 managed OAuth 所有权。

## Risks

- 网络或原生重试限制仍可能导致未发送；修复不代表遥测必达或解决封号。收尾会增加等待，实际支持版本的退出机制需核验。

## Acceptance

- 验证先退出再关闭代理、原会话状态保留、无进程/重复关闭/超时兜底；六类业务结果不变，旧执行清理失败不恢复第二份执行；继续对话关闭不阻塞事件循环，账号及会话隔离、凭据规则不回归。

## Next Step

- 确认后启动任务，经实现路由进入进程收尾及对应回归验证。
