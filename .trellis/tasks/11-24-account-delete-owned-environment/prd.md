# 删除账号时自动清理其专属运行环境

## 目标

管理员在账号页删除账号后，其独占的运行资源和环境卡片随之移除。用户可以保留项目文件、个人配置和历史记录，后续节点升级可以继续进行。

## 现状

- 网关删除入口先取得配置许可。AGY 的空闲环境会在所属节点静默，本机静默路径已有移除容器的行为。见 `services/gateway/src/handler/router.rs:1860`、`services/orchestrator/main.py:14182`、`services/orchestrator/agy_environment.py:382`。
- SSH 上的 AGY 归属归档只涵盖已停止且三个容器 ID 均已清空的记录。环境列表读取工程账号 ID 为空的环境，AGY 和登录草稿均使用此类记录。见 `services/orchestrator/cluster_store.py:271`、`services/orchestrator/agy_placement.py:291`、`services/orchestrator/main.py:14596`。
- Claude 登录草稿保存成正式工程账号后，删除工程账号曾在 SSH 节点留下三个已退出容器。节点升级因无法确认归属而等待。该线上实例已经人工恢复。

## 需求与验收

- R1 所有权。网关账号与工程账号分别按实际绑定确认所有者。在本机和 SSH 两种部署，从账号管理删除 AGY，从工程账号页删除已保存的 Claude 账号。删除网关绑定后仍有有效工程所有者的环境继续供该所有者使用。独立部署中原本没有环境的账号仍可删除。
- R2 完成条件。用户只需执行一次删除。验收时检查账号页、环境列表和实际执行节点。专属 CLI、发送器、网络容器与运行期凭据副本已清理。新请求、预热与重启巡检均不会重建已删除环境。核对同节点其他账号仍可工作。
- R3 数据。保留 HOME 中的个人配置、工作区项目文件、历史请求、用量及任务记录。以文件内容及历史引用验证清理前后的一致性。后续同名新账号使用其自己的运行身份。
- R4 可靠性。现有活动按原准入和排空规则处理。删除结果可查询或重试。模拟节点断连、部分移除后重启、回包丢失、重复删除以及同名重建，验证自动续办与重复请求只处理原账号对应的资源。
- R5 升级。复现登录草稿保存、删除最后一个所有者、升级节点的完整路径。同时使用带旧容器记录的历史样本验证原升级作业可继续。归属证据不足时显示需要核对的节点和环境。

## 同批账号页修复

子任务 [反重力订阅标签](../11-24-agy-subscription-tier-badge/prd.md) 独立验证订阅档位。联合验收用同一个合成 Ultra 账号打开列表和详情，再执行删除，核对当前环境消失及其他账号仍可用。
