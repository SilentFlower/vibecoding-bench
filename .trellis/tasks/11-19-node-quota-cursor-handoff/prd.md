# 修复节点迁移后的额度、上传恢复与历史抓包缺陷

## 目标

让节点迁移及其中断恢复能够接续原操作，并保持工程／养号额度判断和历史抓包读取正确。

## 背景与已核实事实

- 用户报告养号显示“需要处理”，明确对象为账号名 `11-14`，随后要求修复。
- 2026-11-19 只读排查：账号 ID 16，分配到节点 `main`，分配版本 2；迁移账本已完成。养号自动计划开启，计划状态为 `blocked`，下一检查时间为空，原因是“API额度来源已登记另一身份或镜像”。
- 同一 API 来源的账号、身份与环境一致。数据库登记指向迁移前本机的 `environments/<环境>/flows/api/observations.jsonl`，远程镜像实际位于 `cluster-quota/<摘要>/api.jsonl`。
- `services/orchestrator/cluster_quota.py:164` 的来源键独立于执行位置；`:204` 的登记要求已有路径完全一致，导致本机转远程冲突。`services/orchestrator/main.py:3329` 的本机登记使用 INSERT OR IGNORE，回迁也会保留先前路径。
- `services/orchestrator/projects.py:379` 在计划检查异常后保存阻塞并清除下一排期。页面展示该持久事实。
- 用户追加类似迁移缺陷的排查。隔离审计复现了回迁额度停留旧值、上传中断续接受阻、历史工程抓包路由失败及旧认证错误重放，详见 `research/migration-audit.md`。现有 36 项相关回归通过，新增交接场景需要补充验证。
- 用户明确要求“都修复一下吧。在一个任务里面”。本任务统一交付原路径冲突及四项补充缺陷的修复。

## 需求

- **R1／位置衔接**：同一账号、身份及环境迁移后，额度消费位置跟随已确认的当前归属。覆盖已处于本次冲突状态的历史账号、迁回本机、再次迁出与远程节点之间迁移。
- **R2／额度保真**：保留既有窗口事实、认证门禁和已用恢复机会。位置切换、重启、重试与历史样本重读均遵守真实采样时序，禁止以游标修复清空额度、倒退较新事实或重复发放机会。
- **R3／精确交接**：自动衔接仅适用于同一账号／身份／环境的系统固定额度路径。其他账号、其他身份、未知路径、旧分配及迟到读取仍明确报错并保留现场。并发的旧消费不得覆盖新位置的读取进度。
- **R4／原工作恢复**：修复后的启动／恢复仍检查账号启停、额度、运行时段、归属与执行收口。原养号指南、项目池、计划间隔、通过记录、会话及累计预算保持；人工暂停和停止意图仍由原入口处理。
- **R5／交付与现场恢复**：交付代码、隔离回归证据及 `11-14` 的恢复操作说明。生产部署和实际恢复按项目部署流程，在可审核的制品及操作步骤就绪后执行相应授权。
- **R6／上传中断续接**：不完整上传通过“继续原迁移”取得受控的新上传尝试并完成原迁移。已完整上传但回包未知时复用原结果。保留旧部分文件、源包、迁移身份及校验记录；取消、已核验和已发布状态保持原冻结边界。
- **R7／历史抓包读取**：迁移前已结束工程的抓包可从核对后的资料位置只读访问，覆盖工程和养号两个空间、本机与远程双向迁移及再次迁移。保持实际执行历史和账号隔离。读取保持零模型调用、零环境准备。

## 验收标准

- **A1（R1、R2）**：预置与 `11-14` 同构的本机游标、原额度状态及已准备远程镜像，执行真实 QuotaGuard 消费后取得远程新样本；重复读取幂等，额度和恢复机会保持。
- **A2（R1、R2）**：本机→远程→本机→远程及远程→另一远程的连续切换均读取当前所属来源；半行、轮转、重启与镜像保存中断恢复保持原语义。
- **A3（R2、R3）**：较旧额度／认证样本重读、较新窗口、已占用恢复机会及并发迟到游标写入分别验证，最新事实与新游标得到保留。
- **A4（R3）**：账号／身份不符、未知路径、旧归属、读取中迁移及符号链接等既有拒绝场景通过；相关持久记录保持可核查。
- **A5（R4）**：两个工程空间通过既有启动／恢复与计划检查消除路径冲突；额度或人工门禁仍生效，原目标、计划配置和交付进度保持。
- **A6（R5）**：恢复说明明确原故障、部署范围、只读核对项、原恢复入口及成功判据。线上结果在实际操作后单独记录。
- **A7（R6）**：在真实临时文件中注入上传中断，沿同一迁移操作续接后完成；旧部分文件保持，当前传输尝试得到持久登记。覆盖完整上传回包未知、新尝试登记／上传后重启、取消及迟到命令拒绝。
- **A8（R7）**：两个工程空间的已结束工作在本机→远程→本机及远程→远程迁移后仍可读取抓包摘要与受限文件。错误账号、工作、环境、分配版本及路径逃逸继续拒绝。当前节点已有已迁移资料时，旧节点离线不阻断历史资料读取。
- **A9（R2）**：消费旧认证错误后，通过完整人工核验解除门禁，再改变环境代次并重读历史文件；已解除门禁保持，新真实认证错误仍可触发保护。

## 范围外

- 数据库结构和已发布迁移定义的变更。
- 新增额度查询、模型调用、额度阈值或自动重置账号身份的策略。
- 工程／养号产品合并、前端换肤及其他工作控制改造。
- 直接清空生产额度状态、批量重启账号或绕过既有部署授权。
