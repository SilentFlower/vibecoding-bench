# AGY 受管凭据与原生更新合同验证

## Goal

取得 AGY 1.5.9 在受管凭据模式下运行、换代和收尾的可复现实测合同，供账号与 API 运行环境接入使用。

## Background

- 父任务为 `../11-18-multi-platform-account-runtime/prd.md`，本任务承接 R02、R03 及 R04、R05 中与凭据相关的验证，支撑 AC03、AC04、AC05。
- 已有脱敏基线确认原生 consumer OAuth 登录、新进程复用持久登录态、Google 直连文本生成及 18 档模型目录。该基线的 HOME 含完整 AT、RT 与有效期。
- 原版执行体 SHA256 为 `39816d49d5ab92229952987225c23ea3fed7580699dcb4a444e0388e0ac1ce43`，本地原版文件复核一致。旧压缩研究制品的重建差异单独保留为未验证事项。
- 现有 CC 具有单一刷新所有者、受管 HOME 发布和有界 oauth_recovery 合同。AGY 的 AT-only、常驻凭据缓存及 Google 认证失败分类属于本轮实验对象。
- 用户已确定 AGY 与工程任务、养号执行的交互属于范围外。同形体开关按 AGY 账号独立设置，默认关闭。

## Requirements

### C01 原生凭据消费

- 分别观察有效 AT 配合 RT 缺省、空值时的启动、模型目录、文本、额度与遥测行为。
- 对过期 AT、缺失有效期、损坏文件和身份不符给出明确结果；边界故障优先使用合成凭据及离线夹具。
- 观察结果关联固定版本、原生进程和实验用例，明确区分原生行为与验证器模拟结果。

### C02 单一刷新权与发布

- 验证管理侧独占 RT，业务进程仅消费 AT 与有效期的可行机制。
- 验证到期前刷新、同账号并发串行化、AT/RT 原子持久化与代次条件提交。
- 刷新结果不确定时进入对账状态，保存当前权威凭据及恢复依据。
- 记录管理侧发布新凭据后，已运行原生进程实际读取或缓存的行为。热更新或换进程的推荐方案须有原生证据。

### C03 请求期间换代

- 关联每次尝试的账号、环境、worker、请求、尝试与凭据代次。
- 观察真实认证失败前后恢复边界，验证并发失败、旧回执和重复提交的隔离。
- 分别覆盖 SSE 已发送、工具待回填、取消、退出和重新授权，保持原调用与结果归属。
- 工具仅使用实验工作目录内的可控读写；记录真实工具执行次数和结果归属。

### C04 证据与交付

- 提供可重复的离线验证器、最小合成夹具和脱敏实验报告。
- 真实验收限既有 `agy-oauth-test-159` 测试环境及本轮私有实验副本。最多提交 8 次真实模型请求，每次最多等待 120 秒；达到上限后记录待验证项并停止真实调用。
- 各项结果使用“已验证支持”“已验证限制”“待验证”区分，分别列出原生证据、模拟证据和推荐接入方案。
- 原始凭据和包含秘密的观察材料仅保存于受限私有目录，仓库只保存脱敏摘要。

## Acceptance Criteria

- [x] CA01：固定原版哈希、实验进程、隔离 HOME 与每项结果可关联，原生基线与研究制品分别标识。（C01、C04）
- [x] CA02：AT-only、凭据文件替换、缓存读取和可用更新机制有原生结果；发现原生限制时明确影响及后续接入门槛。（C01、C02）
- [x] CA03：离线夹具覆盖并发刷新、RT 轮换、旧代 CAS、响应丢失、坏文件和重启恢复，当前权威凭据保持一致。（C02）
- [x] CA04：认证失败、SSE、工具等待及取消/退出形成逐场景结果，记录实际发送次数和终态；模拟结果与真实结果分别标识。（C03）
- [x] CA05：原生真实发送与私有凭据代次的关联有脱敏依据；工具副作用次数、遥测及停止排空有观察结果。（C02、C03、C04）
- [x] CA06：后续账号、运行环境和请求记录子任务取得同一份接入合同；所有待验证项逐项列明，涉及产品取舍时返回父任务收敛。（C04）

## Non-Goals

- 正式账号平台迁移、生产凭据迁移、生产部署和 new-api 渠道变更。
- 工程任务、养号执行及其与 AGY 的交互。
- 正式 Gemini API 路由、账号设置 UI、请求记录 UI 和同形体文本处理的实现。
- 将合成协议服务器的结果作为 Google 真实认证行为的结论。

## Dependencies

- 既有原生 OAuth 直连基线、固定 1.5.9 原版执行体与可访问的私有测试账号环境。
- 测试环境在实时实验前核对身份、占用和当前凭据状态。访问条件缺失的用例记录为待验证，离线实验可独立推进。

## 验收证据

CA01—CA06 的原生实测、离线参考模型及逐项待验证边界见 `research/credential-contract.md`。本任务交付研究合同，后续产品接入门槛按合同分配到依赖子任务。
