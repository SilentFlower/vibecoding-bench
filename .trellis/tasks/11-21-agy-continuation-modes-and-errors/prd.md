# 反重力工具续轮模式与请求失败修复

## Goal

让 Flower2API 的反重力运行环境可选择工具续轮模式，修复后台摘要冲突、AstrBot 空流与已提交工具回填的归属及重读故障。

## Requirements

- 在「运行环境 → 请求内核」按环境提供「工具续轮模式」。默认「领取续轮」，另有「历史续轮」和「领取优先，历史兜底」。设置保存后由新派发的请求读取。已经发给客户端的工具批次继续使用发出时的策略。
- 「领取续轮」由首次匹配的真实回填完成原生工具轮，再生成下一步。「历史续轮」允许原生工具轮在客户端执行工具期间提前收口，收到真实回填后从完整历史生成下一步。三种策略都核对原会话、请求归属、工具调用、签名和实际结果。同一回填的重试应复用原结果。
- 「领取优先，历史兜底」先使用领取路径。领取无法完成后，旧工具轮已确认结束、下一轮明确尚待提交、当前请求及工具批次仍在有效期内且归属校验通过时，可以使用历史接续。相同回填并发或重试共用一次提交。提交结果不明时按原期限核对状态。批次已过期、归属冲突或执行权限失效时，返回对应错误。
- 依赖当前 WebSearch 回调绑定的批次采用领取续轮。请求诊断展示配置策略、实际续轮路径及切换原因。旧配置默认为领取，包含历史续轮的选项仅在当前环境的执行链支持时可用。
- 匹配已核对的 Claude Code 后台动作摘要请求时应给出简短可读状态。主回填与摘要并发时，按主回填原有归属和有效期处理。普通用户追加文字继续参与正常生成。过期、归属不唯一、冲突结果和越权仍有明确错误。
- **修复内核提前收尾。** AGY 接收通道关闭且源终态缺失时，在原请求剩余时间内等待控制结果。将接收结束、源终态和原生控制状态分别记录，保留实际控制状态码与脱敏错误类别。
- **修复网关提前返回 HTTP 200。** 仅收到用量帧时先累计用量。收到可交付内容、完整工具批次或可公开的明确终态才开流。首块有效内容前失败返回 Messages HTTP 错误，开流后使用 SSE 错误。保持正常文本、工具、用量、拒绝和重读行为。
- 复验 Flower2API 直连和经 New API 转发的 AstrBot Messages。代码范围按 Flower2API 规划。New API 在已发送保活或内容后仍将错误写成普通 JSON 时，需要转发层修复才能让客户端收到 SSE 错误。
- 主模型已完整结束后，经过核验的独立原生调用保留自身帧归属。完整的主工具调用和真实轨迹继续可交付。无法校验主帧、主会话冲突、取消或真实控制失败仍交付对应错误。
- 已交付到发送边界的工具回填在响应窗口结束后仍保留轻量回执。经鉴权的同一回填跨流式与非流式重试仍关联原尝试，读取原失败或明确的响应过期。并发或重试保持一次提交。自动再次发送仅接受可信的尚未提交证明。

- 原版 AGY 1.5.9 回环复现了同一用量帧后的两种收尾。完整 HTTP 响应缺模型结束帧时原生控制返回 200，HTTP 数据块截断时返回 500 和 `unexpected EOF`。控制结果晚到时，旧逻辑都记为 `native_stream_incomplete.unknown`。两个失败在公开网关上也都提前提交了 HTTP 200。[原生收尾排查](research/agy-native-stream-eof.md)

## Acceptance Criteria

- [ ] 两个环境分别保存和读取三种策略。旧配置、新环境默认领取。切换时已发出的工具批次按各自策略完成，并可从诊断确认。已有 WebSearch 回调完整工作。
- [ ] 两种 400 的摘要样本在主回填前、领取中、已提交后都得到可用摘要，真实回填只触发一次生成。同一提示的近似请求、普通追加文本、错 ID 和越权请求继续走各自正常校验。
- [ ] 隔离的原版内核回环确认历史模式下原生旧轮实际关闭，随后从完整历史完成下一轮。并行及同名工具、签名、缓存前缀、重试去重和提前收口失败均有验证证据。
- [ ] 领取优先策略在旧轮正常时完成领取。旧轮已证实关闭且续轮尚待提交时，使用完整历史续轮，触发一次模型生成。同一回填并发或重试复用结果。状态未知、旧关闭回执归属不符、真实到期、冲突正文、授权撤销及下一轮已提交均通过校验。
- [ ] 延迟交付控制结果时，完整 HTTP 响应缺模型结束帧和 HTTP 数据块截断能分别识别为控制 200 且源流不完整、控制 500 且响应读取中断。验证原请求截止、取消和真实源 429。
- [ ] 上述两种异常在只有用量帧时得到明确的 Messages 非 2xx HTTP 错误。有效内容之后失败得到 SSE `error`。新请求和重读使用相同规则，正常用量、文本、工具及拒绝通过回归。
- [ ] 对比原版内核回环下直接领取与直接历史的旧轮收口耗时、回填到可用首块的耗时和出站缓存前缀，记录兜底发生时回填到可用首块的耗时。结合 New API 两种保活状态的结果给出转发边界。
- [x] 原版 AGY 1.5.9 隔离回环验证主调用 STOP 后出现两次额外调用时的原始帧归属、完整工具批次与同轨迹回填。覆盖并发 SDK 帧、缺会话 ID 与真实错归属，核对主调用只计一次。
- [x] 同一回填在并发、120 秒响应回收后均关联原尝试。成功响应过期时返回明确的过期错误。真实失败保留原终态。错会话、错令牌、撤销账号范围及冲突结果按实际校验拒绝。核对三种续轮方式和真实模型提交次数。
