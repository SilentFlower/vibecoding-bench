# Brief — 原生页视觉对齐

## Goal

- 让「任务与工程」和「运行环境」两页换上第二版 token 与组件样式，外观与其余页面一致，并跟随用户保存的主题；业务行为不变。

## Scope

- **运行环境页**：
  - 工具栏：分段筛选、计数和搜索放在同一行。
  - 卡片改实体卡：平台图标块、带圆点的状态徽标；三组件状态改为托盘分段；资源四格；预热块按预热状态着色；四等分操作栏。
  - 环境管理侧抽屉及其分区。
- **任务与工程页面骨架**：页头去掉分组名；六个页签改为带图标的分段，「任务账号」显示账号数；各区块头改为一行。
- **任务账号卡片**：外壳、头部、徽标、节点块、键值行与其余实体卡一致；网关状态改为语义提示条；底部 7 个按钮改为等分操作栏。
- **其余五个页签、原生控件、19 个原生弹窗容器、3 个 Vue 弹窗**：统一外观，宽度与结构不变。
  - 原生弹窗包括任务账号配置、运行配置、账号详情 / 额度、交付、工程研究、抓包等；其中登录和环境工作区只在独立入口使用。
  - Vue 弹窗为运行详情、代理切换、抓包工作区。
- **旧样式清理**：
  - 范围：legacy 7 份 CSS（约 3,700 行）、`native-environment.css`，以及几个 Vue 组件的样式块。
  - 删除旧变量定义块和约 400 条无效规则；颜色与圆角全部改为取 `--ui-*`；终端容器改取墨色 token。
  - 两份图标 sprite 补齐并保持一致。
- **独立 `/runtime/` 入口**：随共享样式换成默认主题；静态版本参数同步。
- **验证与规范**：
  - 新增两页设计稿比对与主题跟随验证脚本；静态样式规则覆盖本页文件。
  - 迁移 6 个对旧原型做比对的脚本；修好子任务 4 移交的 4 个失败脚本。
  - 更新原生组件规范与 `ui-guidelines.md`。

## Non-Goals

- 原生页功能变化，包括弹窗宽度与交互；把原生模块改写为 Vue。
- 设计稿画了但产品没有数据的「运行中 / 空闲」卡片状态和「最近同步」时间，不新增。
- xterm 配色、任务页宿主 `data-theme` 跟随与深色模式，由子任务 7 负责。
- 独立入口的环境页签按新稿重排。

## Technical Overview

- **任务与工程**：原生模块在 Vue 文档内挂载，CSS 构建时加 `.task-runtime` 作用域，能继承根上的 `--ui-*`。所以原生 CSS 改成只引用 token 后，用户主题会直接生效。
- **原生部件与组件库对应**：按钮、输入、选择、数字、时间、页签、徽标、提示条、表格、卡片、弹窗，各自按 `kit.css` 同名部件取同一组 token 和尺寸。
- **改写顺序**：
  1. 先删无效规则，用迁移前后截图像素零差证明没有视觉变化。
  2. 再做 token 化：生成调色板映射，静态规则全部通过。
  3. 最后按设计稿逐区域重排。
- **运行环境**：本身是 Vue 页，直接换用 `Toolbar`、`Segmented`、`EntityCard` 系列与 `Badge`，样式文件改为 `@layer components`、只取 token。新增 `preparationTone(row)` 决定预热块颜色。
- **独立 `/runtime/` 入口**：读取同一组 legacy CSS 和 `ui-foundation.css` 的默认值，自动显示第二版默认主题。只有合并删除文件时，才同步桥接白名单及其测试。

## Context & Decisions

- 设计稿 `mock.html` 只画了 1440 下的「任务账号」页签和环境卡片列表。产品比设计稿多出的功能（养号按钮、登录草稿、网关创建与关联、凭据交接对账、环境抽屉、AGY 文案等）全部保留，只统一外观。
- **【关键决定】一次交付，不拆子任务（你已确认）。单次改动很大，用两个回滚点控制风险：删无效规则后截图像素零差，token 化后静态规则通过。**
- **【关键决定】原生模板保留原类名，原生 CSS 按组件库同名部件的规格重写，不在原生模板里改用 `.fui-*` 类。原因有两条：独立入口读不到组件库样式；约 125 处 `.btn` 和大量验证脚本依赖原类名。代价是原生与组件库各有一份样式声明，靠新验证脚本在同一页上比对计算样式来保持一致。**
- **【关键决定】任务账号卡底部的 7 个按钮（整体停用 / 启用、收尾进度、CLI 配置、额度、养号 / 额度设置、运行时段、删除）全部保留。设计稿没画，第二版又已撤回「⋯」菜单，所以改为等分操作栏，放不下时换行，「删除」用危险色。**
- **【关键决定】网关提示条按现有数据着色：凭据异常为红色并显示原因，同区保留「重新授权并同步 / 解绑」；手动更新额度为蓝色；其余为中性提示。**
- **【关键决定】「任务账号」页签显示账号数（设计稿有）：读取完成前和读取失败时不显示。续聊弹窗标题「run / continue」改为「继续运行」；原生弹窗的终端风角框、扫描线等装饰删除。**
- **【关键决定】运行环境的预热块改按预热状态着色：就绪绿、失败琥珀、其余灰。这修正了现状「环境就绪但准备状态待核对」时仍显示绿色的矛盾。**
- **【关键决定】删除旧原型生成器 `extract_environment_styles.py`。它会把旧原型样式写回 `environment-design.css`，再运行就会覆盖本次迁移。**
- **【重要限制】两页没有 390 设计稿，任务页深层弹窗也没有设计稿。390 按账号移动稿和已迁页面的规则推导，弹窗按通用弹窗规格统一，结果用截图给你目视确认。**
- **【重要限制】独立 `/runtime/` 入口只显示默认主题，读不到你保存的主题。它的环境页签只换成 token 取值，不按新稿重排。**
- **【重要限制】子任务 7 之前，终端仍保持深色、xterm 自身配色不动，任务页宿主仍固定浅色。**

## Risks

- **【交付风险】原生弹窗多且没有设计稿，原生 CSS 又不分层，原生的通用规则可能误伤挂进原生宿主的 Vue 控件（选线弹层、分页、代理气泡）。应对：每改一类弹窗就跑对应的行为脚本，再由部件一致性比对兜底；发现误伤时收窄原生选择器，不给 Vue 组件加覆盖。**
- 判定无效规则时，可能误删动态拼接的类名。迁移前后截图的像素比对会发现，有差异就恢复该条规则。

## Acceptance

- 两页 1440×900 与设计稿逐项比对无差异，白名单逐条注明原因。390×844 单列、无横向溢出。深层弹窗 1440 与 390 截图外观统一。
- 主题设置保存非默认主题后，两页和深层弹窗的主色、圆角、字号随之变化；独立 `/runtime/` 显示默认主题。
- 静态规则：legacy CSS、`native-environment.css` 与本页 Vue 组件中，除 token 定义外没有颜色字面量，圆角只取 token，旧变量定义块清零。
- 原生页既有行为验证全部通过，移交的 4 个失败修好；回归只剩 3 个已登记失败，失败点不变；真实桥接路径可加载全部原生资源。
- 原生组件规范与 `ui-guidelines.md` 已同步。
