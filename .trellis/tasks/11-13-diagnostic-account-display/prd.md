# 请求记录展示账号名称与邮箱

## Goal

通过真实账号名称与邮箱识别请求及其重试实际使用的账号。

## Background

- apps/web/src/components/RequestDiagnostics.vue:300,301,318,320,324,327,333 在手机、桌面及详情各处显示数字 ID。
- services/gateway/src/store/diagnostics_store.rs:223,258 从持久 JSON 读取请求与尝试，记录保留实际账号 ID。
- apps/web/src/api.ts:41 的完整 Account 含凭据，完整账号分页接口返回此管理对象。

## Requirements

- R1：列表、概览、链路、性能和尝试选择器优先显示名称邮箱，桌面与手机保持可读。
- R2：每次重试按实际账号关联；资料采用读取时当前名称与邮箱。
- R3：资料缺失、已删除或旧服务缺扩展字段时明确提示并保留 ID 追溯；未选账号时显示“未知账号”。
- R4：ID 的过滤、关联、采集与环境直达保持；新增读取只查询必要安全字段。
- R5：旧记录、分页、过滤、排序、保留期和错误处理保持兼容。

## Acceptance Criteria

- AC1 → R1：桌面与 390px 列表及详情各入口显示名称邮箱，长文本可读。
- AC2 → R2：跨两个账号重试分别匹配实际资料，改名后显示当前资料。
- AC3 → R3/R5：删除、空名称、空邮箱、旧 JSON/响应、account_id=null 均有明确降级。
- AC4 → R4：公开扩展仅含名称邮箱，过滤和环境跳转仍命中原 ID，列表不逐行调用完整账号 API。
- AC5 → R5：保留期、关联 ID、跨账号筛选与详情异步取消回归通过。

## Out of Scope

凭据展示、名称搜索、历史名称快照、数据库结构迁移、线上数据修改。
