# Antigravity 重授权代理选择与凭据交接

## 目标

让已有 Antigravity 账号在「重新授权」中选择本次使用的代理，并在授权成功后应用到原账号。

## 要求

- R1，页面。原账号继续固定为 Antigravity，代理栏默认显示当前已保存的实际线路或直连，允许搜索代理目录及选择直连。保持现有代理时无需再选。截图中直连来自 `Accounts.vue:1198,1632` 的默认值，实际提交取原账号线路。
- R2，生效。链接生成、授权交换与 AT-only 身份核验使用同一次冻结的线路。授权成功且账号一致时，原账号一次保存经核验的凭据与线路。取消、过期、生成或核验失败时保持原账号配置。
- R3，操作完整性。保留同账号身份、代次及原操作检查。代理修订过期、并发切换、迁移、失联、重启或迟到结果使用已有冲突和对账边界。目录认证与 OAuth 凭据按原私有协议处理。
- R4，兼容。原线路的历史调用继续工作。新建 Antigravity、Claude Code OAuth 与 Setup Token 入口保留原行为。

## 验收

| 要求 | 可观测结果 |
| --- | --- |
| R1 | 原目录代理、自定义代理或直连显示准确。用户能在原弹窗选线或改为直连。 |
| R2 | 合成授权用候选代理穿过生成、交换、核验、持久提交。取消、错邮箱和错误代理保留既有凭据与配置。 |
| R3 | 重复回执、迟到回执、目录变更、已有迁移与进程重启后原操作恢复不会写入错账号、错线路或旧凭据。 |
| R4 | 既有调用和其他授权入口的现有用法通过回归。 |
