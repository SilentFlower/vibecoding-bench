# 账号页迁移

## Goal

把账号管理页（卡片、工具栏、账号工作区与授权登录弹窗）换用新组件与第二版视觉，字段、顺序与业务行为不变。上级需求见 `../11-19-console-ui-pages/prd.md`，画面见 `doc/design/console-v2/mock.html` 的 `#accounts`、`#account-edit`、`#mobile`。

## Background

- **页面**：`apps/web/src/components/Accounts.vue`（1620 行）。页头已由子任务 2 换成 `PageHeader`，其余部分仍是旧样式。
  - 工具栏 `.account-toolbar`：平台筛选（`ChoiceSelect`）、自绘状态分段 `.account-filter-tabs`（4 项带计数）、`SearchInput`。
  - 卡片 `Card.account-card`，自上而下：头像与名称、接收请求开关与停用 / 启用按钮、代理 / 节点 / 运行环境链接、整体状态、健康条与「排队 N」、提示段落、转发方式与调度、用量窗口（反重力为平台额度）、实时指标、停用 / 限流原因、五个操作。
  - 空状态为 Tailwind 工具类拼成的居中块；分页 `Pagination`。
- **账号工作区**：现在是右侧抽屉（`DialogContent.account-workspace`，`style.css:284` 用 `!important` 定位），概览 / 环境为 470px，配置 / 调度为 860px。四个页签是自绘按钮；反重力账号无「调度」；新建账号不显示页签。
  - 设计稿 `#account-edit` 画的是 820px 居中弹窗：头像 + 名称 + 平台与套餐徽标、邮箱、关闭按钮；分段页签（「调度」带计数）；配置页分「基础配置」「用量与调度」等区，转发方式为单选卡；通栏底栏「修改后统一保存 / 取消 / 保存修改」。只画了配置页。
  - `Proxies.vue`、`TasksWorkspace.vue` 用 `workspace-account-id` 嵌入同一组件，只渲染工作区。
- **其它弹窗**：授权登录（三步：生成链接 / 填授权码 / 完成）、删除确认（`ConfirmationDialog`）。
- **子组件**：`AgyAccountUsage`、`AgyQuotaRow`、`UsageWindowStats`（费用气泡）、`SchedulingDetails`（调度页签，含 SVG 时间轴）、`ProxyPicker`、`PlatformBadge`、`runtime/ExecutionNodeBadge`。
- **写死样式**：
  - `Accounts.vue` 45 处 Tailwind 调色板类（15 处在 `statusStyle()` 未使用的 `.class` 里）、5 处 `rounded-*`；`lib/subscription.ts` 的 `usageBarColor()` 返回调色板类，再由 `style.css:242-244` 重映射成十六进制。
  - 子组件：`SchedulingDetails` 9 个十六进制与 5 处调色板类，`PlatformBadge` 9 个十六进制。
  - 全局未分层规则：`style.css` 约 248 条（145 个十六进制、29 个 `!important`），`approved-design.css` 约 161 条（82 个十六进制）。它们压过 `@layer components` 的新组件样式，另有 7 个已无引用的死选择器。
- **移动端现状**：≤760px 卡片单列；≤600px 工具栏改为两行网格；五个操作与四格指标不换行；应用栏没有搜索入口；抽屉固定在右侧。

## Requirements

- **卡片**（`#accounts`）：
  - 字段、顺序、接收请求开关、停用 / 启用账号按钮与五个操作（编辑、用量、测试、详情、删除）不变。
  - 头部：40px 头像（Claude Code / 反重力两种底色）带状态点，名称后接平台与套餐徽标，下行为邮箱。
  - 健康条按语义着色：正常为成功色，限流 / 短冷却 / 调度错误为警示色，异常与认证错误为危险色，已停用为中性色；「排队 N」保留在条内右侧并可点击。认证错误与异常状态现在分别显示为警示色和默认绿色，这是本次唯一的状态语义变化。
  - 转发方式与调度优先级放在浅灰信息块内，智能评分为徽标。
  - 用量窗口、实时指标按设计稿排版；进度条颜色按现有阈值取语义色。
  - 停用 / 限流原因、认证错误等提示改为提示条（`NoticeStrip`）。
  - 1440×900 下首行三张卡片的操作栏落在首屏内。
- **工具栏**：平台筛选、带计数的状态分段、靠右的搜索框，用 `Toolbar` 与 `Segmented`。
- **账号工作区**改为设计稿的 820px 居中弹窗（`ModalDialog`）：
  - 头部为头像、名称、平台与套餐徽标、邮箱；四个页签用分段控件，「调度」在有排队时显示排队数。反重力隐藏「调度」、新建账号不显示页签的规则不变。
  - 四个页签同宽（现在为 470 / 860 两档），切换时弹窗不跳动；头部与页签带固定，只有正文滚动。
  - 配置页按设计稿分区与字段网格排版，转发方式用单选卡（`RadioCardGroup`），底栏通栏。其余页签（概览、调度、环境与诊断）按同一视觉语言排版，内容一项不少。
  - 草稿、校验、取消与保存语义不变；从代理管理、任务与工程嵌入时行为不变。
- **授权登录弹窗**：换用居中弹窗与新控件，三步流程、字段与按钮不变。删除确认沿用 `ConfirmationDialog`。
- **空状态**：用 `Empty` 组件。
- **390×844**（`#mobile`）：
  - 卡片单列，五个操作与四格指标在窄屏下不溢出。
  - 状态分段使用短标签（全部 / 正常 / 关注 / 已停用）并带计数。
  - 应用栏在账号页显示搜索按钮，点击展开搜索行（平台筛选与搜索框）；搜索词非空或平台不是「全部平台」时保持展开，避免隐藏生效中的筛选；其它页面不显示。
  - 工作区弹窗在窄屏占满可用宽度，正文单列。
- **组件扩展**：
  - `ModalDialog` 增加不随内容滚动的页签带，同步演示页。
  - 外壳应用栏增加页面操作位，账号页的搜索按钮放在这里。
  - 账号卡与设计稿 `.ent` 实体卡的尺寸不同，名称区又是打开详情的按钮，所以不套用 `EntityCard`，用卡片容器加原子组件排版。实体卡的首个真实使用留给节点管理与运行环境。
- **网格**：列规则不变（最小 320px，≤760px 单列，≥1680px 四列），间距按设计稿由 18px 改为 16px。
- **样式清理**：账号页及其子组件的颜色与圆角全部取 token；被替代的旧规则从 `style.css`、`approved-design.css` 删除，含死选择器与 `statusStyle()` 中未使用的调色板类。

## Acceptance Criteria

- [ ] 1440×900 下卡片、工具栏、工作区配置页与设计稿 `#accounts`、`#account-edit` 逐项一致（结构写法不同但视觉等价处列白名单并注明原因），首行三张卡片的操作栏在首屏内，附截图。
- [ ] 390×844 下与 `#mobile` 一致，搜索按钮可展开搜索行并完成搜索，页面无横向溢出，附截图。
- [ ] 工作区的概览、调度、环境与诊断页签，以及授权登录三步、删除确认，在 1440 与 390 下有截图供目视确认（设计稿未画）。
- [ ] 业务行为不变：字段保存与取消、分页、OAuth、调度筛选、费用气泡、接收请求开关、停用 / 启用、排队入口、嵌入工作区等既有浏览器验证（`verify_accounts_design.py`、`verify_account_queue_layout.py` 等）按新视觉更新期望后通过，业务断言不放宽。
- [ ] 账号页及其子组件不再写死颜色与圆角；被替代的旧规则已删除，`style.css`、`approved-design.css` 中账号相关的 `!important` 清零。
- [ ] 前端构建通过，`theme.test.mjs` 通过，控制台无新增报错。
