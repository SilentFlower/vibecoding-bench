# V2 后台子代理与请求详情

### 后台子代理

父回复还在输出时，V2 收到完整的 Agent 工具调用就登记派工。归属明确即可启动。确需等启动回执时，原请求在已有期限内等待，主代理继续输出。重试带上的定向 SendMessage 原样交付，同一任务只执行一次。

### 请求头详情

沿用 V1 的动作标签、颜色、汇总和筛选，并列展示「入口、提交、最终 TLS」。新调试记录显示实际处理原因。旧记录标明可观测的差异，缺失或截断的阶段显示未知。

### 联合验收

用真实 CC、网关、账号发送器和隔离上游重现这次约 14 秒的先后顺序，以及追加消息、同提示兄弟和取消。再用真实浏览器核对三阶段请求头、新旧记录、脱敏和三个屏宽。两项在同一候选上验收。
