# 联合设计

发布基线为 flower2api 的 `177e2327`，对应 v1.38.0 已签发源码 `d7cc8406` 后的任务记录提交。主工作区有其他事项的改动，产品实现在上述基线的独立检出中完成。

## 分工

- `11-25-v2-agent-block-handoff` 管理消息流上的父工具登记、子代理等待与认领、已归属消息和取消。
- `11-25-v2-header-decision-details` 管理头部实际处理动作、私有快照、编排读取及管理页。
- 父任务负责发布基线复现和联合验收。一次后台派工成功后，经同次 request 和 attempt 打开管理页，核对入口、受管提交及真实回环上游收到的请求。提交前拒绝仍归入入口诊断。两项工作在同一候选汇总。

## 证据边界

用合成提示、虚构账号和无外网的 HTTPS 上游做回归。线上故障只记录时序、内容长度、字段与相等关系。握手能力、账号绑定、TLS 客户端、已有缓存和原模型提交语义沿现有合同运行。
