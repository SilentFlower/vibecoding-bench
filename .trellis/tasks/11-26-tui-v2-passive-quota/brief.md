# 修复 V2 请求后的官方额度更新

## 目标

- 受管 Claude 账号完成 V2 请求后，账号页显示该账号新观测到的 5 小时和 7 天额度百分比。

## 范围

- 采集受管 V2 的流式、非流式、工具续轮及上游 429 中的官方窗口，涵盖 Fable 专属周额度。

## 范围外事项

- 主动查询策略、页面设计和上线操作沿各自现行流程。

## 技术方案

- 事件源从实际模型响应提取额度头，通过账号发送器传给网关。网关使用现有的窗口合并逻辑写入本次请求的账号。账号页下次轮询读取新值。

## 关键决定

- **【关键决定】使用本次模型请求的实际响应采集额度。每次请求新增的 OAuth usage 查询数为零。**
- **【重要限制】上游提供完整有效的窗口时才更新该窗口。缺失或无效的窗口保留原观察。**
- **【重要限制】自动更新需要运行中的发送器和网关均支持额度回传。旧发送器仍可交付模型响应。**

## 验收

- 用回环上游返回已知百分比，在公开 V2 Messages 和账号列表核对同一账号的额度与重置时间。覆盖两种响应格式、工具续轮和真实 429。
- 核对其他账号隔离、旧发送器兼容、模型单次提交和 Token 用量统计。
