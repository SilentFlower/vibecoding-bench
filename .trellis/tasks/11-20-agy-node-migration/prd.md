# 反重力账号支持节点迁移

## 目标

管理员可以通过节点管理迁移已有运行环境的反重力账号，迁移完成后由目标节点处理网关请求。

## 现状

反重力账号已经可在节点管理中选中。当前界面固定显示本机，反重力账号不会读取迁移归属状态。入口见 `apps/web/src/components/runtime/AccountNodeSelector.vue:18` 和 `:35`。编排器的 AGY 传输同样直接解析本机，网关 AGY 账号和任务账号分别登记。

## 要求

- 沿用现有节点管理的迁移、继续和取消入口。迁移对象为已绑定运行环境的 AGY 网关账号，保留源账号身份、代理、接单偏好与支持迁移的资料。
- 源端关闭新接单后，让已接单请求和工具回填沿原窗口收尾。工具回填窗口最长 1 小时，管理员可取消仍在排空的迁移。目标准备完毕并核验归属后，才接收新请求。
- 目标节点接续[并发热更新](../11-20-agy-live-concurrency/prd.md)保存的有效上限，并支持同一调整入口。当前节点和每次请求实际执行位置分别取当前归属和原尝试记录。

## 验收

- 节点管理显示真实当前节点和符合条件的目标节点，可从本机迁到远程并迁回。
- 完成后发一条请求，确认由目标节点实际执行。账号卡片、运行环境和新请求记录展示同一归属，历史请求保留原执行位置。
- 在中断、取消及恢复场景中，账号身份、凭据、代理配置、可迁移资料和接单设置得到保留。同一账号始终由唯一归属执行。
- 覆盖源端请求或工具回填未收尾、目标制品或资源不兼容、以及提交前取消和提交后重启接续。目标节点重新准备自己的热进程和 CRIU 模板。
