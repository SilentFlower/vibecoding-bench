# 反重力账号节点迁移实施

1. 梳理已存在的 AGY 平台环境表、网关配置、集群归属和迁移记录。给平台专用环境接入已有迁移阶段与版本比较，覆盖历史本机环境和数字 ID 重叠的任务账号。核对中央重启、节点暂停和未收口迁移的准入。
2. 复用原节点 Agent、私有传输和迁移归档。接入 AGY 角色布局和受管凭据的源端排空、资料校验、目标准备、激活及撤销。收口与应用节点按原操作回执核对。
3. 接通 AGY 请求、工具续接、预热、采集和环境操作的真实节点解析。节点管理页复用迁移交互和可恢复状态，账号、环境和请求记录展示各自真实执行位置。
4. 补充集群和 AGY 定向回归，覆盖请求在途、工具等待、输入版本漂移、目标准备失败、取消、控制重启及旧账号兼容。跑编排、网关和前端关联测试。
5. 在隔离部署用真实 AGY 发送器、合成上游和受支持的远程节点验收。本机 3→4、迁出并请求、远程 4→3、迁回并请求。核对实际发包、模型只提交一次、原账号身份、历史请求位置，验证迁移前后正常启动及 CRIU 恢复。
