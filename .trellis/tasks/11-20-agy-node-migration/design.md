# 反重力账号节点迁移设计

## 账号和节点归属

- `platform_api_environments` 关联 AGY 网关账号和 API 专用环境。现有 `account_node_assignments`、`node_migrations` 使用任务账号外键，数字可能与网关账号 ID 重合。扩展集群持久归属与迁移记录时核对平台、网关 ID、环境 ID 和分配版本，历史任务账号路径继续使用其原外键。
- 将集群迁移已有的阶段推进、归属比较写入、私有归档和中断恢复复用于 AGY。由平台各自解析账号、环境和受限准备操作。已登记的老 AGY 环境缺省归属本机，准备或只读查询无需创建任务账号。
- 编排库通过 `bench.agy-nodes.6` 增加 `agy_node_assignments` 和 `agy_node_migrations`。网关账号归属通过 `/api/agy-accounts/{id}/node` 查询，迁移沿同账号的 `node-migrations` 资源提交。节点 Agent 按原固定通道核对 AGY 环境代次。

## 排空和切换

- 沿现有受信节点通道和账号租约完成目标能力、真实镜像、环境身份和资源预算预检。源端记住原接单偏好，停止受理新请求，原请求及工具回填留在原进程，核对实际收尾后冻结源环境。
- 沿原迁移归档校验搬运可迁移资料，并按 AGY 实际文件归属建立白名单。短期令牌副本、旧发送绑定、运行进程和 CRIU 模板由目标从当前权威配置准备。网关保有原凭据刷新权，目标沿 AGY 受管凭据接口取执行所需的短期凭据。
- 目标持有同一逻辑环境身份和新的实际代次，核验原账号、代理、资源布局与并发上限。按同一原操作比较写入分配版本，确认激活后重新开放准入。提交前取消先撤销目标准备，再恢复源；提交后继续确认原目标，避免两端同时接单。
- 执行入口从权威归属选择本机或既有集群传输。核对账号、环境、代次和分配版本，流式、取消、工具回填以及采集沿对应节点。并发修改和环境维护同样按归属路由，迁移期间的调用根据原操作阶段核对。
- 并发变更与迁移按同一账号和当前归属校验。已有容量操作在源端收口，目标按网关已保存的并发上限准备。原代次的容量回执由源端核对。
- 账号与环境摘要取当前节点。请求记录保存本次实际传输中的执行位置。旧记录仍按其已记录的节点查询。
- 排空期间取消直接解除原门禁并保留源进程。源已隔离时沿持久阶段核对目标撤销及源恢复。归档包含已核对的工程资料、CPU 策略、脱敏采集和当前选中内核制品。
- 现有节点组件换批作业按 CC 环境恢复。节点承载 AGY 期间保留原执行组件。平台更新及回退预检同时核对远程 AGY 归属和未完成迁移，迁回本机并收口原操作后可继续换批。
- 远程代理修改和账号删除沿原网关配置许可静默当前角色。网关确认账号已删除后，在后台按零角色的停止代次归档归属，保留节点位置、资料和迁移历史。已归档归属退出节点接单计数和组件维护阻断。
