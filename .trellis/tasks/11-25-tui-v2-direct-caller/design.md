# V2 工具回执匹配

`images/account/tui_session.py` 先按账号、环境、代次、主体和会话定位等待中的进程，再把原历史摘要及已登记响应交给 `tool_receipts`。`WireStep.observe` 按实际响应收集工具块。`images/account/tui_messages.py` 当前将客户端工具块快照与已登记块整组比较。

在这次比较中，只有已登记的块为 `tool_use`、原顶层 `caller` 精确等于直接调用对象且回传确实省略该键时，允许两种表示匹配。继续使用原有字段比较和 ID 集合校验。明确的 null、其他来源、额外属性、嵌套业务参数等分别遵循现有规则。比较使用临时视图，不改客户端请求、已登记块或传给模型的正文。

`services/gateway/src/service/tui_tool_history.rs` 在无显式会话时用历史摘要及工具 ID、名称、参数定位原轮，Sender 继续核对原始响应。用真实连续回填覆盖历史进入下一轮摘要的情况，优先复用原摘要格式、已有记录及在途状态。仅在合法样本确实受阻时调整对应比较位置并核对旧记录。失败输入仍在投递前拒绝。
