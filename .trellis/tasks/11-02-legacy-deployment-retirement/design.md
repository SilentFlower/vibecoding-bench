## 精确删除

1. 冻结私有 plan.json：容器 ID/名称/镜像/启动时间，目标镜像所有标签与 digest、所有容器引用、数据目录 realpath、卷名、当前 v3 配置哈希与磁盘可用字节。
2. 核对旧容器所属 Compose project/服务和挂载。等待在途工作结束，仅停止精确目标后普通 docker rm，不用强制模式；复核无新旧 worker 再继续。
3. 对 bind 路径校验固定父目录、非链接、无嵌套宿主挂载、无任何其他容器的父子挂载引用。只删除固定目标，递归操作不跟随链接；拒绝动态宽前缀或整个源码父目录。
4. 对旧 gateway 卷重查所有容器（含停止的）引用后执行精确 docker volume rm；不能手动清 /var/lib/docker 下层数据。
5. 旧镜像只在无任何容器和保护引用、所有别名来源明确时逐个移除精确标签及匹配 digest。不 force、不 prune；当前 v3 与最近两套完整历史发布、其他应用和未知引用保持。
6. 将只读盘点证明为旧部署的既有备份、暂存及 `.env` 历史副本纳入固定路径清单；校验无 v3 标记、无共享引用与嵌套挂载。用户选择不归档，既不新建备份，也不留下已确认的旧凭据/历史副本。未知文件保留。
7. 每项完成立即写无秘密收据，失败保留已完成事实及剩余清单，不扩大范围。
