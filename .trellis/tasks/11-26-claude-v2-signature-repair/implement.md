## 验收证据

- 隔离回环运行实际 Gateway、节点中继、账号发送器和固定 Claude Code 2.1.293。合成 HTTPS 上游确认普通与原生的流式和 JSON 均可完成 `400 → 200`。工具续轮只认领一次，同进程重发相同工具结果。再次 400 时交付第二次错误。成功会话预清理后首发一次。无真实会话、新历史或此前恢复失败的请求各自判定。
- 回环收包核对原账号凭据、模型、会话、Content-Length 和新版 CCH。受管发送器的实际响应证据与公开请求诊断逐条匹配，状态为 400、200，尝试 ID 各异。
- 普通 400、错误正文截断、提交未知、SSE 内错误、旧中继、未宣告恢复能力的来源及二次准入耗尽均只有一次模型 POST。二次准入耗尽和旧中继保留首个 400。取消、跨绑定和重复控制由 Rust 预留测试核对。
- 运行账号镜像的 `test_tui_*.py`、编排的 `test_cluster_transport` 和网关的 `native_signature_fixture.py`。其余旧入口回归由网关测试集覆盖。
