# 主题设置页

## Goal

新增「主题设置」页，让管理员在当前浏览器里调整控制台主题，并在保存前实时预览。对应父任务 `../11-19-console-ui-revamp/prd.md` 的 R6，画面见设计基准 `doc/design/console-v2/mock.html#theme`。

## Background

- **主题运行时已就绪**（子任务 1，`apps/web/src/theme/`）：
  - 种子 `ThemeSeed`（`tokens.ts`）字段：主色、成功 / 警告 / 错误 / 信息色、表面材质 `default | soft`，以及 `fontSize`、`spaceUnit`、`controlHeight`、`sizeStep`、`radius`、`shadow`。
  - 取值范围 `THEME_SEED_LIMITS` 已写明供本页界面共用，默认种子是 `DEFAULT_THEME_SEED`。
  - 6 个预设 `THEME_PRESETS` 只决定主色。当前预设由主色反查，不另存预设 ID。
  - `parseThemeSeed` 遇到任一字段非法就整体返回 null。颜色只接受 6 位小写 hex（`color.ts` `isHexColor`）。
  - `readStoredTheme` / `writeStoredTheme` 读写 `localStorage['flower2api.theme']`，存储不可用时不抛错。
  - `applyTheme(el, vars)` 写到任意元素即局部生效（`data-ui-theme`）。
  - `initTheme()` 在 `main.ts` 挂载前应用已保存主题，刷新时首屏无闪烁。存储值缺失、损坏或越界时回退默认。
- **入口现状**：
  - 首页 `/` 即账号页（`apps/web/src/router.ts`）。
  - 侧栏 `AppNavigation.vue:13` 已把「系统设置」单独成组放在底部，注释预留「主题设置」加入同组。
  - 移动端应用栏标题取自 `Dashboard.vue:70` 的 `titles`。
  - 网关 SPA 页面在 `services/gateway/src/handler/router.rs:145-161` 显式登记，路由测试在 `:4336`。
- **已有素材**：
  - 页头组件 `PageHeader` 的 description 插槽可附加待应用数。
  - 「已修改」徽标沿用系统设置页做法（`Settings.vue:832-835`，`label-extra` 插槽）。
  - palette、undo、rotate、save、minus、plus、fit 图标已在 sprite 中（`components/ui/icon/index.ts:32,70-80`）。
- **过渡态**：任务与工程（`apps/legacy-web`）和运行环境（`src/native-environment.css`）仍写死颜色，共约 500 处 hex、0 处 `--ui-color-*`，要等子任务 6 才会跟随主题。外壳与其余 Vue 页已改用新 token（子任务 2、4）。

## Requirements

- **R1 路由与入口**：
  - 新增 Vue 路由 `/theme`（`name: 'theme'`，挂在控制台外壳下）。
  - 网关 SPA 登记 `/theme` 与 `/theme/`，并补路由测试。
  - 侧栏底部组在「系统设置」上方加入「主题设置」（palette 图标），与页面同时上线。
  - 移动端应用栏标题为「主题设置」。
- **R2 编辑面板**（左侧）：
  - 主题预设：6 张卡片，三列。点选即把主色设为该预设色；主色不匹配任何预设时，没有卡片处于选中态。
  - 表面材质：默认 / 柔光分段。
  - 颜色 / 尺寸 / 风格三个分类分段：
    - 颜色：品牌主色、成功色、警告色、错误色、信息色。每项显示色块、名称、用途说明和 hex 值，可用取色器或直接输入 hex 修改。
    - 尺寸：基础字号（12–16）、控件高度（32–44）、尺寸步长（4–8）、基础间距（3–6）。
      - 控件高度是本次补上的字段。种子已有它的范围，尺寸步长只决定三档控件高的差值，不开放它就无法调整控件主高度。
    - 风格：通用圆角（0–12）、阴影强度（0–2，步长 0.25）。
    - 范围与步长取自 `THEME_SEED_LIMITS`。
  - 与已保存主题不同的项带「已修改」标记，并可单项恢复为已保存值。
  - 分类分段显示该分类已修改或无效的字段数，切到其它分类后仍能找到待处理的字段。
  - 首版不显示「全局 / 组件」页签、Token 搜索和主题模式（主题模式随子任务 7 加入）。
- **R3 实时预览**（右侧）：
  - 画板用同源 iframe 嵌入真实控制台首页（账号页，含外壳侧栏和真实数据），按 1440×900 渲染后缩放放进预览区。这是用户确认的方案。
  - 草稿只写进画板的文档根，画板外的控制台保持已保存主题。
  - 画板只读，不响应点击、输入和键盘焦点。
  - 画板里的外壳带预览标记，不发起自动检查更新；其余只读请求照常，数据保持真实。
  - 缩放：
    - 减 / 加 / 适应按钮，并显示当前百分比；
    - 支持滚轮缩放；
    - 拖动画布平移；
    - 进入页面时默认适应。
- **R4 页头**：
  - 标题「主题设置」，说明「自定义当前浏览器中的控制台主题」。
  - 说明后附状态：有改动时显示「N 处修改待应用」，N 为与已保存主题不同的种子字段数；有无效输入时再加「M 项输入无效」；两者都没有时显示「已同步」。
  - 撤销草稿：草稿回到已保存主题；没有改动时禁用。
  - 恢复默认：草稿回到第二版默认主题，仍需保存才生效；草稿已是默认时禁用。
  - 保存并应用：没有改动或有无效输入时禁用。
- **R5 保存与持久化**：
  - 保存后立即把主题应用到整个控制台并写入当前浏览器；刷新后保持，首屏无闪烁。
  - 保存值等于默认主题时清除存储。
  - 浏览器存储不可写时提示保存失败，草稿保留，控制台不变。
  - 主题只保存在当前浏览器，不同步到服务器或其他浏览器。
- **R6 离开保护**：有未保存草稿时：
  - 站内切换页面先弹确认框，可选择留下或放弃草稿离开；
  - 刷新或关闭标签页时触发浏览器原生离开提示；
  - 退出登录直接放行并丢弃草稿。原因：退出流程先撤销会话再跳转，此时拦截会让页面停在失去凭据的状态（design §5）。
- **R7 输入校验**：
  - hex 输入接受大小写的 `#rgb` / `#rrggbb`，统一规范为 6 位小写。
  - 数值超出范围或不对齐步长时，就地提示允许范围。
  - 无效值不进入草稿和画板，保存被禁用，直到改正或单项恢复。
- **R8 移动端 390**：面板与预览改为单列，面板在上、预览在下，预览固定高度，无横向溢出。

## Acceptance Criteria

- [x] 切换预设或修改任一参数后，画板立即变化，画板外的控制台不变；画板不可点击或聚焦，画板内没有自动检查更新请求（R2、R3）。
- [x] 页头待应用数与「已修改」标记准确。单项恢复、撤销草稿、恢复默认都按 R4 生效，按钮禁用态正确（R2、R4）。
- [x] 保存并应用后控制台立即换主题；刷新后保持且首屏无闪烁；保存默认主题会清除存储（R5）。
- [x] 越界、步长不对齐和格式错误的输入被拒绝并提示，且不影响画板。清空或篡改浏览器存储后回退默认，控制台无报错。存储写入失败时提示且控制台不变（R5、R7）。
- [x] 有草稿时站内离开弹出确认，刷新或关闭触发原生提示；没有草稿或退出登录时不提示（R6）。
- [x] `/theme` 可直接访问和刷新，侧栏入口位置与选中态正确（R1）。
- [x] 1440×900 与 390×844 截图与设计稿对照：结构、配色、圆角一致，390 下单列、无横向溢出（R8）。
- [x] `vue-tsc -b && vite build`、`node:test` 和网关路由测试都通过；新增的浏览器验证覆盖以上流程；既有回归没有新增失败。

- 主题导入导出、跨浏览器同步。
- 让任务与工程、运行环境随主题变化（子任务 6）。
