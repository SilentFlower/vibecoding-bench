# Brief — 请求记录补充原始会话、实际版本与 TPS

## Goal

- 在请求记录取得原始 session ID、实际转发版本和平均 TPS，方便关联排查。

## Scope

- 增加“原始 Session ID”列及详情展示，支持复制完整值。
- “模型 / 转发方式”列显示“原生运行时 · 2.1.280”等实际版本；详情保留每次尝试版本。
- “Token（末次）”列下方补充平均 TPS，性能详情同步展示。
- “时间 / 请求”列保留本地日期时间，省略 Asia/Shanghai 等时区文字。

## Non-Goals

- 会话搜索筛选、历史回填、上游会话明文、调度及内存策略、发版部署。

## Technical Overview

- 入站解码后、映射前冻结原始会话，复用根记录 JSON；版本和 TPS 复用已有尝试数据。

## Context & Decisions

- 正文会话优先，兼容 JSON-string 和 legacy；仅头请求取唯一会话头。完整值限 256 字节，空白或含控制字符视为缺失。
- info/debug 均记录原始会话，采用管理鉴权及七天保留期。普通 API 显示实际携带的会话与实际转发版本。
- 会话缺失或旧记录显示“未提供”；版本缺失或零尝试显示“未观测”。
- 平均 TPS 为输出 token 数 ÷ 本次尝试耗时（秒），包含首输出等待，保留一位小数；完整成功记录可计算，零输出显示零，其余显示“未观测”。
- 详情继续提供时区与原始时间。

## Risks

- 原始 session ID 将以明文进入管理诊断记录，作为既有匿名摘要规范的明确例外。
- 历史记录的会话散列无法还原为原始 ID。

## Acceptance

- 280、293、原有转发及重试映射后，原始会话保持一致，版本按实际尝试展示。
- 覆盖头体优先级、重复头、长度边界、本地响应、两种日志模式与旧记录兼容。
- 验证 TPS 正常/零值/缺失/不完整记录，以及两时区列表日期时间。
- 完整值复制、桌面/窄屏展示、Rust 测试和前端构建通过。
