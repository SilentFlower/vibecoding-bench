# v3 调度与会话可视化图模型

- 输出语言：中文；技术 token 保留原文。
- 图名：账号负载、平滑提交与当前会话的观测关系。
- 图类型：状态图，附发送时间轴和账号／会话视图示意。
- 主体：管理员、账号总览、单账号调度详情、网关调度租约、持久会话绑定、账号 sender。
- 关系：管理员只读查看；绑定归属于账号；请求经历等并发、准备环境、等发送和执行；真实提交形成时间轴事件；任一准入阶段到期返回 429 并保留既有绑定。
- 边界：仅 v3 API 网关到 sender；不包含原生 CLI／项目／养号的独立发送，不读取官方聊天内容。图中数值均为合成示例，不是线上状态。
- 终态：请求结束／取消释放运行状态；本地队满／超时保留绑定；提交未知沿现有合同处理，不自动重放。

## 事实依据

- `cc2api/web/src/components/Accounts.vue:149`：现有账号页每 5 秒刷新，组件卸载时清理定时器。
- `cc2api/web/src/components/Accounts.vue:591`：已有上游 Session 池摘要和配置展示，与新网关绑定会话概念不同。
- `cc2api/web/src/api.ts:26`：Account 已提供并发、队列、RPM、上游池等可选字段；没有新设计的网关会话列表。
- `cc2api/src/handler/router.rs:130`：管理路由统一使用管理员认证，新只读接口需纳入相同边界。
- `cc2api/src/model/request_diagnostics.rs:29`：会话摘要散列；token 观测未知为 Option；不能由池槽位推算真实会话或缓存命中。
- 同目录上级 `prd.md`／`design.md`：新增绑定、发送闸门与可视化行为均是待实施方案。

## 已确定的图结构

- 账号总览：合成账号 A／B／C 展示不同准入状态，绑定与活跃会话、阶段请求数、槽位和 RPM 分开。
- 请求状态主图：等并发 → 环境准备 → 等发送 → 提交／执行；准入阶段到期可拒绝，既有绑定保留。
- 时间轴：实心点为示例真实提交，下一许可用虚线／空心，50 RPM 示例间隔 1.2 秒；不画虚假的未来排队预订。
- 会话表：脱敏 key、账号、各阶段请求数、最近活动和有效期；一个会话可同时有等待与运行请求。
- 图例放在最低边界下方至少 20px；队列位于服务间隙；连线先于节点绘制，半透明节点使用双矩形遮罩。

## 产品范围与验证边界

- 第一版只保留最近 5 分钟有界事件及当前绑定／状态；重启后不补造时间轴，缺失／截断／陈旧明确展示。
- 详情 5 秒刷新、关闭或页面隐藏暂停；倒计时在浏览器本地更新，不发每秒请求。
- 不新增待决结构问题。首次实施已确认；静态图解不是运行中的监控页，实际界面验证另有合成数据截图。
