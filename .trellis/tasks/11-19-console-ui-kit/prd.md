# 控制台组件库与主题运行时

## Goal

在 `apps/web` 内建立自建组件库的地基：由种子 token 派生出完整 CSS 变量的主题运行时，加上一套按第二版视觉实现的基础组件和演示页。后续子任务都基于它迁移。对应父任务 `../11-19-console-ui-revamp/prd.md` 的 R1。

## Requirements

- 主题运行时：
  - 种子参数（主色、功能色、基础字号、间距单位、控件高度、尺寸步长、圆角、阴影强度、表面材质）派生出语义 token，写成 CSS 变量。
  - 第二版浅色取值为默认主题。提供 6 个配色预设（花瓣紫默认、深海蓝、松石绿、暮光橙、玫瑰红、石墨）和自定义主色；派生出的文字色与按钮文字对比度不低于 4.5:1。
  - 主题可整体应用到文档根，也可应用到局部容器（供主题设置预览画板使用）。
  - 页面首屏渲染前应用已保存的主题，不闪烁；读不到或数据无效时回退默认主题。
- token 分层：
  - 组件的所有颜色（含阴影、描边、遮罩、滚动条）都走语义 token，组件内不写死颜色，为深色模式预留。
  - 保留现有三档阅读尺寸机制（<1920 / 1920–2559 / ≥2560）。
- 过渡期旧层：页面仍在引用的旧 token（shadcn 变量、旧控件 token、阅读尺寸）取值不变、不跟主题变化，重复定义合并为一处并标明退役方式；由子任务 2、4、6 随页面迁移改用新 token，父任务最终复核时删除。
  - 理由：保持未迁移页面与旧原型一致，原型对比脚本在页面迁移前继续有效（父任务 design §6、§7）。
- 删除只服务于旧组件外观的 token 与全局覆盖：`--button-*`、`controls.css` 的 token 块、`style.css:534-570` 等未限定页面作用域的 `[data-slot=…]` 规则。
- 基础组件（形态见设计稿 `../11-19-console-ui-revamp/research/design-v2/mock.html`）：
  - 按钮：主要 / 次要 / 柔和 / 危险 / 文字，32 / 38 两档。
  - 图标按钮。
  - 输入：含前后缀与聚焦外圈。
  - 数字输入、选择。
  - 分段：带计数。
  - 标签 / 状态徽标：圆点 + 文字，6 种语义色 + 平台色。
  - 开关、单选卡 / 复选、气泡、弹窗、确认框、分页、表格、卡片、空态、骨架、通知。
  - 页头属于子任务 2。设计稿未画出的组件和状态按同一视觉语言定义。
- 现有 `components/ui` 组件保持导入路径、props 与事件不变，只做增量扩展，并改用新 token 与样式。涉及 `controls` 的 NumberInput、ChoiceSelect、InfoTooltip、SearchInput、DateTimeControl 等，以及 Button、Input、Dialog、Table、Card、Badge、feedback。
- 原生页可读取同一组 CSS 变量：token 默认值放在已被 legacy-web 以 `<link>` 引用、且已在运行时桥接白名单登记的 `apps/legacy-web/ui-foundation.css`（`runtime_bridge.rs:436`），不新增白名单条目；改动的共享文件同步静态版本参数。
- 演示页：扩充 `apps/web/ui-preview.html`，逐个展示组件的默认 / 悬停 / 聚焦 / 选中 / 禁用 / 加载态，可切换配色预设、自定义主色、表面材质，并含一个局部主题示例。
- 图标 sprite 补齐设计稿 `icons.js` 中的图标，Vue 与 legacy 两份内容一致。
- 把第二版设计稿复制到 `doc/design/console-v2/` 作为新视觉基准（research 副本保留为调研快照）；未迁移页面在迁移前仍以 `doc/design/flower2api-concept.html` 为基准。

## Acceptance Criteria

- [ ] 演示页 1440px 下每个组件的各状态与设计稿取值一致：颜色、圆角 6 / 8 / 12 / 18、控件高 32 / 38 / 44、字号字重、阴影。由新增的 `verify_ui_kit.py` 断言。
- [ ] 设计稿未覆盖的组件（复选、空态、骨架、气泡、通知、确认框）、柔光材质、5 个非默认预设的演示页截图，经用户目视确认。
- [ ] 切换预设或自定义主色后，所有组件随之变化；对局部容器应用主题时，容器外部不受影响。
- [ ] 刷新页面时首屏已是保存的主题，无闪烁；存储值缺失、损坏或越界，或读取存储抛错时，回退默认主题，控制台无报错。
- [ ] 组件源码中没有写死的颜色值，圆角只用 token（静态规则单测校验）；现有组件签名与行为不变，`verify_ui_controls.py` 通过。
- [ ] `vue-tsc -b && vite build` 通过；键盘焦点可见，`prefers-reduced-motion` 下无动画。
- [ ] 主题核心有 `node:test` 单测，覆盖派生、对比度、校验，以及默认值与 `ui-foundation.css` 一致。
- [ ] 回归集（`implement.md` 所列 37 个脚本）与改动前基线相比没有新增失败：
  - 原型对比中的基础组件采样移出原型比对，改由 token 断言覆盖；
  - 写死组件样式值的断言（如 `verify_shared_pagination.py`）改为读取 token；
  - 页面级比对与业务断言不放宽。
- [ ] 旧层合并后、组件改样式前，原型对比类脚本结果与基线一致（页面零视觉变化）。
- [ ] `ui-guidelines.md` 的 token、组件、设计基准与测试命令章节更新为新来源与新取值；原生组件规范补充新 token 与 sprite 同步要求。

## Dependencies

无，第一个交付。

## Out of Scope

- 业务页面迁移、外壳、深色色板（分属其他子任务）；页面对旧层 token 的替换。
- 主题设置页 UI（子任务 5），本任务只提供它要用的运行时接口与取值范围。
- 当前无业务引用的 `label`、`separator`、`tabs` 组件。
- 页面使用新 token 的方式（CSS 变量或 Tailwind 主题映射），由子任务 2 首次落地时确定。
