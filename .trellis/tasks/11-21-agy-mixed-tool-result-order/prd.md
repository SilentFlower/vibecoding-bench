# 修复反重力混合并行工具回填顺序

## 目标

让反重力接受不同工具组之间重排的并行回填，完成端到端回归后更新 US 实例供用户复测。

## 已确认的现象

- US `v1.28.0` 的 `52bd5f2c` 命中上一轮重读并返回 200。后续 `gemini-4-neon` 请求 `affcb234` 等四笔相同正文在 `contents[11]` 返回 `AGY_TOOL_RESULT_MISMATCH`，实际发送次数为零。
- 脱敏结构比对确认既有 10 项历史一致。新增调用按 `A、B、B、B` 出现，四个无 ID 结果按 `B、B、B、A` 到达。Rust 网关和 Python 原生续轮的现行匹配器均已用合成输入复现拒绝。 [网关配对](../../../services/gateway/src/service/gemini.rs#L596) [原生配对](../../../services/orchestrator/agy_runtime/gemini_contract.py#L119)

## 要求

- 优先使用合法显式 ID 和已支持的工具 ID 别名。缺少 ID 的结果可以跨不同函数名调整顺序。每个函数名内按剩余调用和结果的相对出现顺序配对。
- 新规则覆盖网关活跃工具轮、原生续轮和完整历史导入。原生结果按原调用顺序消费。原客户端历史、唯一工具轮归属、令牌账号访问与重读身份沿现有合同校验。
- 缺少结果、重复或未知 ID、同名组数目不合、变更历史或调用参数和归属不唯一继续返回受控拒绝。客户端将同名组内的结果重新排序时需提供真实 ID。
- 验证通过后供用户在 US 实例复测。网关与实际接单账号发送器采用同一受信发行。实例切换过程中原更新器负责排空或中止在途请求，用户在更新后发起新工具轮。

## 验收

- [ ] 合成 `A、B、B、B` 对 `B、B、B、A` 无 ID 请求成功完成一次真实回环模型提交，原生四份结果逐项对应，下一轮可继续。
- [ ] 同轮混合 ID 与无 ID、显式反序、历史多段回填及原有 ID 别名通过。缺项、重复、未知 ID、名称错配及越权拒绝。
- [ ] 已成功的同正文重试仍只回放原响应，真实回填和生成各一次。
- [ ] 按系统更新流程安装 US 实例后，核对网关和目标账号发送器均采用已验签的同一发行。用户用更新后的新轮次复测。

## 范围之外

- AGY 固定二进制版本、客户端重试策略、跨网关恢复和其他实例的安装属于独立工作。
