# Brief — 修复反重力混合并行工具回填顺序

## Goal

- 修复混合并行工具回填的 400，验证通过后更新 US 实例供复测。

## Scope

- 网关工具轮配对、原生续轮和历史导入、合成回环及 US 系统更新。

## Non-Goals

- AGY 固定执行体、客户端重试策略、其他实例安装及跨网关恢复属于独立工作。

## Technical Overview

- 用 US 已捕获的 `A、B、B、B` 调用与 `B、B、B、A` 回填结构重现，新规则按原调用位置交付结果。

## Context & Decisions

- **【关键决定】先为显式 ID 和已支持的 ID 别名占位。无 ID 的结果按函数名和组内相对顺序配对。**
- **【重要限制】同名组内改变返回顺序时需要原调用 ID。切换会收口在途生成和待回填的工具轮，复测使用新工具轮。**
- **【关键决定】400 发生在网关检查。US 用受信的同批网关与账号镜像更新，等接单发送器就绪后再复测。**

## Acceptance

- 核对四项结果均正确回填，下一轮可继续。混合 ID、多段历史、重复回填和异常归属都有回归。
- US 更新器完成安装，网关与相关发送器均运行修复批次。

## Next Step

- 接入两层匹配器并跑重排回归。
