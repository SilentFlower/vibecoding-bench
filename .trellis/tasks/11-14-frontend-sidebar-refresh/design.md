# 全站界面重新设计

## 边界与方案

本任务作为单一全站集成交付，重新设计 apps/web 与 apps/legacy-web 的页面和交互呈现。原页面结构、菜单分组和入口位置可调整；保留功能语义、可发现性和行为合同。Vue 管理端继续使用现有 shadcn-vue / Tailwind / Lucide，原生页面通过 CSS 变量和现有类映射同一套表面、排版、间距、圆角与状态色。独立兼容页面保留既有事件委托；任务宿主通过构建插件将同一控制器编译为模块。

以定稿的中性底色、紫色选中态、深色主按钮、现有粉色花形品牌和内嵌 Inter 字体为准；数字与日志使用 JetBrains Mono，中文沿已确认的系统回退。卡片使用细分隔及轻阴影，按钮、表格、表单、空态和弹窗保持一致密度。任务域保留已有 light/dark 选择及 vibebench-theme 持久化，各配色共享布局和控件规则。既有“终端主题直角/装饰”规范由本次明确全站改造决定替代，业务、资源清理、转义与状态合同继续生效；交付时同步相关规范。

## 页面重新设计

先绘制全局框架、账号页、任务工作区和系统更新的代表页面方案，再沿同一视觉语言覆盖全部业务模块。每页按主要任务组织标题、概览、筛选、数据和操作，减少重复标题与无效装饰。账号和令牌突出状态、关键字段与操作；请求页突出过滤、结果和链路；设置按现有业务领域分组；环境突出状态与常用管理；工程/养号工作区突出当前目标、执行状态、控制与交付。登录、详情和表单弹窗同步重新设计。

原业务控件可以移动、重新分组或替换展示形式；每个变更维护原入口到新入口的映射。字段和操作语义、状态权限、错误反馈及危险确认是保持项。

## 页面与导航

Dashboard.vue 提供固定左侧主导航、右侧路由内容。主导航按网关（账号/请求记录/访问令牌）、资源（代理管理/运行环境）、工作区（任务与工程）及系统设置组织。系统更新位于顶部品牌旁，折叠与退出位于底部。桌面提供折叠，窄屏采用可关闭抽屉并保留七个入口的文字名称。选中态由原 route.name 派生，原 URL 和查询参数保持。

任务域保留账号、题库、普通任务、运行记录、工程迭代与养号迭代的可发现入口；内部导航整理为一致的分组页签/空间切换，沿用原 hash 与父页消息路径。独立访问原生页面保留全部导航、认证与主题工具。

普通内容区采用可伸缩宽度和统一页面标题/工具栏，长表格在自身容器内滚动。环境/任务保持 flex-1、min-h-0 和独立滚动；侧栏折叠不重建工作区宿主。页面标题按层级分配，避免外层和内层重复大标题。

## 功能完整性

research/entry-baseline.json 记录改造前源码哈希及事件、id、data属性、链接基线；research/feature-map.md 描述模块、关键入口及目标位置。实施时核查每个原事件仍有对应控件，每个被调整的选择器仍有消费者。对动态生成按钮与条件显示构造合成状态验证，不以源码字符串数量代替操作验证。

每页保留字段、过滤条件、分页、动作和危险操作确认。页面模板、布局组件和展示状态可按新设计重组；业务 API、数据转换、SSE/WebSocket、请求代次及资源清理沿用原合同。必要的事件绑定调整必须同步核对旧操作与新控件映射。公共样式调整逐页验证，避免 display/overflow/z-index 使入口被遮挡。

## 系统更新信息层级

SystemUpdates.vue 顶部提供当前平台版本、检查状态、可用目标及主操作。发布说明作为主要阅读区域；账号环境和 CLI 内核保留为辅助摘要及直达入口。操作中提供阶段、目标、状态反馈及合法的取消/恢复入口。历史版本与回退、发行标识、清单摘要、快照和迁移详情使用明确标记的次级区域。

状态来自现有 status、catalog 与 operation 投影。检查缓存不新鲜、未知或缺失时使用准确提示；只在现有数据支持时表达可更新或无可用更新。阶段展示只映射后端实际 phase，不生成百分比或推断已完成的阶段。保留 frozen、expected_revision、operation_id、默认一分钟及既有等待选项，保留 busy、data_compatible、fresh、cancelAllowed、recoveryAllowed 控制。

## 数据与兼容性

Vue 请求继续统一走 api.ts；router.ts 继续管理鉴权与登录/退出。Environments.vue 保留 iframe view key、稳定 src、hash同步、origin/source 白名单及参数白名单。原生页面保留 id/data事件关联、表单字段、HTML转义、主题存储、导航历史、异步代次和关闭资源流程。

现有网页资源更改同步 index.html 的静态版本参数。品牌 favicon 与名称按原合同保留。只调整表示层；不引入后端接口、迁移或真实运维动作。

## 验证与风险

最大风险是全局样式导致条件按钮、长表格或弹窗内容不可达，以及导航改动导致 iframe 重建。以入口矩阵、390/720/1280px截图、键盘/焦点、条件状态与请求payload回归验证。明暗主题均覆盖，桌面还核对侧栏折叠后的实际可用宽度。

所有浏览器验收使用合成 API、账号和离线状态，真实 OAuth、账号运维、模型调用与生产安装不参与本地验收。现有系统更新和环境验证脚本复用实际构建产物；任务域新增缺失的合成可达性场景。

## 回退

按导航外壳、共享样式、各业务页、原生页面四类记录变更。局部失败先修复对应层；需要回退时仅回退本任务文件中的变更，保留工作区其他修改。纯界面回退保持数据结构。完整版本新增代理目录与关联同步增量表；平台回退必须使用现有备份/恢复流程，核对目标版本的数据能力，保持镜像和同批备份一致。待同步代理属于持久工作，回退前核对其状态与关联配置，禁止直接删除增量表。

用户反馈字体观感与侧栏缺少收起入口。本轮对公开参考站进行了实际登录只读取证，记录 `research/reference-style.md`。概念稿内嵌 Inter Variable 与 JetBrains Mono Variable，明确中文界面字体回退并提升文字对比度；新增76px侧栏折叠、图标名称提示、品牌版本入口保留及localStorage状态记忆。证据：`.deploy/frontend-sidebar-refresh/concept/verification.json` 与桌面、窄屏、折叠截图。字体许可位于 `doc/design/font-licenses.txt`。本轮是概念稿修订，正式产品映射仍待设计方向收敛。

## 用户增量：操作、弹窗与代理管理

用户要求常用操作直接可见；令牌复制、编辑、启停、删除在行内展示，删除保持确认。账号权限选择器采用搜索、复选行和已选标签。二级配置窗口独立打开，关闭或Esc返回父窗口并恢复触发焦点。

用户新增独立代理管理模块，预览增加导航、列表和配置交互。现有生产实现通过 Account.proxy_url 保存单账号代理，网关运行配置接口强调唯一来源以避免绑定环境代理漂移；本轮只扩展概念稿。正式代理模块需要补齐实体/API、凭据保护、账号绑定与运行环境配置一致性设计后实施，不能将概念稿的示例检测与状态作为已有后端能力。

## 账号卡片与本轮交互验收

用户指定账号使用高信息量卡片。概念稿已改为响应式卡片，集中显示身份/启停、代理与环境直达、状态、用量及重置时间、并发/RPM/活跃会话，编辑/用量/测试/详情/删除直接可达。令牌选择器采用搜索复选列表与可移除标签，草稿取消与保存区别已验证。动态二级dialog保留父DOM，关闭或Esc恢复父层及触发按钮焦点。

代理管理新增为第八个主要入口（含品牌系统更新入口计数），当前只提供示例新增、导入、检测、关联、编辑与删除保护。最新验证入口为 `research/verify_concept.py`，结果位于 `.deploy/frontend-sidebar-refresh/concept/controls-verification.json`。

## 代理出口与账号使用情况

用户要求代理显示出口IP、地区及账号使用情况。列表需展示检测返回的出口IP、国家/地区（有城市时展示城市）、最近检测时间；待检测、检测中、失败、地区未知分别可见。IP位置由经该代理得到的检测证据提供，代理地址、名称或账号地区不作为出口推断来源。

账号使用情况区分配置关联与当前活动，展示关联账号数量、名称、启用/异常状态及正在处理请求的账号和请求数；支持查看账号详情及维护关联。当前概念稿使用明确标注的示例观测，正式接口的数据来源与更新时间仍归代理模块实施设计。

## 最新空间与层级决定（覆盖此前普遍使用多级弹窗的方案）

用户要求减少无必要的多级窗口并提高空间利用率。环境管理改为宽侧栏，运行概览、资源与采集、请求内核、运行时段、维护操作在同一DOM内切换，保留表单草稿；保存配置保留当前工作区。删除、激活、回退等独立确认可使用二级弹窗，关闭返回父层与原焦点。代理账号关联在列表行内展开，编辑代理和令牌权限使用桌面双栏布局，窄屏单栏。

代理观测显示出口IP、国家/地区与城市、检测延迟、最近检测时间；示例过期结果明确标记上次成功，失败和地区未知分别展示。账号使用区分关联数、活跃账号和处理中请求，支持账号直达；检测刷新保留行内关联草稿，修改代理使旧检测回执失效。所有当前检测均为本地模拟。

## 账号选择代理与原用量窗口（最新用户决定）

代理绑定的唯一编辑入口归账号配置：选择一条已有代理或直连，保存后更新配置；取消保留原选择。代理管理只维护代理线路、检测与只读账号使用情况，提供跳转到账号配置的入口，去掉代理页勾选/保存关联。原有使用者、数量与删除占用判断均从账号选择派生。概念稿使用本地proxyId演示；正式后端当前为Account.proxy_url，正式实体迁移及运行环境一致性仍需设计。

账号用量对齐现有 Accounts.vue / UsageWindowStats.vue：保留5小时、7天与7天Fable，移除独立7天Sonnet展示。5h/7d保留本地请求数、Token、费用、估算与范围说明，上限/未限制、重置倒计时、记录起点与刷新时间；未知、待更新、官方未返回5h窗口和真实0%继续区分。模型子窗口不虚构独立本地统计。后台原数据兼容在正式实现中保留。

## 本轮概念稿：主要编辑、代理规模与滚动

主要编辑区复用已核对的 Account.request_backend 枚举 legacy/native293，保留原生运行时与原有转发选项；auth_type 放入折叠高级配置。卡片以 queued_requests 显示队列，调度详情同时显示 current_concurrency，当前概念稿数值均为示例。

代理选择器将已选值保存在表单隐藏字段中，候选搜索覆盖名称、地址、出口IP与地区；每批50条，候选列表最高232px。选择仅更新草稿，表单提交时更新账号，取消保留原关联。Escape先关闭候选，再关闭账号侧栏；键盘上下键、首尾键及确认可用。

账号侧栏使用纵向flex布局，标题与页签固定，正文min-height:0并独立overflow-y:auto；滚动条采用thin及WebKit 6px样式。移除正文重复身份区以提升空间利用率。正式页面迁移及代理后端仍处于待实施范围，当前交付持续用于设计反馈。

## 用量统计密度微调

请求数、Token、折算费用及预计总费用改为无底色的紧凑文字行，以间隔点分隔。保留原有数值、费用口径和悬浮说明，长内容按完整统计项换行；卡片与账号侧栏共用样式。

## 转发与调度摘要密度微调

账号卡片的转发方式、优先级及调度入口改为无底色单行摘要。转发方式及版本靠左，优先级与调度文字入口靠右；移除重复的上层标签与独立背景块。保留完整版本、优先级数值及原调度操作，窄容器允许按项换行。

## 滚动条按活动显隐

页面外层、侧栏正文、弹窗及动态选择列表统一使用透明轨道和细滑块。真实滚动事件显现当前容器滑块；停止800ms后在250ms内淡出。轨道宽度保持稳定以避免布局跳动，捕获监听覆盖动态创建容器；减少动画偏好缩短淡出，高对比模式沿用系统滚动条颜色。

## 用户反馈：摘要层次与卡片高度

转发与调度摘要恢复浅底分组，转发方式及完整版本位于左侧，右侧优先级分组整体进入调度详情；使用较紧凑的内边距和标签间距。卡片每个用量窗口的本地统计固定16px单行，仅显示请求数、Token及费用；详情入口打开账号概览，完整展示预计总费用与统计范围说明。极长数值在卡片省略，详情保留完整数值；卡片高度不随统计文本换行增加。此决定覆盖之前的纯文字单行转发摘要及卡片全量费用展示。

## 最新决定：预计费用保留且统计强制单行

用户明确要求预计费用保留在卡片，并接受超长内容隐藏。请求、Token、折算费用和预计总费用均直接渲染到固定16px单行；超出可用宽度时整行省略，禁止换行。完整统计及费用口径通过悬浮说明和账号概览保留。此决定覆盖上一轮将预计费用移入详情，以及尚未实施的固定两行提议。

任务账号原 name 同时用作 profile、日志路径和锁标识。可编辑名称采用 display_name 公共字段，保存在已有 app_settings 的 account_display_name:<账号ID> 键中；CLI设置 GET/PUT 增量读写该字段，与版本更新共用事务。原 name、profile_path、环境ID、凭据、网关关联及历史运行保持。null恢复原标识显示，非空名称去首尾空白、最多128字符、拒绝控制字符；列表通过一次联表读展示名称，避免逐账号查询。任务卡片及任务选择器使用 display_name/name 回退，授权仍使用稳定 name。

配置窗口按定稿提供名称、版本、网关/时段/额度三个入口与折叠高级维护。工程空间的执行配置沿原合同，仅写本空间的版本及抓包字段。公开凭据状态统一网关称谓，内部协议字段保持。原生池探针显式采用UID1001并验证执行身份；数量、共享映像、封存、内存和回收断言保持。工作区验收明确校验所选账号URL。
