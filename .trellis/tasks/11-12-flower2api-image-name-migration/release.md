## 一次切换

1. 按原独立服务维护锁和存储锁核对门禁空闲及无活动更新，刷新已冻结固定源码及模板，启动更新服务并检查当前旧发行仍可读取。
2. 经原更新入口登记唯一维护操作，关闭新认领，等待养号 CLI、API、评审、执行登记及租约自然排空。超时服从原状态机恢复；长作业继续等空闲窗口。
3. 冻结控制 ID、环境快照和数据身份，沿v2合同停止真实控制角色并生成同组数据库快照。
4. 移除本次已停止且来源吻合的旧 Compose 控制角色；新项目创建新网络。控制启动后，旧账号网络角色按当前数据库登记及原/候选来源复核，使用原精确 DNS 别名临时接入新网络，并沿原 network-guard 入口更新精确管理 IP 白名单。
5. 启动候选控制程序，逐项沿原环境维护入口重建账号角色，更新正常容器关联及代次。继续保持当前资源、原生内核和 CRIU 选择；停止环境保留原状态。
6. 核对当前组合、健康、签名来源、双库及身份摘要、资源额度、原生预热与 CRIU，然后沿原状态机开放准入。
