# 节点管理与系统设置页迁移

## Goal

把节点管理、系统设置两页换用新组件与第二版视觉，信息结构与业务行为不变。上级需求见 `../11-19-console-ui-pages/prd.md`，画面见 `doc/design/console-v2/mock.html` 的 `#nodes`、`#settings`。

## Background

- **页面入口**
  - 节点管理：`Nodes.vue`（`/nodes`，291 行）。页面内嵌「账号执行节点」区 `runtime/AccountNodeSelector.vue` 与迁移面板 `runtime/AccountNodeMigration.vue`。
  - 系统设置：`Settings.vue`（`/settings`，866 行），配合 `settings-design.css`（136 行）。字段元数据在 `lib/settingsSchema.ts`。
  - 两页页头已由子任务 2 换成 `PageHeader`，设置页的浮动保存栏已换成 `FloatingSaveBar`。
- **旧样式现状**
  - 节点页的 scoped 样式里有十六进制色值、`12px` / `10px` 圆角字面量和 `var(--x, #hex)` 回退值。
  - `settings-design.css` 里有 48 处 `rgb()` 或十六进制色值，以及 `!important`。
  - 迁移组件的 scoped 样式里有圆角字面量。
  - 上述文件都不在 `theme.test.mjs` 的 token-only 覆盖范围内。
- **节点页现状**
  - 页头有三个按钮：同步全部节点、刷新列表、添加节点。
  - 摘要行 `.nodes-summary` 显示「N 个节点 · N 台远程服务器 · N 个归属账号」。
  - 节点卡依次显示：
    - 资源两列：CPU、可用内存、可用磁盘、归属账号；
    - 元信息：最近检查、Docker，远程节点另有「运行组件」；
    - 可折叠的「主机身份与版本」；
    - 操作行：检查连接、准备或同步组件（远程节点）、暂停或恢复接单、改名（远程节点）、移除（远程节点）。
  - 状态文案由 `state()` 产生，共 8 种：连接正常、待检查、连接异常、观测已过期、已暂停接单、移除中、移除待重试、已移除。目前只有绿、灰、红三种着色，「待检查」显示为绿色。
  - 弹窗：添加 SSH 节点、修改节点名称用旧 `Dialog`；移除节点、准备运行组件用 `ConfirmationDialog`。
  - 节点列表接口一次返回全部节点（无分页），概览卡可在前端按全量计算，**不需要接口改动**。
- **设置页现状**
  - 搜索框与「N 项配置」单独占一行，位于页头下方。
  - 左侧分类导航：有未保存修改的分类显示一个小圆点，预热记录显示条数。
  - 右侧工作区先显示分类标题和说明，再显示各段落卡（标题、说明，图标在右上角）。
  - 字段两列排布；布尔字段用原生 `input[role=switch]` 加伪元素绘制开关。
  - 预热记录分类为旧 `Table`，结果状态用自定义着色类。
  - 搜索跨分类过滤，切换分类保留草稿；保存失败时定位到出错字段；撤销恢复为上次保存值。
- **设计稿 `#nodes`**
  - 四张概览卡：节点、远程服务器、归属账号、待处理（示例「1 · 需检查连接」）。
  - 节点卡为实体卡，包含：
    - 头部：图标块、名称、远程节点等宽地址、带点状态徽标（在线为绿、待检查为琥珀）；
    - 资源四列；
    - 浅灰信息块：最近检查、Docker、运行组件；
    - 「主机身份与版本 ›」入口；
    - 小号按钮行，「移除」为靠右的危险文字按钮。
  - 页面下方是两列字段的「账号执行节点」卡。
  - 设计稿未画「改名」按钮，本机节点也画了「运行组件」行。
- **设计稿 `#settings`**
  - 搜索框与「59 项配置」放在页头操作区。
  - 分类导航选中项为白底卡片，已修改数量用琥珀色数字表示。
  - 段落卡左侧为图标块，后接标题与说明；没有单独的分类标题行。
  - 字段两列排布；被修改字段的标签旁显示琥珀色「已修改」标签。
  - 浮动保存栏显示「1 项待保存」。
- **设计稿未画的画面**
  - 节点：添加和改名弹窗、移除与准备确认、迁移面板。
  - 设置：搜索结果与空态、预热记录表。
  - 两页的 390 形态。
- **依赖两页的验证脚本与基线状态**
  - 节点：
    - `verify_cluster_ui`：用到 `.node-card`、`.nodes-summary` 的「3 个归属账号」、卡内 `dd` 末项、`.account-node-selector`、`.migration-status`、`.node-migration` 和按钮名称，基线通过。
    - `verify_node_password_ui`：基线在 L36 `dialog.get_by_label('节点名称')` 失败，原有问题。
    - `verify_cluster_draft_ui`、`verify_execution_node_visibility`（跳转 `/nodes`）、`verify_ui_shell` 只依赖节点接口或路由。
  - 设置：
    - `verify_remaining_pages`：基线在 L52 失败。脚本断言保存载荷为 56 个字段，与当前字段数不符，属脚本漂移。
    - `verify_scheduling_preferences`、`verify_session_policy_blocks_ui`：依赖 `data-settings-field`、`.setting-help`。
    - `verify_prime_history_ui`：依赖 `.settings-prime-records`、`.system-settings-nav`。
    - `verify_ui_shell`：依赖 `.settings-save-bar`。
    - `verify_frontend_navigation`：依赖 `.system-settings-nav`。基线在 L105 `#theme-toggle` 失败，与本批无关。

## Requirements

- **节点管理**
  - 摘要行换成四张概览卡：
    - 节点：总数，说明「N 台本机 · N 台远程」；
    - 远程服务器：远程节点数；
    - 归属账号：沿用现有合计，反重力账号归属读取失败时显示「—」；
    - 待处理（用户决定）：统计需管理员处理的节点。
      - 计入五种状态：待检查（从未检查）、连接异常、观测已过期、组件同步失败或待核对、移除待重试。
      - 暂停接单是主动操作，同步中、移除中是进行中，三者都不计。
      - 说明行列出原因：只有一类原因时显示原因本身（如「需检查连接」）；多类时按「N 台需检查连接 · N 台组件异常 · N 台移除待重试」列出；为 0 时显示「全部正常」。
      - 「远程服务器」卡说明行对远程节点用同一口径，显示「N 台待处理」，为 0 时显示「全部正常」。
  - 节点卡换用实体卡：
    - 头部状态徽标按语义着色，「待检查」为琥珀色；
    - 资源四列；最近检查、Docker、运行组件放进浅灰信息块；
    - 「主机身份与版本」保持可折叠；
    - 按钮统一为小号，「移除」为靠右的危险文字按钮。
  - 节点卡信息与操作保持不变：
    - 「改名」保留（设计稿未画）；
    - 本机节点不新增「运行组件」行；
    - 组件版本变更说明、错误原因、移除进度照常显示；
    - 各按钮的禁用条件与文案不变。
  - 「账号执行节点」卡与迁移面板换用第二版卡片样式与 token；选择、迁移、取消、续接行为不变。
  - 添加 SSH 节点、修改节点名称两个弹窗换用 `ModalDialog`。字段、指纹核对、认证方式切换和关闭时清空凭据的行为不变。移除与准备确认沿用 `ConfirmationDialog`。
- **系统设置**
  - 搜索框与配置总数移入页头操作区。
  - 分类导航改为第二版样式：已修改的分类显示该分类的待保存字段数（琥珀色），预热记录显示条数。
  - 段落卡左侧为图标块，后接标题与说明，字段两列排布；被修改字段的标签旁显示「已修改」标签。
  - 工作区顶部的分类标题行按设计稿去掉，分类说明不再单独显示；搜索时保留「搜索结果 · 找到 N 项配置」一行。
  - 分类图标按设计稿：预热与拦截用滑杆图标，日志与观测用清单图标。
  - 布尔字段换用组件库开关。
  - 预热记录表与结果徽标换用 token 样式。
  - 草稿、撤销、搜索、切换分类保留草稿、保存失败定位等语义不变。
- **两页的 390×844 形态**：
  - 概览卡与节点卡单列；
  - 设置分类导航可横向滚动；
  - 字段单列；
  - 不出现页面横向滚动。
- **样式与脚本**
  - 两页及上述组件的样式只用 token，被替代的旧规则删除。
  - 新样式文件纳入 `theme.test.mjs` 覆盖。
  - 依赖脚本按新视觉更新定位与期望，业务断言不放宽。
