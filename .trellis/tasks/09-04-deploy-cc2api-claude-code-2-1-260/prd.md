# 发布并验证 cc2api Claude Code 2.1.260

## Goal

在 2.1.260 抓包与 cc2api 协议适配通过后，发布并部署 cc2api，验证线上默认画像、账号
迁移和真实请求，同时完成已先行部署的 bench 2.1.260 与 cc2api 的跨项目一致性和
2.1.257 回滚材料保留与版本协调记录。

## Requirements

- 只在抓包证据任务和 cc2api 协议任务完成 Check-All、提交并推送后开始发布。
- 发布前记录 cc2api 旧镜像、连接数、SQLite/PostgreSQL 备份、profile/range、账号
  canonical env、管理员自定义设置摘要和 bench 当前版本状态。
- 等待低连接窗口，拉取目标镜像并 force recreate；不得只 restart 或在构建未完成时
  使用漂移的 `latest`。
- 部署后核验 HTTP、容器 image ID/digest、DB integrity、profile/range、账号版本分布、
  设置保留和近期协议/迁移错误日志；协议覆盖复用已完成的抓包与协议子任务证据。
- 真实使用结果采用用户反馈和已有记录；按用户停测要求，不再主动发送模型请求或重跑
  生产 continue，不把未逐项覆盖的模型与 bootstrap/hello 写成已验证。
- 保留已确认的旧 cc2api 镜像、两套数据库备份和版本协调记录。完整联合回滚脚本、旧
  bench 三镜像追加核验及副本恢复演练本次不执行，不作为收尾门禁；不改写历史 run 快照。
