# Brief — Pi 观察等待合并与增量上下文

## Goal

- 减少 Pi 等待 Claude 期间的空转模型调用及重复画面输入。

## Scope

- 两空间共用的观察等待、模型画面增量、按需完整读取及相关回放验证。

## Non-Goals

- 不代替 Pi 作业务决策，不自动发送输入，不改变管理页面和原始观察协议，不部署生产。

## Technical Overview

- Python 本地监听交互钩子、原生提问和画面变化；交互事件立即返回，新有效画面约一秒去抖，显示噪声合并，无有效变化才三十秒兜底。
- Node 在原始结果落库后生成可还原行替换片段，相同屏幕省去重复正文；首次、摘要、重启及 full_screen 请求使用整屏。

## Context & Decisions

- 来源为父任务 R1、R2、R5 和用户已确认的交互事件即时唤醒决定；项目与工程养号复用同一代码，完整观察保留在数据库与页面。

## Risks

- 必须验证固定 CLI 钩子与无钩子菜单的覆盖、显示噪声过滤、摘要基线、多个工具回执和取消顺序。

## Acceptance

- 等待不被纯屏幕噪声提前打断，有效事件及时返回，取消/代次/预算保护和输入去重有效。
- 差异可还原，按需整屏及摘要恢复有效，页面快照保持完整。
- mock 上游计数和保存的时间轨迹表明请求及载荷下降，原样回放与近似估计明确区分。
