# 项目迭代验收缺陷修复设计

## 边界与兼容

本任务围绕同一套项目迭代验收闭环修复 RUN-01／02／03、UI-01／02。保持 schema 1／2、API 载荷、数据库字段、冻结会话及原账号门禁；不修改 cc2api。现有部署及工作流变更属于任务基线，不能混入修复。

## 决定文件发布与读取

- 扩展项目原子文档写入的可选权限能力，默认仍使用私有0600。决定专用写入在临时 fd 上完成 root:1000、0640、完整写入及 fsync 后一次 replace；不存在发布后再按目标路径更改权限的窗口。
- `_decision()` 只对可信普通文件检查当前内容和元数据；完全一致的决定不替换。目标缺失时补发、内容／归属／权限不符时按原有拒绝规则或受控重发处理，不跟随链接。
- driver `_read()` 保留 NOFOLLOW、普通文件、硬链接与大小限制。只有已打开文件被合法原子替换导致 nlink=0 时，关闭旧 fd 并有限重开；持续竞争达到上限明确失败。其他异常不笼统重试。读取后仍校验字节上限与 JSON 对象形状。
- source、generation、phase_seq、step_id、session_id、response_key 的精确核验继续由现有阶段机负责，不因文件重试放宽。

## 局部阻塞与终态收口

- 将停止的状态认领与长IO分开：短DB锁内依据当前状态和额度代次条件认领 stopping，只有成功认领者执行清理，终态不能由旧读取覆盖。
- 共享停止逻辑提供项目内部的终态幂等模式；公开停止路由保留对本来已终态请求的拒绝行为。内部幂等只表示观察到执行已结束，不伪造 released_at，也不略过 is_executing、released_quota_attempt、execution_error 的核对。
- 项目管理器统一通过该内部入口停止；不匹配异常消息或广泛吞掉HTTP400，认证、失联、清理失败和归属异常仍按原强保护处理。
- 区分人工批次取消与项目局部故障导致的定向停止。局部 blocked 优先保留在计划和实例，失败报告保留具体原因；只有用户停止或父代次取消使用 cancelled/stopped。健康项目继续从原队列补池。
- 事务中的批次generation、执行额度代次与已接受检查点仍是接受和恢复依据；不在真实执行未释放时启动新写入。

## 界面

- `paintProjectBatch()` 先按批次状态生成调度说明：active 才使用实时等待原因／自动推进提示；paused、pausing、stopping 各有准确说明；completed、stopped、blocked 展示对应终态及已有错误。下一投放时间仅在active且提示仍有意义时显示。
- 运行时段表单使用已有 `.toggle-line`；星期标签单独固定同行布局、checkbox尺寸和选中状态。日期与区间控件收进可禁用区域，关闭限制时禁用，重新启用保留原输入。
- 保存仍从明确的DOM字段读取完整配置，不能因 disabled 控件不进入 FormData 而清空原值；服务端时区与严格校验不变。所有动态文本沿用 escapeHTML，颜色沿用主题变量。
- 保存后的列表刷新完成再关闭弹窗，使关闭状态表示本次交互已经结束，避免用户快速切页与尚未完成的旧列表渲染竞争；窄屏时间区间改为单列，边界验证覆盖弹窗内部。
- 既有 SSE、滚动位置、路线展开及 modal关闭机制沿用，不新增异步资源。

## 验证与交付

- 先用确定性时序验证两个文件窗口和停止竞争，再运行现有计划／实例／停止／额度／时段回归。
- 扩展已有真实Docker和浏览器验收入口，增加opt-in百项目规模入口；新入口复用原合成账号、模型替身、Scheduler、driver与独立业务验证器。独立长时截止，不改变短验证入口的1200秒上限。
- 可选全库模式固定并发2、活动池3、每计划20步、20步后轮换、间隔0、计划工作超时1800秒，`COMPLETION_IDLE_SEC` 保持生产默认10秒。用户最新要求“太慢了，按实际情况测”，因此本轮改用已观察运行规模与关键故障场景验收，保存用户停止前的部分结果和未覆盖边界；完整100×20保留为后续opt-in能力，不再阻塞本轮。默认2＋2＋1继续由原回归覆盖。
- 修复镜像仅在本地Docker随机部署测试，不发布、不切换生产。局部异常注入与正常全库运行分别留证；任何失败如实报告，保留诊断后定向清理。
- 更新项目迭代、停止收口和前端相关规范中可复用契约；此次不写尚未获确认的全链路playbook预览。

## 风险与回滚

- 原子写 helper 的其他调用必须保持0600；读取重试不能接受链接或旧来源。
- 停止逻辑被普通Tasks、项目和养号共用，须复验这些路径以及额度等待；严格清理失败绝不能被幂等模式隐藏。
- 百项目默认稳定等待需要数小时，应持续记录进度及独立截止；脚本启动不算验收通过。
- 本地改动可按本任务文件diff回退，无数据库迁移；部署回滚不属于本轮范围。
