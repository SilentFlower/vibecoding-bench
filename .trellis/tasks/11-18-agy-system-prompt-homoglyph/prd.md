# AGY 系统提示词同形体替换与记录

## Goal

让AGY账号按独立配置转换实际出站的系统文本，并追溯本次请求采用的策略。

## Background

- 父任务为../11-18-multi-platform-account-runtime/prd.md，本任务承接R07、AC08和R05/R06的策略记录与账号交互部分。
- 账号授权和AGY运行环境已交付，当前基线为37aa1399及业务提交c61d635b。Account和账号设置页已具有默认false的agy_system_prompt_homoglyph_enabled；页面目前提示模型接入后生效。
- 参考来源为/root/project/new-api/scripts/system-prompt-worker。固定26字符映射、来源摘要及既有测试已核对，见research/reference-mapping.json和research/current-contracts.md。
- 固定原版、本地TLS的系统文本基线已完成，9次合成生成的实际request.systemInstruction.parts与输入系统文本一致，见research/native-system-baseline.json。
- 当前真实外部模型调用预算为0。工程验证采用合成凭据、断网容器和本地TLS上游；真实模型分词、缓存和计费用量效果作为独立外部验收。

## Requirements

### HG01 账号策略与一致性

- 复用现有AGY账号开关，按账号独立保存，缺省关闭。设置控件、布局、保存反馈及账号切换体验沿用既有界面。
- 每个HTTP请求在账号选择后冻结本次策略；同请求的认证恢复沿用原策略。后续HTTP请求采用其准入时的账号配置。
- 账号切换、迟到保存回执和凭据换代保持归属隔离；CC路径继续原行为。

### HG02 固定文本边界

- 使用参考Worker的26字符固定同形字映射，输出确定且幂等，Unicode码点数量保持一致。
- 仅转换协议定义的系统文本。用户消息、模型历史、工具定义、参数、结果、ID、签名及非文本字段保持原有数据。
- 关闭时保持传入目标文本原样，包含调用方已经转换过的文本。空系统文本和缺省系统文本沿原生行为。
- 正常、SSE、工具续轮及有界认证恢复采用一致处理；大文本继续服从既有请求、截止和内存边界。

### HG03 实际执行与兼容

- 在现有AGY原生提交链路接入转换，核对固定原版实际发给本地上游的系统文本。
- 原始入站视图和处理后的提交视图区分来源；不能将只改管理字段视为真实生效。
- 启用策略遭遇未知规则、损坏配置或不兼容执行端时在模型发送前受控失败，防止静默按原文发送。
- 关闭策略恢复后续请求的原文处理；旧在途与原工具结果保持本次冻结策略和真实归属。

### HG04 策略记录与用量

- 记录账号、HTTP请求、实际尝试与本次冻结开关、规则版本及实际处理来源，区分开启和实际发生替换。
- 完整系统文本继续受账号采集开关和管理权限保护；公开日志仅保存必要策略元数据。
- 保留平台原始usage和缓存字段。字符数或替换数不换算成token用量，不声称合成实验已经验证真实缓存命中。
- 为后续请求记录任务交付策略事件及视图来源合同。

## Acceptance Criteria

- [ ] HGA01：两个AGY账号分别保存、回读和采用各自开关；缺省false，账号切换与迟到回执隔离，CC回归通过。（HG01）
- [ ] HGA02：映射与参考26字符一致；开启、关闭、重复经过、多Part、空文本、Unicode和大文本结果可核验，码点数量及幂等性通过。（HG02）
- [ ] HGA03：真实固定原版在普通、SSE及工具续轮中仅转换系统文本；用户、历史、工具和签名边界通过实际出站及结构对照。（HG02、HG03）
- [ ] HGA04：同HTTP认证恢复保持策略快照；后续HTTP按新配置处理；未知规则和不兼容链路在发送前失败。（HG01、HG03）
- [ ] HGA05：策略事件准确关联本次尝试，原始入站与实际提交视图区分，关闭采集及敏感保护通过。（HG04）
- [ ] HGA06：固定输入重复产生稳定系统文本；上游usage及缓存字段原样交付。真实分词、缓存和计费变化在有授权账号与独立预算时验证并保留来源。（HG02、HG04）
- [ ] HGA07：账号控件桌面/390px、草稿、焦点及保存反馈通过回归；可通过关闭开关恢复后续请求原文处理。（HG01、HG03）

## Non-Goals

- 工程任务、养号、CC系统文本转换、新公共协议和完整请求记录页面。
- 修改new-api源码、渠道99、Cloudflare Worker或外部服务配置。
- 用户文本星号、零宽字符、随机同形字和其他独立文本策略。
- 生产迁移、部署、真实凭据访问及未授权真实模型费用。
