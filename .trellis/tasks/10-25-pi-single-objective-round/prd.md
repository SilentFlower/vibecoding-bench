# 修复项目与养号单目标边界及 Pi 上下文超限

## Goal

让两种迭代每次指挥只处理一个工程目标，并以可配置的 token 摘要压缩安全恢复和持续运行。

## Background

- 用户先确认单目标修复，随后明确要求一起修复上下文超限与长期保留过多历史的问题；这是本任务的增量范围决定。
- 用户随后明确澄清：全新上下文的边界是每个新工程目标，同一目标内继续沿用上下文；不是每次模型请求重建。此前对“每次请求”的误解未进入实现，以本次澄清为准。
- 线上真实错误为 `400 The input token count exceeds the maximum number of tokens allowed 1048576.`。最后成功请求已经达到 995,718 token；恢复时取消消息的零用量及连续工具循环缺少检查，导致原压缩未生效。
- 原 `ProjectsService` 指南允许完成后继续其他目标，`_submit` 成功后只释放 Claude 工作而不结束控制者，`_start_work` 可以随后创建另一个目标。
- 工程养号入口使用同一个 `ProjectsService`，仅通过 `namespace='warmup'`、`auto_cycle=True` 区分，因此存在同类行为。

## Requirements

- R1：项目与工程养号每个账号的单次指挥最多绑定一个工程目标。开始时存在未完成工作则只续做该工作；否则可从当前授权、依赖就绪的目标中选择一个。
- R2：完整独立验收返回通过并保存通过事实、完成执行收口后，正常结束本轮，不继续选目标，也不为用满时限空转。模型旧会话或错误工具调用不能绕过此边界。
- R3：验收失败时继续在当前目标和原会话中返工；超时、额度等待或服务中断保留原目标、工作区、会话和累计耗时，下次仍优先续做。单轮时限配置沿用当前值，本轮不调整预算语义。
- R4：下一轮继续遵守原计划开关、各自固定或随机间隔、额度、运行时段、身份和共享账号占用门禁。人工暂停、关闭计划和旧代次迟到结果不得被正常完成逻辑覆盖。
- R5：工程养号完成一个目标后同样结束本次指挥；完整工程池全部目标独立验收通过后，仍由后续计划认领按既有规则清理并开始下一工程轮次，不提前清理或借用另一空间的通过事实。
- R6：控制端工具硬性限制与 Pi 指南一致；已通过目标、冻结验收材料、历史记录及两个空间的隔离保持。
- R7：同一目标按 token 用量触发模型摘要压缩，默认阈值 350,000 token，包含缓存输入；取消／错误的零用量不能覆盖此前有效用量，连续工具调用、模型降级和恢复前均检查。
- R8：每个新工程目标从干净上下文开始，同一目标内保留连贯上下文，到阈值后生成包含关键决定、进度、待办和投递事实的摘要并保留近期完整交互；移除 12／24 KiB 的字节裁剪和请求硬上限。原历史、work、Claude 会话和输入去重保持。
- R9：模型工具的目标清单和项目材料按需分段读取，明确真实总数、剩余页和截断信息；不能把部分结果说成全部完成，也不能截断业务指南后继续执行。
- R10：超限旧会话先分段生成摘要，不能将全部原历史作为一个超限摘要请求。真实上下文错误最多在强制摘要并确实缩减后续接一次；无法缩减或再次失败时明确说明问题，不盲目发送同一超长输入或无限重试。

- R11：Pi 模型设置可保存压缩阈值，默认 350,000 token，允许 10,000～900,000 的整数。旧私有配置补缺省，读取不泄露密钥，省略字段沿用已保存值，下一次启动／恢复同时适用于项目和工程养号。

## Acceptance Criteria

- [x] AC1（R1、R2、R6）：两个空间分别复现“第一目标通过后 Pi 继续请求第二目标”，第二目标不能创建或启动，本次控制者及时以正常完成状态退出。
- [x] AC2（R2、R4）：完成后只保存一次通过和一次下一轮安排；计划关闭时不自动重启，计划开启时遵守该空间原固定或随机间隔。
- [x] AC3（R1、R3）：当前目标业务失败仍能原会话返工、复验；超时后下一轮保持相同 work/session、累计耗时和已保存输入事实，不转到其他目标。
- [x] AC4（R4）：人工暂停与验收完成竞争、旧代次结果、额度等待、未对账输入和账号被另一空间占用时，仍保持原门禁与取消优先级。
- [x] AC5（R5）：养号在部分完成时不清理工程池；完整通过后仍只在后续合法认领推进新工程轮次，项目空间不自动循环。
- [x] AC6（R2、R6）：真实 Pi 管道的本地替身验证正常结束与工具结果交接，无真实模型、账号或生产数据调用。
- [x] AC7（R7、R10）：百万级历史加零用量取消／错误尾消息恢复时，先分段生成摘要，再以缩小的上下文继续原任务；同一会话及原工具回执留档。
- [x] AC8（R7、R8）：连续工具结果增长时达到 token 阈值后先压缩再继续，工具调用／结果配对，已确认工具不重放，取消与单目标完成优先。
- [x] AC9（R8、R9）：新目标不带上个目标历史，原目标在阈值以下保留完整交互，达到阈值后保留摘要及近期交互；600 项分页可完整遍历，公开项目材料分段可还原，页面完整视图不变。
- [x] AC10（R10）：真正上下文拒绝只有一次缩减后的续接机会，重复拒绝明确报错；认证、内容拒绝、禁止重试和原预算优先。

- [x] AC11（R11）：页面表单、真实配置 API、私有保存、重启读取、旧配置兼容和两空间启动配置完整贯通，非法阈值不替换原配置。

## Out of Scope

- 修改模型名单、提高上游真实模型容量或改变既有内容过滤恢复策略。
- 另外三项验收误判修复、工程题库内容或冻结资产调整。
- 计划参数重置、预算策略重设、会话清理和历史进度迁移。
