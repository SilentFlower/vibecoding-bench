# Brief — 修复 AGY CRIU 模板启动失败

## Goal

- 让 AGY 当前代次的 CRIU 模板能够启动并恢复，失败时保留可定位的阶段。

## Scope

- 文件型模板启动的映射校验、普通启动回退和脱敏诊断。

## Non-Goals

- AGY #14 的生产验收随正式发布和部署进行。

## Technical Overview

- 按实际映射来源核验文件型执行体，处理 OverlayFS 的设备号差异。模板失败时保留首个失败阶段，并沿原请求截止回退普通启动。

## Context & Decisions

- **【已复现】同一份 AGY 1.5.9 执行体在容器文件系统中被观察器拒绝，经只读绑定挂载后可以就绪。** 失败发生在 CRIU 保存之前。
- **【关键决定】保留执行体归属、完整摘要、映射权限、指令指纹和代次校验。**

## Acceptance

- 隔离环境中当前代次模板实际就绪，并完成一次 CRIU 保存和恢复。
- 错误映射、跨代、普通 memfd、旧代清理和 Claude Code CRIU 通过回归。回退路径保留脱敏阶段，原请求只提交一次。

## Next Step

- 修复文件型执行体的映射准入，并用已复现的对照验证。
