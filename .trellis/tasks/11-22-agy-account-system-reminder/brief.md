# Brief — AGY 账号提示词位置对照试验

## Goal

- 用相同对话和工具配置，对照系统提示词放在系统段和用户消息里的效果。

## Scope

- 在「账号 → 配置 → Antigravity 配置」增加 **系统提示词移入用户消息（试验）**。每个账号独立保存，**新旧账号默认关闭**。

## Non-Goals

- 真实模型的指令遵循、缓存和账号状态归因留待独立验证。

## Technical Overview

- 关闭时走现有系统段。开启时，普通 Messages 请求把原系统文本包装成 `<system-reminder>`，追加到首条普通用户消息。系统段放一句固定的中性指令。
- **两个开关均开启时，先用现有同形体规则处理原系统文本，再包装成用户提醒。固定中性指令保留原文。**

## Context & Decisions

- **新生成按当前选中账号的设置发送。已交付的工具批次按原发送历史完成回填，同一 HTTP 的认证恢复沿用首次设置。**
- 现有断网回环中，两组各完成一次工具调用和一次回填。原生出站的工具声明一致，回填重读复用了结果。响应由本地合成端给定。

## Acceptance

- 两个账号分别保存开启和关闭，重新打开配置能读到各自状态。原生 TLS 出站核对四种开关组合。三种续轮覆盖回填期间切换开关、工具归属和重复读回填。

## Next Step

- 接通 AGY 账号表单与保存接口。
