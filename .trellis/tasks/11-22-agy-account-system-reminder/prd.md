# AGY 账号提示词位置对照试验

## 目标

在单个 Antigravity 账号上切换 Messages 系统提示词的位置，用相同对话和工具配置做对照试验。

## 需求

- 在账号的「配置 → Antigravity 配置」提供「系统提示词移入用户消息（试验）」。新账号及升级后的已有账号默认关闭。设置随账号保存，重开编辑器可回读，各账号独立生效。
- 关闭时，Messages 独立系统提示词进入系统段。开启时，将原系统文本包在 `<system-reminder>` 中并加入首条普通用户消息，系统段使用一句固定的中性指令。缺少系统文本或普通用户消息时沿原请求路径。
- 同形体转换与位置开关可以独立设置。两个开关均开启时，先用现有规则处理原系统文本，再将处理结果包装为提醒。固定中性指令和原有用户内容保留原文。
- 新生成读取选中账号的当前配置。同一 HTTP 请求在认证恢复中复用原选择。已发出的工具批次按原发送历史收口，回填查询与重复提交继续受原归属及回执保护。
- 本轮以断网回环和合成凭据验证。真实模型的指令遵循、缓存及供应商账号状态归因留待独立验证。

## 验收

- [ ] 两个 AGY 账号分别保存开启、关闭，列表回读和编辑状态与实际选中账号一致。旧账号升级后为关闭。Claude Code 编辑页隐藏该项，管理 API 拒绝为其启用。
- [ ] 使用相同 Messages 系统文本、用户消息和工具声明，实际原生 TLS 出站可分别看到原系统段与用户消息中的一次提醒。多文本块、已有提醒和轮内补充上下文按各自原顺序保留。Gemini 原生直连和 Claude Code 直转仍按各自协议出站。
- [ ] 四种组合有明确结果。仅同形体开启时，转换文本在系统段。仅位置开启时，提醒包含原文。两个开关开启时，提醒包含转换文本，标签和中性指令保持字面量。两个开关关闭时使用原系统文本。
- [ ] 领取、历史续轮和领取后历史兜底均校验正确的工具调用、签名和结果。工具待回填时切换开关后，原轮按旧输入收口，新生成按当前账号设置。重复读取同一回填仅交付原结果。
