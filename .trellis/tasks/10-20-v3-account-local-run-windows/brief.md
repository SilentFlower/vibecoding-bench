# 任务摘要 — 账号当地运行窗口

## 目标

- 按账号固化时区控制下一轮可运行时间，并清楚显示当地时钟和休息状态。

## 范围

- 星期、多区间、跨午夜、夏令时及持久配置；普通/批次/养号/抓包启动、恢复和新交互续聊输入共用服务端门禁。

## 不在本轮范围

- 对外 API、登录/OAuth/手动额度查询的时间限制，账号时区改写和生产部署。

## 技术概览

- 使用 zoneinfo 按真实 UTC 分钟计算边界；窗口外保留 queued/active 与等待提示，实际启动前重判且不占 CLI 资源。

## 背景与决定

- 承接已确认整体 Brief；当前 run 包括既定补充和收尾，窗口关闭不打断。已发送续聊回合继续，新输入拒绝且不重放。
- 旧账号默认全天可运行；时间和额度同时阻塞时，全部条件允许才开始下一轮。

## 风险

- 队列重启不能误判为崩溃执行；窗口关闭不能消耗额度恢复许可或清零原间隔。

## 验收

- 跨午夜、周切换、DST、各入口、排队跨边界、改配置、停止和重启去重通过；真实本地 driver 完成本轮，下一轮等待两个条件。
