# 控制台外壳与通用业务组件

## Goal

把控制台外壳换成第二版：白色侧栏、无分组名页头、新的移动端应用栏与登录页，并提供各页面共用的业务组合组件。对应父任务 `../11-19-console-ui-revamp/prd.md` 的 R2、R3；形态以 `doc/design/console-v2/mock.html` 为准，登录页以第一版设计稿的 `#login` 画面为准（第一版设计稿由本任务复制入库）。

## Requirements

- **侧栏**：
  - 白色背景，选中项浅灰底配主色图标；账号数与运行中任务数用小徽标（运行中为 0 时用中性色）。
  - 品牌旁版本号：常态灰底；有新版本时转成功色并带上箭头图标。点击沿用现有系统更新入口（打开现有更新面板，带修饰键时进入 `/updates`），弹窗本身由子任务 3 重做。
  - 导航分组名（网关 / 资源 / 工作区）保留；「系统设置」单独成组位于底部。
  - 底部管理员区保留折叠与退出。
  - 保持现有折叠宽度（76px）、视口高度布局与导航内部滚动规则。
- **页头**：
  - 去掉分组名，标题 28px + 一行说明，操作靠右。
  - 替换范围：账号、请求记录、会话封禁、访问令牌、代理管理、运行环境、节点管理、系统设置这 8 个 Vue 页面的页头，页头里的操作按钮去掉页面级外观覆盖。
  - 页面主体不变，任务与工程的页头留给子任务 6，`/updates` 整页留给子任务 3。
- **移动端（≤760px）**：
  - 顶部应用栏：品牌标志、当前页面标题、菜单按钮。
  - 抽屉导航与桌面侧栏同一外观。
  - 页头在移动端只保留操作，标题由应用栏显示。
- **通用组合组件**：
  - **页头**：见上文。
  - **概览卡**：标签、大号等宽数字、说明、右上图标块，一行四张。
  - **工具栏**：左侧筛选 / 分段，右侧搜索。
  - **实体卡**：头像 / 图标块 + 名称 + 副标题 + 状态徽标的统一头部，浅灰信息块，等分操作底栏。
  - **数据表卡片**：标题与计数、头部工具栏、圆角表头条、斑马行、60px 行高、每格主值 + 一行辅助值、操作固定最右、底部分页。
  - **浮动保存栏**：待保存项数、说明、撤销、保存。
  - **居中弹窗**：头像 / 图标块 + 标题与说明的头部、独立滚动的内容区、通栏浅灰底栏，18px 圆角（父任务 R3；子任务 1 设计 §5 约定由本任务提供）。
- **登录页**：
  - 采用第一版登录设计：深墨底品牌区配五瓣花纹理，右侧表单使用统一的输入框与主按钮，带显示 / 隐藏密码切换和凭据保存说明。
  - 登录行为、错误提示与凭据保存方式不变。
  - 第一版品牌区底部的版本号不显示，因为未登录时读不到版本，而本次范围不新增接口。

## Acceptance Criteria

- [ ] 1440×900 下侧栏、页头、登录页的计算样式与设计稿逐项一致（结构写法不同但视觉等价处列白名单并注明原因），附截图。
- [ ] 390×844 下应用栏、抽屉导航、登录页与设计稿一致，附截图。
- [ ] 侧栏可折叠 / 展开且状态保存；视口很矮时导航在侧栏内部滚动，底部管理员区始终可见。
- [ ] 有新版本与无新版本两种状态下版本号样式正确，点击可打开系统更新；退出、折叠、导航选中态正常。
- [ ] 8 个 Vue 页面的页头不再显示分组名，标题、说明、操作与设计稿一致。
- [ ] 系统设置使用浮动保存栏，修改计数、撤销与保存行为不变。
- [ ] 概览卡、工具栏、实体卡、数据表卡片、居中弹窗在演示页各有示例，与设计稿对应画面逐项一致。它们的首个真实页面使用由子任务 3、4 在对应页面验收。
- [ ] 登录成功、密码错误、空密码三种情况行为不变；显示 / 隐藏密码切换可用。
- [ ] 既有侧栏、导航、登录、设置相关浏览器验证通过；依赖旧原型取样外壳与页头的脚本，改为对新设计稿的样式断言。

## Dependencies

依赖子任务 1（组件库与主题运行时），已完成。

## Out of Scope

- 各业务页主体迁移，以及概览卡、工具栏、实体卡、数据表卡片、居中弹窗的真实页面接入（子任务 3、4、6）。
- 系统更新弹窗（子任务 3）。
- 主题设置页及其侧栏入口（子任务 5，入口随页面一起加入，避免先出现无效链接）。
- 深色模式快捷切换（子任务 7）。
- 移动端底部导航、应用栏内的页面级搜索（账号页移动端搜索随子任务 4）。
