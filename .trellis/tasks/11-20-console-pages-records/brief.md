# Brief — 请求记录、代理、令牌与会话封禁页迁移

## Goal

- 把请求记录、代理管理、访问令牌、会话封禁四页及其弹窗换成第二版视觉与组件库，信息结构与业务行为不变。

## Scope

- 请求记录：四张概览卡（第 4 张为可点击的日志级别切换），表格卡片头部（分段、ID 搜索、筛选、查询、刷新），主值 + 辅助值表格，请求详情抽屉。
- 代理管理：四张概览卡、数据表、展开使用账号、编辑与批量导入弹窗。
- 访问令牌：单行卡片改为数据表，加令牌名称搜索，编辑弹窗。
- 会话封禁：状态下拉改为带计数的分段，工具栏一次性说明时区与刷新周期。
- 网关：代理目录接口补到期计数，会话封禁列表接口补各状态计数。
- 组件库小扩展：可点击概览卡、无标题表格卡片头部、32px 图标块、表格单元格工具类、靠右抽屉式弹窗。
- 四页的 390 形态、旧样式删除、验证脚本分诊与新增四页设计比对脚本、规范同步。

## Non-Goals

- 账号页（4-1 已完成），节点管理与系统设置（4-3）。
- 第二版已撤回的请求导出、令牌「最近使用 / 轮换」。
- 查询参数、轮询、分页、复制、保存、删除、解除、批量检测、导入与识别等业务逻辑；接口旧字段与筛选语义；数据库表结构与迁移。

## Technical Overview

- 前端每页一份 `@layer components` 样式文件（`request-records.css`、`proxies.css`、`tokens.css`、`session-blocks.css`），只取 token。替代的旧规则（`request-design.css`、`proxy-design.css`、`style.css` / `approved-design.css` 中的代理与令牌规则、两个组件的 scoped 样式）整段删除，不加 `!important`。
- 网关代理计数在内存中解析到期时间，与前端「7 天内」判定一致；会话封禁用一条聚合 SQL，与列表同一时刻、同一前缀条件，列表 `total` 也改由同一结果取值。
- 前端对计数字段缺失（旧网关）显示「—」，前后端可分别回退。
- 被脚本与组件逻辑依赖的类名、属性和按钮名保留为定位契约，样式另写。

## Context & Decisions

- 设计稿只画了四页 1440 宽的列表；请求详情等弹窗与四页 390 形态按同一视觉语言补齐，截图交你目视确认。
- **【关键决定】代理第 4 张概览卡「7 天内到期 / 另有 N 条已过期」和会话封禁分段计数，由网关补只读计数字段提供（你已选定）。这是对父任务「不改接口」的一次明确例外：只增加字段、旧字段不变，本批同时提交一处 Rust 网关改动和单测。**
- **【关键决定】请求详情保留右侧全高抽屉，宽度不变（你已选定），换成第二版头部、页签带和滚动区；四个页签保留标准页签语义，键盘操作与现有一致。**
- **【关键决定】请求列表原「N 条匹配记录 · 本页成功 · 本页错误」摘要行，由概览卡和分页「共 N 条」替代，不再显示本页成功 / 错误条数。**
- **【关键决定】令牌页按设计稿新增名称搜索，只在已读取的全部令牌中过滤，不发请求。会话封禁保留现有四种状态（封禁中、已到期、已解除、全部记录），比设计稿多「已解除」一项。**
- 与设计稿不一致处按现有信息保留：请求列表 Token 列保留缓存写和平均 TPS（两行辅助值），账号列保留平台与执行节点徽标；代理延迟着色沿用现有 120ms 阈值；代理列表保留分页、检测时间与处理中请求数。
- 日志级别切换从页头下拉改为点击第 4 张概览卡，一次点击即保存，影响后续请求；保存中与读取中禁用。

## Risks

- **【交付风险】`verify_management_ui`、`verify_remaining_pages`、`verify_page_sizes` 中请求与代理段位于已知基线失败点之后，回归跑不到；改定位后需单独核对，回归结果不能证明这部分。**
- 网关首次 `cargo test` 需全量编译并联网补齐依赖，耗时较长；PostgreSQL 路径没有自动化测试，按规范人工核对 SQL。
- 旧样式规则未分层，删除不全会压过新样式；由新增的逐项计算样式比对脚本兜底。

## Acceptance

- 四页 1440×900 与设计稿逐项比对通过；请求详情、弹窗与四页 390×844 截图交你目视确认，四页无页面横向滚动。
- 请求详情、代理、令牌、会话封禁的既有浏览器验证按新视觉更新期望后通过，业务断言不放宽；回归集与集合外的失败项与基线一致。
- 四页及其弹窗的样式只取 token，被替代的旧样式删除。
- 两个接口返回新计数字段，旧字段与筛选行为不变；网关单测覆盖到期边界、已解除、前缀筛选与 `usage=false`。
