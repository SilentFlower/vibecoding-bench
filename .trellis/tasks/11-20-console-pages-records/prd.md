# 请求记录、代理、令牌与会话封禁页迁移

## Goal

把请求记录、代理管理、访问令牌、会话封禁四页换用新组件与第二版视觉，信息结构与业务行为不变。上级需求见 `../11-19-console-ui-pages/prd.md`，画面见 `doc/design/console-v2/mock.html` 的 `#requests`、`#proxies`、`#tokens`、`#blocks`。

## Background

- 四页入口：`RequestDiagnostics.vue`（`/requests`）、`Proxies.vue`（`/proxies`）、`Tokens.vue`（`/tokens`）、`SessionPolicyBlocks.vue`（`/session-blocks`）。页头已由子任务 2 换成 `PageHeader`，其余仍是旧结构：`request-design.css`（363 行）、`proxy-design.css`（90 行）、`style.css` / `approved-design.css` 中的令牌规则、`SessionPolicyBlocks.vue` 的 scoped 样式，含十六进制色值与圆角字面量。
- 四页的弹窗仍用旧 `Dialog`：请求详情（右侧全高抽屉，宽 `min(1020px, 100vw - 28px)`，四个页签）、代理编辑、批量导入、令牌编辑。删除与解除确认用 `ConfirmationDialog`。代理页内嵌账号工作区（复用 `Accounts.vue`，子任务 4-1 已换成居中弹窗）。
- 设计稿只画了四页 1440 宽的列表画面，未画请求详情等弹窗，也未画四页的 390 形态（移动端稿只有账号页）。
- 子任务 4-1 已扩展并可复用：`ModalDialog` 的 `nav` 页签带插槽、应用栏页面操作位 `#console-toolbar-page-actions`、`Segmented` 计数、`usageBarTone` 等。
- 计数来源（接口现状）：
  - 请求记录：`/admin/request-diagnostics` 返回 `counts {all, errors, processing}`，按除结果外的全部筛选条件统计，可直接供概览卡与分段使用。
  - 代理管理：`/admin/proxies` 的 `counts` 只有 `all / available / used`，没有到期统计；当前页行数据不能代表全量。
  - 会话封禁：`/admin/session-policy-blocks` 只返回当前状态的 `total`，没有各状态计数。现有状态是四种：封禁中、已到期、已解除、全部记录（设计稿只画了三种）。
- 父任务范围排除「除更新步骤记录以外的 API 或业务行为变化」。本任务经用户决定开一处例外：为代理与会话封禁两个列表接口补只读计数字段（见 Requirements「接口计数」）。

## Requirements

- **请求记录**：四张概览卡（全部、错误、处理中、后续请求日志）；日志级别从页头移入第 4 张概览卡，点击在 info / debug 间切换，保存中与读取失败的状态保持可见。分段（全部 / 错误 / 处理中，带计数）、ID 搜索、筛选、查询、刷新收进表格卡片头部；表格每格主值 + 一行辅助值（Token 列按现有规范保留缓存写与平均 TPS，为两行辅助值；账号列保留平台与执行节点徽标）；分页在卡片底部。原「N 条匹配记录 · 本页成功 · 本页错误」摘要行由概览卡与分页「共 N 条」替代，不再显示本页成功 / 错误数。请求详情保持右侧全高抽屉（用户决定），宽度不变，换用第二版头部、页签带与滚动区，四个页签与全部字段保持不变。
- **代理管理**：四张概览卡；数据表；延迟（沿用现有 120ms 阈值）与到期按数值着色；行操作检测、编辑、删除；展开使用账号、批量检测进度、同步中状态保持。代理编辑、批量导入弹窗换用新组件。
- **访问令牌**：由单行卡片改为数据表（名称、遮蔽令牌 + 复制、可用账号、创建时间、启停开关、操作），表格卡片头部带令牌名称搜索（在已读取的全部令牌中过滤）。令牌编辑弹窗换用新组件。
- **会话封禁**：状态改为分段筛选并带计数，保留现有四种状态；时区与刷新周期只在工具栏说明一次；会话标识、关联请求、解除封禁等现有操作不变。
- **接口计数**（用户决定的父任务例外，只增加字段、不改旧字段）：
  - `/admin/proxies` 的 `counts` 增加 `expiring`（7 天内到期、尚未过期）与 `expired`（已过期），按全量目录统计，与 `all / available / used` 同口径；`usage=false` 时 `counts` 仍为 `null`。
  - `/admin/session-policy-blocks` 增加 `counts {active, expired, released, all}`，与列表使用同一时刻和同一会话前缀条件，状态判定与列表筛选一致。
  - 前端在字段缺失（旧网关）时显示「—」，不按当前页推算。
- 四页的 390×844 形态：表格卡片头部换行、次要列收起、主值与辅助值保持可读，不出现页面横向滚动。

## Acceptance Criteria

- [ ] 四页 1440×900 截图与设计稿一致；设计稿未画的弹窗与 390×844 形态截图交用户目视确认。
- [ ] 请求详情、代理、令牌、会话封禁的既有浏览器验证按新视觉更新期望后通过，业务断言不放宽。
- [ ] 四页及其弹窗的样式不再写死颜色与圆角，被替代的旧样式规则删除。
- [ ] 两个接口返回新计数字段，旧字段与筛选行为不变；网关单测覆盖到期边界、已解除、前缀筛选与 `usage=false`。
