# 反重力默认登记运行环境并持续补热设计

## 账号保存与环境登记

网关持有账号和 OAuth 刷新权。AGY 保存事务提交后，通过受服务鉴权保护的内部入口按账号 ID 请求登记。编排端重读网关的当前平台和凭据阶段，复用 `agy_environment.register()` 及 `platform_api_environments` 唯一键。正式创建、补登记和并发业务唤醒通过同一事务取得同一个环境 ID 及其节点归属。登记只读取受控账号配置元数据，在正常链路的创建响应前完成有界尝试。暂时失败记录脱敏原因并交后台恢复，启动及巡检按权威账号数据补齐遗漏。运行环境列表沿现有读取入口和账号显示名联接。[正式保存](../../../services/gateway/src/service/account.rs#L826) · [登记事务](../../../services/orchestrator/agy_environment.py#L146) · [环境列表](../../../services/orchestrator/main.py#L14439)

首次后台准备资格随登记写入既有 AGY 环境持久元数据。历史环境按原生命周期判断。首次成功启动角色或显式停止时，在环境锁内收口首次准备资格。初次容量不足、控制端重启或可重试失败仍能恢复。明确停止与已回收的环境沿原唤醒流程处理。首次已登记且等待准备时，从 `agy_runtime` 投影 `unprepared`，底层容器状态由实际角色决定。[生命周期与容量](../../../services/orchestrator/agy_environment.py#L259) · [停止流程](../../../services/orchestrator/agy_environment.py#L328)

## 调度与进程池

网关在启动、账号生命周期通知和周期巡检时读取真实 AGY 账号。沿现有原生后台启动入口、20 秒巡检、账号去重、有限并发、轮转及失败退避接入。AGY 使用自己的准备与就绪校验。新登记环境走受控首次后台启动。已运行环境查询当前绑定。编排在环境锁内复核节点绑定、首次资格、账号状态、维护、现有角色及容量，后台首次启动沿 `allow_eviction=False` 申请空余名额。准备前核对平台活动门禁及原凭据准入，复用网关的 AT-only 快照与刷新锁。采集配置、代理、凭据代次、内核和环境身份与业务共用现有池键。[后台巡检](../../../services/gateway/src/service/native_prewarm.rs#L95) · [凭据快照](../../../services/gateway/src/service/agy_account.rs#L149) · [容量判定](../../../services/orchestrator/account_runtime.py#L2974)

接入服务专用的零模型热准备操作，携带受限账号及环境归属、截止、AT-only 快照和实际采集策略。发送器沿私有绑定鉴权和同一 `AgyPool` 控制器登记、交付、收口。服务准备使用独立的请求形状，业务提交及既有准备夹具沿其当前合同。监督器校验代次，复用实际启动及 ready 探针。已就绪和正在准备的同身份进程合并，业务和待回填工位先完成原工作。冷池可用原启动或同身份模板恢复。唯一可用名额用于热进程，已有停放模板可在该名额内恢复。有余量时继续沿原快照准备和过期规则。[现有准备接口](../../../services/gateway/src/service/runtime_transport.rs#L1764) · [原生池](../../../services/orchestrator/agy_runtime/supervisor.py#L379)

正常关停时，发送器停止接纳新 HTTP 请求，在原监督器业务已收口时发送既有 shutdown 指令，由实际进程退出生成原停止回执。CRIU 入口将正常关停传递给发送器，保留原不可收口时的强制退出。无停止回执的原监督器继续沿环境对账流程。

## 执行归属与可见状态

- 本机和 SSH 执行沿已登记的 AGY 节点分配及可信隧道。节点暂停、迁移和系统维护通过原门禁。后台就绪及当前状态核验账号、节点版本、环境及凭据代次。异版发送器的管理能力缺失通过受控状态呈现，业务继续使用其已有协议。[AGY 节点合同](../../spec/orchestrator/backend/agy-node-migration.md)
- 环境状态投影发送器实时观察及同环境代次的后台准备结果。就绪依据为当前池已完成真实握手的有效空闲进程。准备失败展示受控类别。恢复后，仅当前环境的实际结果覆盖该失败。失败、暂停和容量等待继续走原生命周期和退避。[环境投影](../../../services/orchestrator/agy_environment.py#L89) · [状态读取](../../../services/gateway/src/service/agy_runtime.rs#L596)
- 网关、编排与发送器的写入边界覆盖创建已提交、登记暂时失败、后台握手中断和切线。旧数据继续用原绑定。新登记通过既有持久元数据记录首次准备。隔离验证覆盖回退至已有版本时的卡片、原业务发送和节点归属。
