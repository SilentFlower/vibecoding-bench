# Brief — 再次合并 flower2api 主线（v1.32.1）并移植新功能到第二版控制台

## Goal

- 把 `origin/flower2api`（`faa53196`，v1.26.1 → v1.32.1）合并进 `feat/console-ui-revamp`，主线新功能全部以第二版控制台呈现，让本分支达到可正式合回主线的状态。

## Scope

- 解决 7 个冲突文件：
  - 账号页：补「系统提示词移入用户消息（试验）」开关；
  - 节点页：归属账号改用后端计数；

- `ui-guidelines.md` 补充三处第二版位置说明。
- 验证通过后，经 Push 计划确认完成合并提交并推送 `feat/console-ui-revamp`。

## Context & Decisions

- 主线约 60 个新提交，只有 7 个触及前端：系统提示词位置试验、补热准备原因、工具续轮模式、会话粘性、反重力节点迁移、环境账号名。其余是 AGY、网关、编排和集群的后端改动，已自动合并。
- **【关键决定】「漏页面」排查结论：主线没有本分支缺失的整页。** 主线独有的前端文件只有新增组件 `RequestSessionId.vue`，其余都是改版时有意删除的旧页和旧样式。全部路由页已是第二版结构；旧系统更新页的几条横幅文案在弹窗里由其他文案承担，功能都在。
- **【关键决定】节点页的归属账号数直接用后端 `account_count`。** 主线后端已把反重力账号计入节点，前端如果继续累加会重复计数。
- **【关键决定】工具续轮模式放在内核面板「请求内核」行下方，写法与内核选择一致（`ChoiceSelect` +「保存模式」）。** 不沿用主线为原生 `<dialog>` 写的 `portal-target`，第二版环境详情是另一种弹窗组件，同面板的内核选择已证明不需要。
- **【重要限制】合并提交和推送仍需你确认 Push 计划。** 本任务只把合并推到 `feat/console-ui-revamp`，正式合入主线和升级另行进行。

## Risks
