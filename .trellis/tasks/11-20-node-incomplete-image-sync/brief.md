# Brief — 修复 SSH 节点同步复用残缺镜像

## Goal

- 补齐并核验 SSH 节点的目标镜像，恢复节点同步。

## Scope

- 两类镜像的复用、补齐、导入验收，以及首次准备、自动同步和兼容维护的停机顺序。

## Non-Goals

- 本次交付先完成源码和隔离回归。main 的换版走正式部署流程。

## Technical Overview

- 从受信中央镜像流式补齐节点目标平台内容。重读两类镜像的实际配置、平台和发布身份，再进入节点排空及切换。

## Context & Decisions

- **【关键决定】两类目标镜像都通过核验后才停止旧节点。补齐失败时旧环境可继续服务。**
- **【关键决定】完整同名冲突仍按原身份保护处理。** Docker 标签与 ID 在实际配置缺失时仍可查到。

## Risks

- **【交付风险】不同 Docker 版本对平台选择的能力不同，需要用实际镜像验证导入和重读。**

## Acceptance

- 在隔离节点复现并补齐同标签同 ID 的残缺镜像，成功换版并取得健康回执。覆盖健康复用、全缺失、同名冲突与失败重试。

## Next Step

- 建立残缺镜像的隔离回归。
