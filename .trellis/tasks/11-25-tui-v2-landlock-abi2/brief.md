# V2 发送器兼容 Landlock ABI 2

**目标**　让美国节点沿用现有 Linux 内核，在账号页选中 V2 后能发送消息、续聊和恢复历史。

**范围**　适配发送器的就绪检查和实际会话启动。ABI 1、正式发版和生产账号切换另行处理。

**方案**　发送器自动识别 Landlock 版本。ABI 2 使用已有的文件访问规则和进程过滤器保护其他会话的私有文件。ABI 3 及以上沿用现有策略。管理员按原流程操作。

**验收**　在真实 ABI 2 内核的测试部署中，把已有账号从 V1 切到 V2，刷新确认保存成功，再用实际 CLI 发消息、续聊并在进程重启后恢复历史。同账号的两个会话各自保存配置时，核对彼此私有文件的内容和长度。同时回归 ABI 3 及以上，并验证隔离初始化失败时保留原转发方式。

**下一步**　由你指定的开发窗口实现，我独立验证切换和会话隔离。
