# attrs 验收合同修正与可用反馈

## Goal

让 attrs 多字段验证报告目标按已公布的功能合同验收，并给 Pi 具体可信的失败类别，减少错误反馈导致的无效返工。

## Background & Decisions

- 来源为父任务 `../10-26-pi-efficiency-feedback/prd.md` 的 R3、R4。
- 目标为 attrs / AT-VALIDATION-REPORT-DEV。冻结候选 c1c39e7a459542998c5b1e7eabeaa885 在本地重现 business=false，但六条公开回归通过。
- 直接原因是私有观察器要求 raise_errors=1 在执行验证器前抛 TypeError，公开合同未规定该要求。修复不能反过来给候选追加未公开需求。
- 项目已有 schema/weighted/Arrow 精确版本运行时适配和白名单反馈模式，复用其冻结保护、报告与隔离执行边界。

## Requirements

- V1：未来观察器仅按既有公开合同检查独立字段声明顺序、真实 Attribute/字段名/异常对象、一遍且组合 fail-fast 的验证语义、共享禁用开关、Exception 边界、可选聚合与不变更字段；移除未公布的严格 bool 要求。
- V2：既有冻结观察器仅在原始摘要、脚本/路径/参数与结果协议精确匹配时在临时可信副本适配，保留冻结资产与历史报告；未知版本不猜测修复。
- V3：业务矩阵失败输出有界枚举类别，验证器严格核验，再投影为公开合同可理解的反馈；不暴露私有断言、异常正文或日志。原 business 布尔和 candidate_import 来源证明仍严格校验。
- V4：复现候选与反例均在本地隔离验证；当前目标的通过仍需原生回归、历史能力及语义审查，不更改冷却、失败计数或通过证明规则。

## Acceptance Criteria

- [x] V-A1 / V1：原候选通过修正版业务矩阵与原六条公开回归；TypeError 严格拒绝与普通真值行为均不因未公开参数要求被误判。
- [x] V-A2 / V1：原始 Exception 对象/字段顺序、组合验证一遍语义、禁用、聚合、BaseException 边界与字段不变更具备独立反例，真实错误不能被适配放行。
- [x] V-A3 / V2：旧冻结字节不变，审计记录原始和实际摘要，未知字节/错误协议/假 candidate_import 不通过。
- [x] V-A4 / V3：每个失败类别对应具体安全反馈，未知类别和额外结果字段被拒绝，反馈不突破原有 12 KiB 总预算和八项上限。
- [x] V-A5 / V4：项目/养号共用真实验证入口、原有三个业务/回归适配器、历史目标及 deferred 机制回归通过；不产生未经完整验收的通过事实。

## Non-Goals

- 不更改候选业务代码、公开需求、原生测试门槛、旧提交结论或线上目标的冷却/计划。
- 不批量扩展所有项目的诊断协议，不部署或新增真实模型调用。
