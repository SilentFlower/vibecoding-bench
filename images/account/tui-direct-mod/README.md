# Flower2API 受管模型许可

此 Mod 由组织管理员发布到目标账号的固定目录市场。它通过同一会话的本机回调申请 Messages 模型发送许可，并将获准 HTTPS 请求的响应状态关联至原预留。CLI 持有原 HTTPS 连接。此模块随正式账号镜像提供，注册和启用由管理员策略控制。

在管理设置中启用实际市场中的 `flower2api-v2-direct`，并把它放在 `appendPlugins` 的最后。若已有 `prependPlugins`，保持 `sec-default@builtin`。所选账号和环境须由节点管理员登记。账号 sender 会核验实际安装模块与同批发行内容。管理员批准的固定账号以外继续使用原转发路径。
